# v27 · 双方案部署与交接 · 2026-10-22

用户明确希望同时支持使用者自行配置部署，以及网站维护者统一运行，且不准备长期维护公共站点。本轮以可独立保存、可交接为目标，同一份程序支持两种用途，不增加一套分叉后端，也不要求使用者持续连接原公共站点。

## 最终行为

- 交付同一个管理员部署 ZIP，内含已构建网页、原生 Node 服务、Windows 配置/启动入口、跨平台配置命令和可选 Compose/Caddy 模板。配置工具按步骤选择“独立部署”或“公共站点”，设置站名、本机/正式来源、端口及私有目录；保留原有模型和其他环境值，不初始化或改写数据库。生产服务现在也从 `.env.local` 读取监听地址和端口，进程环境仍优先。
- “我的圈子”增加双方式说明与部署包下载。服务仅公开用途、站名及是否有下载，固定下载入口只提供维护者准备的通用 ZIP，不暴露配置或数据库。下载文件来自 `release-download/campus-insight-admin.zip`，不会递归嵌入下一份部署包。
- 成员可导出自己的已交答卷；管理员可导出本圈当前题库版本的最新原始答卷 CSV，包括显示名称、提交时间和次数。CSV 可直接进入既有离线统计入口，公式开头的显示名称会转义，不包含账号密码或邀请码。
- 原有整站一致性备份增加空目录恢复命令，验证备份格式、完整性和关联关系；拒绝覆盖现有数据库，保留原密码、圈子和答卷，清除旧会话并撤销旧邀请。由服务器维护者私下交接整站备份，普通圈子管理员导出的 CSV 不会迁移在线账号关系。
- 独立站点与公共站点使用相同的逐圈权限；“公共站点”用途标记不授予全局读取权，账号仍凭邀请注册。不同实例不共享账号、cookie 或数据库。

## 验收

最终 `npm run check` 退出 0，既有计算、问卷、CSV、模型回退、地图、构建与隐私检查通过；账号专项 47 项及新增部署/恢复/数据带走 26 项通过。另以隔离根目录实际回答 7 个配置问题，验证交互 CLI 保存站名与端口，没有创建账号数据库。

管理员部署包共有 94 个文件，ZIP CRC、全部文件逐字节核对及 SHA256 通过。包不含账号库、初始化口令、环境私密值、测试账号、node_modules 或下载目录本身。无 npm 运行依赖，要求 Node.js 24.21+。

从该 ZIP 解压的生产实例通过 `.env.local` 指定 5194 端口和公共用途模式，合成账号实际走通初始化、建圈、受邀注册与提交。生产服务检查 8 项通过。真实浏览器核验双方式说明、管理员包下载、管理员原始答卷导出、成员仅自己的导出入口；下载 ZIP 的 SHA256 与交付 ZIP 一致，导出 CSV 实际含十题、成员和时间，不含测试密码。390×844 手机无横向溢出，最终生产页控制台无警告/错误。原 5191 预览也提供同一份管理员 ZIP。

## 边界与交付

本机没有 Docker，本轮没有运行容器构建、Compose 或实际证书签发，模板按官方文档准备；公网域名、服务器购买及公开部署均未执行。本机地址不能发给外网成员直接使用。独立运行仍由部署者负责运行、域名/服务器和备份，不承诺永久免维护。没有重新调用收费模型、修改问卷映射或地图几何，也没有重新测 GPU 帧率。

交付与完整日志位于原工作区 `交付文件/campus-insight/v27-双方案部署与交接/`，聊天 outputs 同步保留。配置与启动工具不依赖公共站点；部署者可本地保存包与数据，公共站点停用前需自行通知使用者保存资料，本轮没有向任何人发送消息。未提交或推送 Git。

# 新手体验优化 B-v52

用户反馈：信息杂、初次进入不知道做什么、重点文字偏小、可点选项不够明显；公网登录疑似故障。用户随后明确由原部署AI处理公网，本轮修改本地文件并交接。

## 修改

- 首页直接说明“先完成十个校园日常选择，再查看解读与图表”，保留问卷主按钮和页头可见的3D入口。
- 删除结果介绍中重复的三项说明，示例改答、情境试玩和收卷四步说明默认按需展开。展开入口使用边框、加号及键盘焦点反馈。
- 正文16px，功能说明15px，答题选项17px、辅助提示14px，重点小幅增强，没有整体放大标题。实际浏览器计算样式已核对。
- 登录页减少表单上方重复品牌、英文标题和流程说明，让账号、密码和登录按钮更靠前。登录/注册选中状态加深；小屏页头先显示“我的圈子”，避免被长用户名挤掉功能名称。
- 账号请求识别未配置公网来源的503，给普通用户显示服务未就绪，允许继续个人体验；服务恢复后点“重新连接”可恢复表单。服务端仍拒绝未配置来源，并提供 `ACCOUNT_ORIGIN_REQUIRED` 错误码。

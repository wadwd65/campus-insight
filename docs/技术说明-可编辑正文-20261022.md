# 你的大学平行宇宙 - 技术说明校对版

程序：v29；材料：第3版，2026-10-22。两AI原始消息已归档；最终视频、仓库同步和个人中心提交尚待完成。

## 01 你的大学平行宇宙

从校园日常，到可解释的个人与圈子画像。

面向校园日常记录的全栈应用。个人回答十道选择题，查看可追溯的规则画像；管理员邀请成员在线填报，直接查看原始答卷与汇总，减少文件收集与合并。

| 10 道日常题 | 8 + 1 个属性 | 2000 条模拟基准 |
| --- | --- | --- |
| 明确题库与选项契约 | 八项基础属性与佛系派生属性 | 用于相对位置，非真实调查 |

参赛方向：校园 / 垂直社区全栈 MVP。实现采用 React、Node.js、原生 SQLite 与同源可选模型服务。v29 功能 / 第3版材料，2026-10-22。

## 02 从真实任务出发

让个人探索与圈子收集形成可操作的闭环。

目标用户分为两类：希望趣味记录校园生活的个人，以及希望了解圈内日常选择的班级或兴趣圈管理员。后者过去需要逐份收文件、人工合并；本项目提供邀请、填报、确认共享、查看与导出的一条流程。

| 用户 | 完整任务 | 当前可验证结果 |
| --- | --- | --- |
| 个人 | 回答十题 → 报告 → 查看依据 → 临时换答 → 导出 | 浏览器按固定矩阵计算；无需注册即可使用 |
| 成员 | 打开邀请 → 注册 / 登录 → 填报 → 确认提交 | 仅本人和所属圈管理员可查看；支持撤回 |
| 管理员 | 建圈 → 邀请 → 看进度 → 查答卷 → 汇总 → 导出 | 原始十题、时间与次数直接可见，不必收文件 |
| 接任者 | 取得程序 → 私有备份 → 空目录恢复 → 重登 | 保留账号和答卷；旧会话、旧邀请失效 |

本机使用合成账号完成闭环，尚未进行真实班级长期试用。减少文件操作是可验证的流程变化；尚不能据此宣称节省了多少时间、改善了多少沟通效果。

画像可作为讨论与访谈的起点。它不用于能力排名、心理评估、教育机会分配或对个体作高影响判断。

## 03 让每个数字有来处

规则负责计算，AI 负责在明确边界内表达。

| 计算环节 | 实现原则 |
| --- | --- |
| 输入契约 | 十道题的字段、选项与映射统一来自 matrix.json / surveySchema.js，问卷、CSV 和报告共用。 |
| 基础属性 | 对有效选项对应的八维向量求和。累加阶段保留负数，避免把不同回答压成同一倾向。 |
| 相对位置 | 与 2000 条模拟基准比较，并列取中点，展示范围 2-98；它是规则中的相对位置，不是能力分。 |
| 派生叙事 | 佛系指数、时间分配和四年曲线由规则生成；明确标为推算，不伪装成实测或预测。 |
| 解释与试算 | 展示选项对维度的正负贡献；临时替换一道答案，只重算预览，不改写已交答卷。 |

问卷与行动地图共用属性账本，但来源保持清楚：问卷来自十题，行动地图只记录实际入账增量，包括重复访问衰减与时段约束。纯 3D 自由参观不改变画像。

演示答卷的学术、社交、运动、美食、佛系位置为 75、22、43、76、52。这是本轮合成答案的计算结果，不能当作真实同学的群体结论。

## 04 清晰的架构与边界

浏览器计算，与同源服务各自承担明确职责。

| 层 | 模块与职责 |
| --- | --- |
| 呈现层 | React 页面、SVG 行动地图、按需加载的 ECharts 报告。独立 3D 页面只在自由参观时加载。 |
| 领域层 | matrix / results / surveySchema / profileExplanation / circleExport。计算、校验、导出与视图分离。 |
| 状态层 | 个人账本由 Zustand 管理；账号由 AccountProvider 管理；答题草稿按账号与圈子限定。 |
| 服务层 | Node 原生 HTTP 提供静态网页、账号圈子、部署下载和模型转发。密钥不进入前端。 |
| 持久层 | 私有 SQLite 存储账号、会话、圈子、成员、邀请和最新答卷；一致性快照用于迁移。 |

数据流：选项 → 本机规则计算 → 图表 / 解释；主动同意 → 同源账号 API → 私有数据库；模型摘要 → 同源转发 → 校验后的文字 / 本地回退。

管理员、普通成员与其他圈子的请求均由服务端检查。隐藏按钮不能代替授权；接口收到未授权请求也必须拒绝。

源代码入口：src/App.jsx、src/lib/results.js、src/lib/accounts.jsx、server/index.mjs、server/accounts.mjs、server/ai.mjs。

## 05 圈子里的可见范围

由成员确认共享，再由管理员查看。

| 角色 | 允许 | 不允许 |
| --- | --- | --- |
| 未登录访客 | 个人测评、示例 CSV 与自由参观 | 查看圈内原始答卷 |
| 普通成员 | 本人答卷、填报、重交、撤回、个人导出 | 其他成员答卷、圈内名单与管理员汇总接口 |
| 圈子管理员 | 本圈名单、原始十题、时间、汇总、圈内导出 | 跨圈读取、通过邀请码授予管理权限 |
| 服务器维护者 | 管理运行环境与私有备份 | 将数据库或密钥混入公开通用下载包 |

密码使用 scrypt；随机会话在服务器保留哈希，Cookie 设为 HttpOnly 与 SameSite，HTTPS 环境使用 Secure。写请求验证 Origin 与 CSRF，并有限流与输入校验。首次账号使用私有一次性口令，不提供共享默认密码。

邀请链接把一次性令牌放在 URL 片段中，浏览器进入后立即清理地址；不写本地存储。新用户注册后加入，已有账号先登录，再明确确认加入。邀请只授予本圈普通成员权限。

答完十题后报告显示“尚未提交”。成员需勾选共享范围说明，才可确认提交原始答案、名称和时间。CSV 导出会处理电子表格公式注入；单圈导出不包含登录凭据。

## 08 十分钟复现与交接

先保证无模型也能使用，再按需配置在线解读。

| 复现路径 | 操作 |
| --- | --- |
| 管理员运行包 | 安装 Node.js 24.21+ → 解压 campus-insight-admin.zip → Windows 打开 deploy/配置并启动.cmd → 选择本机试用 → 访问打印的网址。 |
| 开发源码 | 安装锁文件依赖 npm ci → npm run build → npm start。开发可用 npm run dev，详细变量见 .env.example。 |
| 首位账号 | 从提示的私有数据目录查看 setup-key.txt → 网页创建自己的账号 → 建圈 → 邀请。 |
| 在线模型 | 仅在服务端环境变量或私有文件配置，未配置时仍可算图和显示本地规则解读。 |
| 整站交接 | 执行 accounts:backup；新包配置空私有目录，启动前 accounts:restore；原账号重登、管理员重发邀请。 |

同一包有独立部署与公共站点两种用途，权限规则相同；不同实例不自动同步账号或答卷。CSV 供离线统计，不用于迁移账号；整站备份包含私人数据，不能作为公开部署包下载。

异地使用仍需完整Node服务、HTTPS和持久磁盘。旧WorkBuddy静态首页HTTP 200，但账号会话API 404，不能用它证明v29账号已上线；Docker/Caddy模板尚未实测。

## 10 收集到的答卷可以带走

运行结束后，数据与接任路径仍清楚。

工作台先呈现成员数、收到答卷数、等待数与收集进度，明确管理员计入总数。汇总只采用每人最新的当前题库答卷。搜索与筛选改变显示列表，不改变完整导出范围。

成员可导出自己的已交答卷；管理员可导出本圈原始十题、时间与次数。是否继续原站点，由圈子管理员自行决定；保存程序与数据后可独立运行，但仍需负责服务运行和私有备份。

单人样本只展示个体分布，页面明确提醒不能据此判断整个班级。模拟班级与真实在线填报在界面和数据入口上标注来源，避免混淆。

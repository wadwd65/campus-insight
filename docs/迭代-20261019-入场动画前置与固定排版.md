# 入场动画前置与固定排版

根据用户最新反馈，打开网站先显示独立入场动画，之后由用户进入主页。此前把首屏直接改为测评入口的设计已调整。

## 当前行为

- 第一次打开或刷新：先进入全屏片头。三层背景进行一次 6.8 秒景深推进，配合光雨、浅色花瓣；画面结束后停住，等待点击「进入首页」。
- 标题、说明和按钮使用正常布局流固定在上、中、下区域。文字只淡入，不再位移或模糊；右上角跳过与底部进入按钮从首帧可用，不跟随背景缩放。
- Enter 或 Esc 可以进入主页。主页右上角和内容页顶栏均可重播片头；重播不清空问卷、班级数据或地图账本。
- 减少动态效果设置开启时，显示静态完整片头，不创建光雨、花瓣和推镜循环。
- 主页仍保留测评、校园漫游、结果示例和上传 CSV；进入主页后背景保持静态。

## 验证

完整 `npm run check` 通过，含构建、SSR 页面结构、问卷 / CSV、统计、隐私与新增逐题统计测试。在线模型验证仍未执行。

浏览器实测：

- 片头初始推进量约 0.032、结束推进量为 1，标题和进入按钮的 x / y 坐标完全一致。
- 默认桌面宽度、390×844、320×568 检查无横向溢出；320×568 下进入按钮底部为 534px，仍在屏幕内。
- 刷新先出现独立片头；点击跳过可进主页；重播、Enter 进入均正常。
- 片头 → 主页 → 十题 → 个人报告，以及报告 → 重播 → 主页 → 示例 CSV → 48 人群体页均完成；自己的作答仍可用于班内相似作答，控制台未记录错误。

本次不修改问卷契约、属性映射、统计基准与地图数据。修改仍在本地，未推送、未部署。新部署包以 v4 为准。

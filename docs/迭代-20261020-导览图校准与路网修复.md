# 导览图校准与路网修复（v10）

日期：2026-10-20。用户指出“公路断了”“建筑的位置有点问题”，并确认“基本上都不对”，随后提供一张校园导览图和两张高德截图。本轮已替换旧落位底稿，不能沿用 v9 的位置与地点计数。

## 当前布局依据

唯一坐标底稿是用户提供的 [674×536 校园导览图](map-review/用户导览图-20261020.jpg)，坐标整理在 `map-src/campus-layout.json`。该文件记录参考文件名、尺寸、像素坐标、道路和各地点，不是经纬度或实测米制数据。所有位置由图上人工标注，建筑外形继续使用简化模型。

两张高德截图用于检查楼群围合及道路关系。截图视角有旋转，未将屏幕上下直接当作南北；没有把带定位蓝点的截图复制到网站或部署包。旧目录中另有规划图放大截图，但其年代、清晰度与规划/现状差异不宜继续混作这次落位底稿。

## 实际改动

- 体育馆位于腾龙运动场西侧，凌云网球场仍在其楼顶；实验、综合及计算机楼群位于东北桂香苑。
- 按图分别保留“图书馆（桂香苑）”与“图书馆（晴缘湖畔）”；湖畔馆位于湖西侧，转为南北长体量，入口朝向晴澜广场。
- 西侧逐栋标记 1—10 栋公寓及梅苑，共 11 处；由北至南的楼号顺序按参考图整理。
- 晴味堂、超市商业区和拓新楼位于南侧；四栋教学楼位于东南，楼一、楼二在楼四、楼三以北。
- 迎日、望月分布在晴樱广场两端，抱璞亭在湖东岸。修正了上一版把抱璞亭放在湖西侧的错误。
- 删除旧示意图重复的教学楼分组、虚构小吃街分组和无对应的地面运动场占位，按图重建为 34 处地点，加湖、田径场共 36 处可选目标。该数字不是全校真实建筑总数。
- 重画晴韵、如玉、仁爱、飞花/观书、德馨和东门连接道路；在转角与路口增加共享圆面连接，消除矩形路段之间的视觉缝隙。移除旧断头支路及自动寻找最近车道而生成的随意连接线。
- 新增“俯瞰核对”，固定正向俯瞰并补充更多地点标签；简写公寓楼号，减少标签重叠。调整窗口大小时会重新适配全景/俯瞰，防止相机过渡恢复旧距离。

构建脚本不再读取 `tower-10-campus.js` 或其他旧塔楼落位，历史高精源码保留但不参与当前位置生成。若要继续校正位置，只修改新 JSON，运行 `npm run build`；不要编辑生成的 `public/map/campus-data.json`。

## 验证

最终 `npm run check` 退出码 0，共 617 项检查通过，其中地图 19 项。新路网检查验证所有道路属于一个连通整体，除东门出口外，各开放道路的端点都与其他道路相接。

原“车道中心线不穿楼”检查加强为路面两侧与中心抽样，间距不超过 1.5 个场景单位。检查曾发现拓新楼附属体量和 10 栋的简化体量侵入路幅，已在保持参考锚点的前提下收敛建筑体量。检查针对简化建筑主体，不等于真实道路测绘或完整三角网碰撞证明。

原性能上限没有放宽：32 个绘制对象、1500 个实例、25000 个三角形。最终 30 次绘制、1455 个实例、21,693 个三角形；标准档浏览器记录 12 份几何、15 份 GPU 贴图。静止停止重绘；不以 CPU 提交时间推断真实 GPU 帧率。

电脑生产页检查俯瞰、区域取景、地点选择与说明，未见控制台 error。手机分流、资源释放与主线冒烟检查通过，手机继续不启用 3D。没有新的真实手机性能测试。主问卷、CSV 统计及四时段行动账本未因本轮修改。

# 开发任务表 · 「你的大学平行宇宙」

> **产品**：个人青春行为图谱生成器 —— 答 6 题，30 秒生成一份专属的大学时代数据叙事报告。
> **方向**：传智杯「AI创新应用挑战赛」方向 6（校园 / 垂直社区全栈 MVP，数据看板类）
> **定案依据**：`docs/选型-05-大学平行宇宙-方案定义.md`（本人 2026-09-14 拍板 D-1 ~ D-6）
> **详细设计**：`docs/设计-01-问题与映射矩阵.md`
> **最后更新**：2026-09-14

## 一、这个产品做什么

```
评委/用户 答 6 道有画面感的选择题（约 30 秒）
        ↓  映射矩阵：每个选项 = 一个 8 维增量向量
   8 个潜在属性的连续值
        ↓  与 2000 人基准人群比对 → 百分位
        ↓  四套派生规则
五件套：雷达图 · 时间分配环形图 · 四年心情曲线 · 人群冷知识 · 大模型个性化总结
```

**官方对方向 6 的描述**：

> 数据源（CSV / JSON 或公开 API）→ ECharts / D3 动态图表大盘 → 大模型对长尾数据做**趣味**解读

四个要素逐一对应：

| 官方要求 | 本产品对应 |
|---|---|
| 数据源（CSV） | `public/data/问卷基准数据.csv`（2000 条模拟问卷，真入口另可上传自己的 CSV） |
| 动态图表大盘 | ECharts 雷达图 / 环形图 / 折线图，均带入场动画 |
| 长尾数据 | 8 个潜在属性的分布，以及「你排在人群第几」的百分位 |
| **趣味**解读 | 大模型生成带称呼的个性化总结；「称号」与冷知识句 |

**核心机制（产品最值钱的地方）**：让评委不做观众，做数据源。不需要账号、不需要数据、不需要安装，只需要回答几个问题 —— 然后看到「我自己」。人类对自己的好奇心，远大于对抽象数据的好奇。

**两个入口（D-4 拍板）**

| 入口 | 做什么 | 负责 |
|---|---|---|
| 快入口 | 答 6 题 → 30 秒出个人报告 | 「亮」—— 现场能玩 |
| 真入口 | 上传批量问卷 CSV → 出群体画像 | 「有用」—— 教师能看到一个班级的分布 |

「平行宇宙」的设定由此完整：**快入口是「我的」宇宙，真入口是「我们」的宇宙。** 两个入口走**同一套映射矩阵**，统计口径必然一致。

**产品边界**：纯前端，无登录、无数据库、无后端。数据只在浏览器内存里，刷新即清空。可部署为静态站（D-3 拍板）。

**M2 的两个关键设计决策（不做会被后面坑死）**

1. **归一化用基准人群分位数，不用 min-max。** 数值因此自带含义：「学术力 82」＝ 超过了 82% 的大学生。于是「人群对比」不必单独做一个功能 —— 它就是归一化本身。
2. **基准 CSV 只存原始作答，不存算好的属性值。** 于是评委本人与 2000 人走完全相同的计算路径，百分位是算出来的而不是查表来的。

**验收标准**：无密钥时打开线上站点，报告依然完整可看 —— 这是 D-3 部署路线的前提。✅ 已验证

**M4 的四个实现决定**

1. **结尾那句话不走大模型。** 它是整份报告最可能被截图转发的一句，不能出现"这次没写好"。
   于是它由 `keyword.js` 确定性生成，结果页单独渲染；大模型两条路径的正文都**不含**结尾句。
   凡是不能被写砸的东西，就别放在模型手里。
2. **摘要里每个维度都标了方向**（`佛系指数 2（偏低）`）。
   百分位本身不携带方向语义 —— 模型看到"2"和"98"能读出的东西是一样的，
   第一版提示词就因此把"很佛系"和"很有社交天赋"全写反了。在输入侧补齐语义，比在提示词里加十句"请注意方向"管用。
3. **失败是一种正常返回，不是异常。** 所有失败路径都返回同一形状（`degraded` + 内置文案），
   调用方永远不需要 try/catch。因为线上那版大概率不带密钥，降级是主路径之一。
4. **半句话比内置文案严重得多。** 拿到的正文若不以句末标点结尾，一律判为截断、整段降级。
   这条来自一个很真实的成因：模型撞上 `max_tokens` 时，服务端会**一切正常地**结束连接，只把话说了一半。

**验证方式（不靠肉眼）**

流式这块最容易出的问题是"一个 JSON 被切成两半"，肉眼在浏览器里几乎发现不了。所以：
- `sse.js` 拆成纯函数，自检里用**按 1 字节切块**的假流验证（中文每字 3 字节，必然被劈开）
- `llm.js` 的传输配置可注入 → 自检里起一个**本地假 OpenAI 服务端**，用真 fetch 跑完整条路径：
  正常流式 / HTTP 500 / 只回 `[DONE]` / 不回 `[DONE]` / 撞限长写半句 / 连接硬断 / 挂住超时 / 完全没配 / 外部中断
- `npm run selftest`：**94 项全通过**（原 39 + 文本层 55）

**演示视频要用到的一点**

线上版不带密钥（`VITE_` 变量会被打进 bundle，公开的密钥等于没有密钥）。
真流式输出的画面要用本地 `.env` 跑再录 —— 这一段正好也是 AI 协同过程里的实拍素材。

**验收标准**：干净电脑上打开线上站 → 点「上传一份班级问卷 CSV」→ 用示例数据 → 看到群体画像。✅ 已验证（SSR 冒烟 21 项）

**M5 的四个实现决定**

1. **两个入口共用同一个基准、同一个百分位函数。** 真入口本可以自己给自己当分母（48 个人互相排），但那样算出来的数只在这个班内部有意义，换一个班就不可比 —— 教师拿两个班一对比就会得出错的结论。现在「班里学术力中位数 62」与某位同学报告里的「学术力 82」是同一把尺子，可以直接比。自检里有一条断言把这件事钉住：**一个人的「班级」中位数，必须等于他快入口报告里的那个百分位**。
2. **班级整体位置用「个体百分位的中位数」，不用「均值的百分位」。** 几十个人的均值波动极小（约 1/√n），它的百分位会永远挤在 40~60 之间，每个班都显示成「中等」—— 恰恰把「这个班有没有特点」这个真问题压平了。中位数不受极端个体影响，也与个体数字同标尺。
3. **分组按「最突出的那一维」，不用聚类。** k-means 依赖初始点，同一批数据跑两次可能给出不同分组，而「我们班 12 个人是学术型」这句话必须每次都一样。确定性 + 规则可解释，比"高级算法"重要。
4. **示例数据不走捷径。** 示例 CSV 与前缀路径完全一致：fetch 同一个文件 → 同一个解析函数 → 同一个清洗函数。做捷径意味着示例永远能过、真文件永远在踩坑，而评委试的第一份数据恰恰是示例。

**顺带补上的一层验证（不为 M5、但由 M5 引出）**

`npm run smoke` —— 用 `vite build --ssr` 把四个页面在 Node 里**服务端渲染一遍**，断言页面上真的出现了该有的字。

它补的是「构建成功 ≠ 页面能打开」这个缺口：JSX 属性名写错、模板取不存在的字段、import 路径少一层，都不会让 `vite build` 失败，只会让浏览器里出现一块白屏 —— 而白屏是评委能看到的最糟的失败。最后一条兜底断言尤其重要：**整页 HTML 里不许出现 `undefined` / `NaN` / `[object Object]`**，一个字段名写错通常不会报错，只会把这三个字符串之一印在用户面前。

## 五、怎么验证（三个命令，都不需要装东西）

```bash
npm run check      # 一次跑完下面两条
npm run selftest   # 113 项：计算层 + 文本层 + 流式解析 + 假服务端端到端
npm run smoke       #  21 项：四个页面在 Node 里服务端渲染一遍，断言该有的字都在
```

| 命令 | 守住什么 | 为什么不能用肉眼看代替 |
|---|---|---|
| `selftest` | 选项零漂移、输出分化度、摘要完整性、降级文案不塌缩、SSE 逐字还原、八条失败路径 | 5000 次随机作答的分化度、被切成 1 字节的中文流 —— 手点不出来 |
| `smoke` | 四个页面能否渲染出结构；HTML 里不许出现 `undefined` / `NaN` / `[object Object]` | 「构建成功」不等于「页面能打开」，而白屏不报错 |

这两条一起构成了「验收标准必须能自动跑」这条规矩的落点 —— 写在文档里的阈值不算数，能被脚本执行的才算。

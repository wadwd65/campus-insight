# B-v41 · 可拖动同行与彩蛋恢复

问题：B版替换立绘组件后，旧彩蛋的计算仍在App里，但新同行组件没有接收数据和动作，也没有点击计数。用户看到立绘，却无法再触发彩蛋。

- 按住立绘或“移动”把手即可拖动；至少移动6px才视为拖动，普通点击与轻微手抖仍正常招呼。Pointer capture保持拖动，释放、取消、失去捕获或窗口失焦均结束手势，不残留拖动状态。
- 拖动结束只在浏览器保存位置比例，不保存账号、答案或报告。刷新后按当前窗口尺寸恢复；窗口缩小自动夹紧。“归位”清除此位置设置并回到默认右下角；浏览器禁止本地存储时仍可拖动。把手支持方向键16px、Shift加方向键40px、Home归位。
- 恢复滑动60秒内10次有效点击的彩蛋。拖动后产生的兼容click不计入，拖动把手也不计数；键盘触发的立绘click仍可触发。触发后计数清零，可再次发现。
- 彩蛋复用原EGG_GREET、EGG_NO_DATA及buildEggQuip，不编造百分比。当前报告数据由ExperienceSettings context送给同行；没有数据时明确说明，并提供真实“先答十题”入口。
- 有问卷时提供真实CSV下载；行动地图路线提供“查看行动报告”，避免把历史问卷CSV说成当前地图档案。切换账号、重来或数据变化后关闭旧彩蛋并清除计数。未在本地存储趣评或用户数据。
- 彩蛋停留至用户关闭，方便阅读和操作；气泡根据实际尺寸夹紧在窗口内。保留关闭、收起、图片失败兜底和系统减少动态时的文字交互。
- 沿用v40四首场景配乐及播放意愿规则，移动小人和触发彩蛋不会开启音乐。A、B-v38/v39/v40归档保留。

本轮没有新增公网部署、云端账号、外部服务或图像生成。运行包不含真实数据库及私有配置。验收记录明确区分纯函数测试、jsdom真实React事件与原生媒体模拟；浏览器原URL访问限制仍遵守，没有用其他工具绕过，也不声称已完成真实浏览器拖动、视觉或扬声器实测。

# v18 校园建筑现代化重建 · 2026-10-21

用户认为大量楼宇像十年前的旧式建筑，授权重新建模并希望一次完成较多工作。本轮更新覆盖 29 处建筑/建筑组与廊亭：11 组公寓、10 处教学实验建筑、两处图书馆、体育馆、食堂、生活商业区与三处廊亭。原有位置、朝向、比例、道路、湖岸和球场落位输入保持一致。建筑继续明确为艺术化设计示意。

## 外观变化

- 公寓：去掉蓝色坡屋顶、米黄色墙面和双拱入口，改为薄檐平顶、浅色模块阳台、细框玻璃楼梯间、木色廊架与屋顶种植；枕霞苑保留围院、梅香苑采用错层退台、松涛苑采用架空连桥，三个片区仍可区分。
- 教学与实验：重做浅色围院与玻璃连桥，采用细竖向遮阳、矩形柱廊、平屋顶与条形天窗；技术中心和综合楼保留各自的中庭与错层体量。
- 图书馆：湖畔馆改为通高玻璃阅览厅、浅色双翼与薄悬挑顶，两侧屋顶使用透空木格廊架；桂香苑馆维持低矮花园体量，采用平顶双翼与玻璃中厅。
- 食堂与商业：整片餐厅窗、轻薄连续雨棚、退台露台和透空木格廊架，取代较厚的檐口及拱廊。体育馆的屋顶网球场高度不变；三处亭子使用细柱、薄顶与木格。
- 材质：重新绘制教学楼、公寓、石材、玻璃和屋面共享贴图，减少黄褐色与粗框；玻璃增加轻微高光，维持低饱和银蓝、暖木、浅石与灰绿的统一色调。

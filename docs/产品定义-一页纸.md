# 这个作品到底是什么（一页纸）

> 用途：回答"我们到底做出来的是什么东西"。写给自己对齐方向，也直接可复用进技术文档/演示视频的开场。

---

## 一、一句话

**一个"把一份表格变成本事"的数据分析作品**：喂进去一份问卷/清单类 CSV，它出图表大盘，
再用大模型把数字写成人话；没有数据的人，也能靠十道题现场生成一份**自己的**数据。

## 二、主链路（对应赛题方向 6 的形态要求）

```
数据源（CSV / 也可以没有）→ 图表大盘（ECharts）→ 大模型解读
```

三段都在，且每段都有可验证的产物：

| 段 | 具体是什么 | 怎么证明它真的在跑 |
|---|---|---|
| ① 数据 | 上传课问卷 CSV（每人一行、10 列作答）；内置 48 人示例可一键试 | `npm run smoke:csv` 在 Node 里跑真链路，断言 **48 人 / 学术型最多 12 人 25%** |
| ② 图表 | 类型分布条形图 · 班级 vs 全体大学生雷达图 · 九项属性分位区间 · KPI 三卡 | 页面渲染冒烟（4 个页面）+ 实拍截图 |
| ③ 解读 | 大模型三段话：整体气质 / 最不一样的一项 / 给班主任两条可执行建议 | 无密钥时**降级为本地规则**，同一套数字写出 310 字真结论（评委看到的就是它） |

## 三、支线（不是主体，但让作品"可玩"）

| 支线 | 是什么 | 边界 |
|---|---|---|
| 问卷测评 | 10 道有画面感的选择题 → 八维属性 → 个人报告（雷达 / 时间分配 / 四年曲线 / 冷知识 / AI 解读） | 同一套算法、同一本账；**没有数据也能立刻玩** |
| 行动地图 | 4 个时段 / 16 个地点，反复走、属性衰减 | **附加体验**，不参与评分功能、不阻塞主线 |
| 3D 实景校园 | 单文件 three.js 校园（湖 / 田径场 / 院墙 / 行道树） | **附加展示**，外链进入 |

## 四、它**不是**什么（把误解先挡住）

- **不是问卷网站**：问卷只是"没有数据时的冷启动入口"，主体是数据 → 图表 → 解读。
- **不是地图产品**：地图/3D 是彩蛋，删掉它们，主链路照样完整可演示。
- **不是"看得见的数据"**：产品的主张是"让你成为数据源"——看别人的数据人人会，看自己的数据才有那个"这就是我"的瞬间。

## 五、可靠性（这是"过程可复现"的一部分）

`npm run check` = **7 步 426 项**，其中两步是这次新增的硬闸门：

- `smoke:csv`（30 项）：CSV 主线的端到端数值断言 + 负向用例（脏数据必须被拒）
- `verify:dist`（13 项）：构建产物完整性 + 反死重量（不该存在的目录 / 体积上限）

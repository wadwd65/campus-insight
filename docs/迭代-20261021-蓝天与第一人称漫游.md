# v23 蓝天与第一人称漫游 · 2026-10-21

本轮按「蓝色的天空」及「第一人称」要求，将默认画面改成晴朗蓝天，并增加可切换的地面漫游。

## 使用

刷新本地地图，点击底部「第一人称漫游」。WASD / 方向键行走，鼠标左键拖动转向，Shift 快走，Esc 或「退出漫游」返回。可以点击「自由转向」捕获鼠标；捕获后 Esc 先释放，再按 Esc 返回地图。浏览器拒绝捕获时会提示继续拖动。「回到湖畔」可恢复起点。

默认从图书馆湖畔开始；先选择地点再进入，会从附近合法落点开始。漫游自动收起导览、隐藏地点浮签，保留方向指示与附近地点提示。退出恢复原视角、预设和导览展开状态，切换其他取景也能退出漫游。

## 实现

- 天空采用饱和度适中的蓝色渐变，远处淡蓝；延用静态云层、太阳圆面与轻光晕。默认光照和薄雾协调为晴朗蓝天，保留可选的杏金傍晚。天空依然是一张按画幅适配的静态背景，转向不重画贴图，没有新增天空网格或云层动画。
- 漫游相机使用约 1.75 单位眼高、67° 视场角和独立的近远裁剪；地面高度随道路、岸边步道、木平台和体育场平滑调整。进入地面视角时将既有静态投影层降至地面附近，退出恢复高度，不重新烘焙。
- 碰撞采用实际墙体体积、旋转包围盒和空间格网查询，保留门廊中间的通路；另有湖面、树干及校园边界阻挡。移动按小步推进并沿墙滑动，斜走归一化，长帧间隔限制步幅。属于地面漫游，未扩展楼内空间、楼梯攀爬或跳跃系统。
- 行走或转向时沿用交互降分辨率与约 30Hz 的绘制节奏；松键及高度收敛后停止行走补帧。静止时继续按需绘制，已有湖水仍受可见性、省电档、页面状态及减少动态效果等条件控制。未增加常驻漫游定时器、后处理、三维模型或贴图对象，也未增加项目依赖。
- 键盘失焦、页面隐藏、退出、图形上下文丢失与销毁时清理输入并释放本页拥有的鼠标捕获。拖动转向与原地图旋转互斥，指针捕获失败可回退到拖动。

# B-v53 / B-v53.1：布局减负与流程复查

对应本轮要求：修复文字及操作遮挡，减少默认展示的信息，让用户知道当前在做什么，并改善3D地图入口。修改范围是主站界面和入口，没有重做3D模型。公网由原部署AI接手，本轮没有发布。

## 发现与处理

| 问题 | 处理 |
| --- | --- |
| 手机吸底翻页栏盖住末尾选项，小人挤占操作区 | 翻页栏放在全部选项之后，进入正常文档流；答题、报告、圈子、统计与导入时暂时隐藏悬浮小人 |
| 题号、五站路线、地点与逐项解释堆叠 | 保留题数、题干和五个原答案；路线、回答提示及全部选项解释按需展开；选后明确提示答案及下一步 |
| 地图带入问卷时，来源说明挤在题目上方 | 来源细节移到题干下的可展开区域；保留建议及显式采用按钮，原人工答案仍优先 |
| 报告首屏先显示说明和交卷面板，看不到结果 | 先显示称号、个人解读和结果；保留直接提交入口及共享确认，没有取消管理员本人提交 |
| 圈子页三张步骤卡占据大段手机屏幕 | 改成当前下一步提示，完整操作路线可展开；提交状态与实际操作按钮仍直接可见 |
| 3D入口不鲜明 | 页头保持直接可见，增加暖金渐变、立体校园图标和箭头；320px避免标题孤字换行 |
| 主页原位立绘碰到右侧内容 | 常见桌面宽度给立绘预留右侧空位，仍可拖动、收起和触发彩蛋 |
| 主按钮等待入场淡入 | 问卷主线和按钮立即出现，示例预览仍保留轻量动画 |

重复的吸底栏补丁和“下一步建议”CSS已合并。未删除问卷、维度与计算，也没有把游戏建议直接当作已核对答卷。

## 真实浏览器覆盖

使用本地5396端口和隔离测试数据，不使用公网真实账号或答卷。

- 管理员测试身份逐题答完十题、生成报告；进入共享确认，勾选后实际提交成功，回圈子看到最新提交。
- 阵雨地图走完十个决定，资源不足的行动保持不可选；回问卷保留十题人工答案，改选后可显式采用地图建议，再生成报告。
- 访客跳过登录进入问卷；空选不能翻页；选择、下一题、上一题均可操作；暂停回首页再进入，选中项恢复。仅清理了本轮生成的隔离访客测试草稿。
- 登录错误明确显示“账号或密码不正确”；登录/注册可切换，注册密码原生约束为6～12位，免登录入口可用。
- 48份合成示例可以打开，标明非真实调查；小剧场第一幕选择有反馈并可存档返回。
- 响应式检查覆盖320、390、680、780、900、1280px，补查320px标题和桌面立绘留白。390px答题不再出现选项与翻页栏重叠。临时视口在结束时恢复。
- 页头3D入口实际打开独立3D页面并加载画布，主站返回入口可见。不是只检查链接字符串。

## B-v53.1追加：小人默认展开与新手主线

用户要求恢复小人默认打开，并重新检查新手会不会不知道该做什么。

发现三处理解风险：两个大入口容易被当作两项必做任务；“地图”与“3D”用途不够明确；报告的装饰性文字没有直接告知本轮已完成。另外，进入答题/圈子会永久把小人的状态设为收起，造成回首页后仍不出现。

本轮处理：

- 电脑首页默认展开小人。进入答题、报告、圈子时仅避让控件，回首页恢复原开合状态；手动收起仍有效。850px及以下默认采用紧凑显示，窗口恢复宽屏会恢复默认展开。手动选择开合后以手动选择为准，刷新页面回到默认状态。
- 首页写明“推荐从十题问卷开始”；另一入口改成“可选：先玩校园一天”，说明“玩后核对十题，生成同一份档案”。3D副文案改为“自由参观·电脑端”。
- 报告直接提示“十题已完成·个人档案已生成”。
- 登录页原来的免登录说明改成可点击入口，放在桌面首屏左侧，避免720px高窗口中跳过按钮位于表单下方而被忽略。窄屏仍使用表单下方的免登录按钮。

实测使用独立临时标签页，从片头跳过、首页、免登录入口、十题到报告；验证暂停/上一题保留选项，完成后小人回首页展开，手动收起后往返保持收起。没有创建真实账号或提交公网数据。

本轮执行SSR109项、React DOM完整衔接测试（新增默认展开、往返、手动收起断言）、立绘位置7项、构建产物19项及本地HTTP资源15项，全部通过。没有将B-v53的完整check日志冒充本轮重跑全部脚本。证据文件以 `v531-` 开头。

从新手视角，推荐路径现在是“十题问卷→个人档案”；校园一天是可选的情境开场，圈子用于有收卷需求的人。可选模块总量依然较多，因此继续保持详细说明和故事按需展开。这是本轮走查判断；真实陌生用户的独立完成率尚未重新测量。

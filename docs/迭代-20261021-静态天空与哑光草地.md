# v22 静态天空与哑光草地 · 2026-10-21

用户要求加静态天空和太阳，用更简单、开销更少的方法改善效果，进一步提高草地观感。本轮集中修改天空与草地，沿用已有建筑、树木、布局、连续桥面及体育场避路几何。

## 修改

- 天空改为一张固定背景贴图，包含六组静态云层、柔暖渐变、清楚的太阳圆面与轻光晕。移除原天空球；太阳画在画幅上方，俯视校园时不会因天空球朝向而落到镜头后方。背景太阳是艺术化示意，原日光方向仍控制校园定向光与静态地面投影。
- 太阳按画幅比例补偿半径，在窄窗与宽屏中保持圆形。只有色调、日光方向或画幅比例改变才重新绘制天空；转动和平移地图、重复选择相同设置不重画贴图，不增加动画定时器。
- 正常桌面天空贴图由 2048×1024 改为 1024×1024，初始省电档由 1024×512 改为 512×512，均不生成 mipmap。对应像素存储减半；这是贴图尺寸的结构比较，不是实际 GPU 帧率测量。
- 草地改为哑光漫反射材质，去掉原有高光与凹凸法线采样。重画更深、更柔和的绿色、低对比修剪条带和细碎草色，降低泛黄亮点及斑驳噪声。减轻远景雾化，已有实体草叶颜色同步协调。
- 复用原来一张 512² 细节纹理的预算，改为近景草纹颜色调制：100～300 场景单位逐渐淡出，远景与省电档跳过额外纹理采样。没有新增草叶实例、纹理对象、后处理或持续动画。相较原草地 Phong + bump 路径，材质不再计算高光与高度导数，近景细节只增加一次颜色采样；仍有正常地面和背景绘制成本。

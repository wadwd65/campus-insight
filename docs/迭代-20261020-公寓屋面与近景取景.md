# v14：公寓屋面与近景取景

日期：2026-10-20。继续校园建筑外观优化，位置沿用用户确认的导览图。没有修改校园布局输入、道路、湖岸、建筑锚点、旋转或比例。

## 本轮实际核对与边界

原全景标签页已关闭，本轮重新打开同一720yun作品，实际能够看到校园画面。没有操作付款或绕过访问限制。全景交互仍慢，且自动漫游影响取景。

取得[明确标注3栋、4栋的画面](map-review/全景-公寓3与4栋标注画面-20261020.png)：可见蓝灰双坡金属屋面、浅色山墙、楼端露台和暖色平顶服务空间。这一帧作为新增外观身份依据，不把底部“食堂”缩略图的选中状态当作食堂建筑的证据。

3、4栋补充专用双坡顶、浅色山墙与一侧楼端服务体量，服务体量保持在原有楼翼和露台范围内；配色沿用暖卡其墙、蓝灰顶和浅色檐口。4栋没有被解释成3栋的真实镜像：当前仍是导览图上的简化围合，完整楼翼尺寸、背面、服务体量精确方向未实测。未将这组细节套到1、2、5、6、7、8栋等其他公寓。9、10栋保持此前专用屋面。

食堂仍未取得足够明确的外观证据，本轮没有声称完成其还原。参考截图只留在开发记录与交付材料，不进入public或dist。

## 取景交互

- “靠近看看”现在根据建筑类型和旋转确定视角，不继承此前随意环绕的方向。综合楼二能直接看到玻璃楼梯间与上层窗带；公寓采用轻微侧向取景，兼顾楼端和阳台。这里的取景是模型展示角度，不代表真实大门方位。
- 新增“俯看屋面”，在同一建筑上提高俯视角度，方便核对屋顶和院落；点击“靠近看看”可恢复近景。
- “看看另一侧”在相机过渡期间连按时按预定目标角度累计，避免使用尚未到达的中间角度导致每次转动幅度不一致。
- 继续按需绘制，自动环绕默认关闭；这些按钮不重建几何或阴影，也不引入常驻动画。

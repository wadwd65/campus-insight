# 反馈收敛与站内四时段行动地图

日期：2026-10-19。范围来自用户本轮要求：移除夸张扫光、增加交互反馈与彩蛋，并优先重做站内四时段行动地图。

## 界面与彩蛋

- 删除入场按钮、答题选项的扫光，以及跟随鼠标的大片柔光。纹样的轻微视差与纹章点击反馈保留。
- 统一可操作元素的悬停、按压、键盘焦点和禁用状态；遵循系统减少动态效果设置。
- 片头与主页增加四封可翻阅的「校园来信」。可关闭、按 Escape 收起；不会触发片头跳过。
- 地图湖边增加小鸭留言。两个彩蛋均不影响计算、预算或报告。

## 行动地图

- 用原生 SVG 绘制教学区、运动与湖畔、生活区、道路、建筑和树木；16 个真实配置地点以按钮覆盖在示意坐标上。明确标注「示意布局 · 非真实坐标」。区域图片仅作印象图。
- 点选只查看，确认才消耗时段。详情显示地点故事、成本、剩余时段和经过重复到访衰减后的实际增量，包含负向变化。
- 实际路线连线、四格时段条、到访区域纪念章与路线标题随行动、撤销和清空同步变化。两时段地点占连续两格；重复到访保留每次记录。
- 路线小记可下载为带 UTF-8 BOM 的 TXT，仅含地点、时段与故事说明，不导出原始问卷答案。
- 手机使用编号地点，点选后滚动至完整详情，另提供返回地图按钮与原生地点选择框。底部档案入口不遮挡确认出发按钮。
- 地图页将小人缩成工具栏头像，避免覆盖详情操作。

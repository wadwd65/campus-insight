# v37 · 从“像工具”到有自己的校园片段

用户反馈：找了几个人测试，认为网站单调；进一步明确为“整体像工具，缺少参与感”。本轮目标是让主站早一些发生可见的选择，而不是继续扩展3D地图或强接在线模型。

## 改动

- 首页静态流程说明卡替换为三幕小剧场：早八、课后、深夜。每幕有三个正式题库中的合法选项，选择后更换场景反馈，支持换幕、改选、重玩、跳过和开始正式测评。试玩只用组件内临时状态，不预填、覆盖或提交真实答卷。
- 个人测评成为首页第一个主要入口；圈子登录/收卷入口保留，CSV和48人模拟班级移动到组织者相关区。首页不再自动弹出三步模态说明，保留显眼的使用帮助；圈子首次指引仍可展开或跳过。修正旧指引中需先由站点管理员开通账号的过时说法。
- 十题以不同的校园片段提示呈现，选中反馈显示本人原始选项。没有增加分数奖励、自动跳题或假人群反馈。选项文字、矩阵、草稿恢复、手动下一题和提交前确认保持原契约。
- 报告提供纪念卡：从本人Q6/Q8/Q10合法答案挑一幕，可添加40字内留言，实时看预览并保存900×1160 PNG。留空可直接生成；也可跳过制作看图表。留言仅用于本机图片，不写进答卷、CSV、圈子提交或模型请求。无合法答案时不伪造纪念卡。
- 使用本地SVG和原生Canvas生成图像，不新增图形库、外部字体、音频、自动轮播或新的常驻动画循环。原有v36车辆、人物、室内和屋顶玩法保留。

## 验证

- `npm run check`完整检查通过；新增5项参与感/片段合法性/原始CSV不变/XML转义/边界输入检查。
- 另有5项离线DOM与真实React事件验收：试玩门槛和改选、完整试玩/重玩/跳过、留言与片段预览且可跳过、真正SVG转PNG下载和错误恢复、真实十题逐题确认及回调只触发一次。测试拦截网络请求，结果为0。
- 实际导出了PNG，并用本机渲染检查常规、长留言和转义边界样例。输出均为合成答案的测试样例，不是真实用户档案或新用户试用证据。
- 最后文字/样式调整后补验SSR、生产构建、产物、隐私和相关新测试。
- 浏览器工具仍受既有URL策略限制，未做真实浏览器布局/点击、屏幕阅读器或真实用户盲测。离线DOM和图片渲染不能替代这些验收，尚未证明转化率或满意度提升。

## 下一轮用户复测

让原测试者从新版首页开始，观察第一分钟是否能发现并愿意操作小剧场、是否完成自己的十题、是否愿意制作/保存纪念卡，以及哪些位置仍想退出。记录实际原话和卡住的位置；不编造访问量、点赞、好友在线或班级排名来营造参与感。

圈子是实际收卷工具，管理员权限、原始作答和同意流程继续优先保证清楚。无需为这轮改动重新填写账号或部署参数；已有私有数据应保留。正式公网和视频仍按实际验收推进。

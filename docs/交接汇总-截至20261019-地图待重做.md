## 3. 目前已完成的网站修改

### 3.1 入场动画与首页

- 恢复并前置独立全屏片头：打开、刷新先看到片头，然后进入首页。
- 片头背景进行一次约 6.8 秒的景深推进，结束后停在完整画面，等待用户进入；可跳过、重播，支持键盘进入。
- 修复标题、说明和按钮随动画飞移的问题：文字与操作固定排布，只让背景和装饰承担运动。
- 首页保留测评、校园漫游、CSV 导入三种入口；新增三组可切换的示例档案，明确标注“示例，非你的结果”。
- 示例称号、数值与雷达由正式报告计算路径产生；雷达切换有平滑过渡，并遵循系统减少动态效果设置。
- 新增书页、星轨、罗盘等 SVG 纹样，桌面鼠标移动产生轻微视差；中央纹章可点击点亮。标题和按钮不参与视差。
- **后续已删除**入场按钮扫光、答题选项扫光、大片鼠标跟随柔光。早期记录或旧截图中的这些效果不是当前状态。
- 统一悬停、按压、键盘焦点与禁用反馈；手机与减少动态效果模式关闭鼠标跟随。
- 新增四封可翻阅的“校园来信”，可收起、Escape 关闭，不影响测评数据。

对应文件：`src/scenes/IntroScene.jsx`、`src/scenes/EntryScene.jsx`、`src/components/LandingContent.jsx`、`ProfilePreview.jsx`、`SceneOrnaments.jsx`、`CampusNote.jsx`；样式主要在 `landing.css`、`scene-details.css`、`interaction.css`，视差逻辑为 `src/lib/scenePointer.js`。

### 3.2 问卷与作答体验

- 调整十道题的题干、提示和主题标签，让在校生也能作答，去掉必须毕业或经历四年的前提，减少过度人格判断。
- 保留十题、48 个规范答案、CSV 字段和原有选项增量向量；题干调整不是建立了科学心理量表。
- 支持 A–E / 1–5 快捷键、上一题修改、切题回顶部，选择反馈期间防止重复操作。
- sessionStorage 保存本标签页草稿；刷新后可恢复，完成或主动清空后删除。校验版本、进度与选项，存储不可用时仍可作答。
- 紧凑页头和布局，减少答题滚动；保留颜色与勾选反馈，删除扫光。
- 修复从班级报告去补答再返回原班级的路径，以及回首页后残留补答去向的问题。

对应文件：`SurveyForm.jsx`、`QuizGate.jsx`、`ArkOption.jsx`、`src/lib/surveyDraft.js`、`src/data/matrix.json`、`src/App.jsx`。

### 3.3 个人报告与导出

- 报告优先显示称号、关键词、关键读数；收起冗长的作答轨迹，展开时显示实际答案。
- 支持本地 Canvas 生成 1080×1350 PNG 档案卡，复制报告文字及复制失败后的文字下载。
- 修复账本路径漏算派生维的问题：保存八项基础属性，在报告边界使用同一公式重算派生属性，避免问卷与地图口径不同。
- 地图档案编号加入实际属性；探索前后比较明确为“问卷 + 地图行动增量”。
- 修正模拟基准、规则推算、相似度及隐私说明；“冷知识”不再把 2000 条模拟记录说成真实大学生总体。
- 未配置接口时明确显示本地规则解读，不把模板称为真实在线 AI，也不展示无效的重写操作。

对应文件：`ReportView.jsx`、`AiSummary.jsx`、`FactsCard.jsx`、`src/lib/reportCard.js`、`exportProfile.js`、`matrix.js`、`results.js`、`fallback.js`。

### 3.4 CSV 导入与群体画像

- 多文件分别解析、按列名合并，支持列重排、后续文件新增编号、引号内换行；缺列、重复列、损坏引号给出明确错误。
- 支持 UTF-8、GBK / GB18030、带 BOM 的 UTF-16LE / BE；混合编码分别解码再合并，界面显示编码。
- 对误选 XLSX / XLS、PDF 提供格式转换提示。单文件 5 MB、每批合计 10 MB。
- 班级报告优先呈现有效样本、最多类型、分歧最大维度；可下载统计摘要、切换文件。
- 新增十题原始作答分布：逐题人数、占比、零人选项、并列最多与分母说明；可导出 48 行选项汇总 CSV，无逐人作答数据。
- 小样本不外推全班；四分位距大不再推导“没有中间人”等不成立结论；相似度按八项基础属性计算。
- 增加稳定浅色阅读底、手机布局及可读标题层级。

对应文件：`UploadPanel.jsx`、`CohortPage.jsx`、`CohortAi.jsx`、`AnswerLens.jsx`、`src/lib/decodeCsv.js`、`answerDistribution.js`、`cohortSummary.js`、`exportProfile.js`、`answer-lens.css`。

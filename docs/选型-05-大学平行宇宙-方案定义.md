## 一、方案原文（本人提出，未删改）

> 核心思路是：**让评委不做观众，做数据源。** 不用他有任何账号，只需要在现场回答几个好玩的、有共鸣的简单问题，系统就生成一份专属的「大学时代数据叙事报告」。整个过程大约 30 秒，结果因人而异，且一定逗乐评委。
>
> 我称之为：**「你的大学平行宇宙」—— 个人青春行为图谱生成器。**

**演示流程**：请评委走上台 → 大屏逐个显示问题，评委选一个 → 系统记录 → 答完立刻生成专属报告。

**问题示例**（本人设计）

| 问题 | 选项 |
|---|---|
| 大学时，你深夜最常出没在哪个角落？ | 宿舍床上 / 图书馆自习室 / 操场跑道 / 食堂窗口 / 网吧 |
| 期末复习周，你的生存方式？ | 死磕课本 / 刷往年题 / 组团开黑边复习 / 临时抱佛脚 |
| 你大学吃宵夜的频率？ | 天天吃 / 一周三五次 / 偶尔 / 从不 |
| 如果大学能重选一次，你会加入什么社团？ | 乐队 / 辩论队 / 电竞社 / 志愿者协会 / 摄影社 |

**输出五件套**

1. **雷达图** —— 大学生活者画像：学术力 / 社交力 / 运动力 / 美食力 / 佛系指数
2. **时间轴** —— 模拟四年心情起伏线（「大一：以食堂为中心展开社交；大二：在宿舍和图书馆之间反复横跳…」）
3. **环形图** —— 时间去哪了：学习 / 娱乐 / 社交 / 干饭 / 睡觉 比例
4. **人群冷知识** —— 「比你更频繁吃宵夜的人只有 12%，你是深夜食堂的神秘部员」
5. **大模型个性化总结** —— 「王老师，你是一个『学术与干饭并重』的选手……你的青春关键词是：热气腾腾」

**本人陈述的核心竞争力**

> 结果属于评委本人。人类对自己的好奇心远大于对抽象数据的好奇。评委输入账号时，他看到的是「别人的数据」；但他亲手做出选择时，他看到的是「我自己」。这个「哦，这就是我！」的瞬间，就是全场最亮的那一刻。

## 二、为什么这个方案成立（检索依据）

### 2.1 它自己修掉了候选 ⑥ 的硬伤

候选 ⑥「公开 API 实时画像」的死穴是：**评委必须有对应平台的账号**。现场若无人有账号，演示当场冷场。

本人方案把「评委需要准备的东西」降到 **零** —— 不需要账号、不需要数据、不需要安装任何东西，只需要**回答问题**。而「回答问题」比「输入账号」的参与门槛更低、心理负担更小。

### 2.2 命中了已被验证的核心机制

Pudding Cup 2025 的获奖作品里，有一件是**作者分析自己 100 天的填字游戏记录**。它拿奖不是因为技术，是因为**分析对象是「我」**。

本人方案把这个机制放大了：**不是让作者看见自己，而是让评委看见自己。** 这个「我」的强度比前者高一个量级。

### 2.3 「人群对比」补上了「垂直社区」的定位缺口

「比你更频繁吃宵夜的人只有 12%」这一句，让产品从「一个人的测试」变成「**一个社区里的位置**」。方向 6 要求的「垂直社区」属性，靠这句话立住了。

## 三、三处接口的解决方案（原为风险，现已全部焊死）

### 接口一：五样输出，靠 6 个问题怎么算出来？

**采用：路径 B · 映射矩阵**（见 D-1 拍板）。

建立 **8 个潜在属性**作为中间层，每个选项同时影响多个属性；五件套全部由这 8 个属性派生。详细设计见 `docs/设计-01-问题与映射矩阵.md`。

核心判断：**输出分化度必须可验证**。因此自检脚本要跑「随机 5000 份答卷 → 两两输出向量平均距离」与「每维度取值熵」，低于阈值即判失败。这是防「千人一面」的硬闸门，不能只写在文档里。

### 接口二：人群百分比的基准数据

**采用：造 2000 条模拟问卷 CSV**（见 D-2 拍板）。

关键设计决策：**基准 CSV 存的是「2000 个人的原始作答」，不是算好的属性值。**

这样带来三个后果，每一个都是加分项：

1. 评审链路完整：**数据源（原始问卷 CSV）→ 计算（映射矩阵）→ 图表**，方向 6 要求的链路有了正式依据
2. 基准人群与评委本人**走完全相同的计算路径** ——「你的百分位」这个数不是查表得来的，是算出来的，口径必然一致
3. 数据层三件套（`parseCsv` / `validate` / `cleanData`）**100% 复用**

⚠️ README 与页面上都必须声明为**模拟生成数据**，不得暗示为真实调查结果。

### 接口三：评委在现场吗？

**采用：部署线上静态站**（见 D-3 拍板）。

| | 无线上链接 | 有线上链接 |
|---|---|---|
| 现场路演 | ✅ 可用 | ✅ 可用 |
| 线上材料评审 | ❌ 核心机制失效 | ✅ 评委自己答、自己看结果 |

线上版无大模型密钥时降级为**内置模板文案**，但「自己答完看到自己的结果」这个机制仍然完整。

## 四、「真入口」的定位（D-4 拍板：加，轻量）

评审权重中「解题有效性与实用价值」占 25%，纯娱乐向在这一项吃亏。因此加一层「真入口」：

| 入口 | 做什么 | 负责哪件事 |
|---|---|---|
| **快入口** | 回答 6 题 → 30 秒出个人报告 | 负责「亮」—— 评委现场玩 |
| **真入口** | 上传**批量问卷 CSV**（班级 / 社团的多人作答）→ 出**群体画像** | 负责「有用」—— 教师能看到一个班级的分布 |

「平行宇宙」的设定由此完整：**快入口是「我的」宇宙，真入口是「我们」的宇宙。**

真入口复用**同一套映射矩阵**，因此个体与群体的统计口径完全一致 —— 这不是巧合，是刻意的单一实现。

## 三、这段时间做了什么（11-06 → 11-10）

### 3.1 11-06 ｜体验与天气系统

- **钓鱼帧率 / 小车外观**：修钓鱼状态机「rAF 与渲染循环双推」导致的双倍速；小车两轮外观迭代。
- **天气与太阳系统**：新增 5 档光照（晴朗/薄云/阴天/杏金/暮色）+ 太阳方位滑块，带过渡动画；同步静态阴影烘焙。
- **交口共面 / 黑椭圆**：定位到透明贴片与路面深度差不足一个量化步长，改 `polygonOffset` + 压低贴片高度；**黑椭圆未消除**（如实留痕）。

### 3.2 11-07 ｜图书馆入口、公路与角标

- **图书馆门厅**：玻璃材质换成 `MeshPhysicalMaterial` + 高反光贴图，去掉近看像瓷砖的横向层线；门厅收窄、两侧补实体翼墙接回主体；雨棚收窄并给底面提亮。
- **第一人称补缝 + 几何衔接**：发现 `frame` 带约 90° 旋转，入口构件实际沿世界 +x 排开；用 AABB 量出主体与广场之间 **2.0m 断口**，把入口整组收回贴墙、基座跨接、台阶外推，做到零断口、标高单调下降。
- **构建角标同步**：发现 `BUILD 2026-10-31 22:06` 一直硬编码、发布脚本从不更新，导致无法确认打开的是不是新版 → 改为**发布时自动写入当前时刻**。
- **交口盖板删除**：用户指出「公路还是错的」——方盘只是把圆盘补丁换了形状，本质是往路上盖一块高出路面的面。删掉全部盖板，改由路段自身拼接。
- **环路四角（失败并回退）**：v16 的 miter 公式只钳下限没钳上限，生成 **24 个 13.5m 大方块铺满全图**；用户指出「所有地方都不正常」，已整体回退到 v13 基线。

### 3.3 11-08 上午 ｜公路裂片、闪烁与道路重构

- **v17 黑裂片 + 移动闪烁**：真因是 `length+.6` 让相邻段水平重叠 0.6m 且顶面同高 → 移动时 z-fighting，低视角还露出垂直侧面发黑。改回 `length` 精确相接。
- **v19 ribbon 重构（失败弃用）**：改成每条路一条连续 ribbon，但 miter 把拐角撑宽 44%、每条路独立 Mesh 又在交叉处共面闪烁、两套 UV 让虚线重复。判定失败。
- **v23 单纹理路网（结构解）**：**取消「拼接」概念**，整张路网用 canvas 一次画完（`lineJoin='round'`）贴到单一平面。期间依次修了 UV 翻转（多翻一次 flipY）、画布比例（横竖线宽不等）、Lambert 过曝（深灰被洗成白，改 `MeshBasicMaterial`）。

### 3.4 11-08 下午 ｜虚空、建筑闪烁、渲染精度

- **v24 虚空区域**：射线实测 36 个功能区域实体几何都在，真因是**支撑高度表**——`walkSurfaces` 只登记 `y>2` 高台，`floorAt()` 对广场/平台一律 `.04`，与渲染顶面 `0.32~0.88` 不一致。放宽登记 + `floorAt` 纳入平台顶面。
- **v24 建筑闪烁（覆盖所有同类建筑）**：实测 **500 对跨批次共面**（食堂、宿舍、实验楼、教学楼、综合楼、体育馆都有），历史 `resolveCoplanar()` 已缺失。按材质给确定性 `polygonOffset` 深度层级，13/13 共面材质组合全部分离；几何坐标一个没动。
- **v25 渲染精度**：实测静止也被判成「移动」（`waterTick` 常驻）、iframe 强制 low 档，画布只有 `1070×745`。修后回到 **dpr 2 / `1784×1242`**。中途用户以为「改错文件、树变形」，核对是刷新撞上旧缓存，两版全景几何完全一致。

### 3.5 11-08 傍晚 ｜MC 风格光影 + 去假太阳

- **v29 柔和写实光影**（用户三选一确认）：项目早有 `campus-post.js` 后处理链却从未生效——默认 `?post=1` 才开、`post.render(scene,camera)` **漏传第三参 `sunWorld`** 导致光轴恒 0、俯视时太阳在相机背后 `vis=0`。修复后默认开 Bloom + 调色 + 暗角 + 太阳光晕 + God rays，光轴改解析式太阳源 + 场景遮挡，背后/出画回退到右上天空柔和源（**艺术化处理，非严格物理**），daylight 换暖阳冷天光，UI 加「光影」开关。
- **v30 去掉假太阳**：用户确认新光影好看后，把 `paintSky` 固定右上画的 2D 白色圆盘（5 档 `sunDisc`）归零；保留 CSS 柔光与全部新光影。抬头对照确认圆盘消失、光轴调试通道仍是右上暖色光束。

### 3.6 11-08 ｜日志分离与入库

- 用户指出「3D 地图日志不是主站日志，注意分别好」→ 新建 **`docs/3D地图开发日志.md`** 作为唯一入口，主站 `开发日志.md` 顶部加范围说明与跳转，历史 3D 记录保留原处不迁移。
- `git commit b29dae5` 并 push 到 `origin/main`：147 文件，仅日志与 3D 证据；**剔除**了原本在暂存区的 `public/map/*.js` 三个源码改动（只取消暂存，未覆盖任何工作区文件）。

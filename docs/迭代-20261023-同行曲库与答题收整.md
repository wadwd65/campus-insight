# B-v39：同行、曲库与答题收整

用户反馈：答题页底部存在没有融入风格的大块白框；音乐短而重复；原来的小人不见了；题目还可优化，并询问动态角色的可行性。

## 改动

- 旧 `.quiz-draft-note` 白底来自 `ui-polish.css`，此前B版样式未清除。现明确覆盖为透明底，翻页区用切角淡灰面板，进度说明和键盘帮助收在同一底部区域；页面最底部隐私说明也清除整块底色、按答题宽度对齐。
- 恢复原来的 `art/mascot.webp`，新组件 `CampusCompanion` 独立于旧 `.mascot` 隐藏规则。支持呼吸、轻摆、点击招呼、收起与恢复、选答案后提供操作提示。消息只说本题切面和下一步，不回显账户、原始选项或推断人格。
- 角色动画只用CSS transform，不使用逐帧JS、实时渲染、视频或骨骼运行库。宽屏放在内容右侧空余处，普通屏和手机位于正文前的同行条，避免遮住答案与翻页。背景暂停、系统减少动态、窄屏省电和后台状态都令持续动作停止；静止时仍可点击回应。图片加载失败有符号占位。
- 当前是原立绘的轻动画，不是Live2D或拆层骨骼模型，未实现独立眨眼、口型或头部转向。完整可动角色需要分层素材及绑定，可作为后续工作。
- 四首自制配乐：校园夜航2:24、晨光刻度2:12、图书馆慢页2:36、晚风回廊2:20，总长9:32，MP3合计906216字节。不同和声、音色和节奏编排，不是同一段简单变速。默认关闭、点击才请求当前曲目；曲库支持上一首/下一首、顺序/随机/单曲循环和音量。后台暂停、回来不自动播放，切歌与取消的异步竞态受保护。仅一个audio元素。
- 题干改为更具体的校园情境，每个选项增加解释，明确复习方法、费用情况、活动形式等。`questionPresentation.js`保存展示文字；原题库字段、题干备份、选项值、向量、矩阵版本1、CSV和模拟基线均保留。没有借改文案重新解释旧答卷；此轮也不声称题库已通过心理测量验证。

## 验收

完整 `npm run check`，含SSR103项和B版契约8项。离线React交互10项覆盖暂停/媒体失败/连续播放/随机与单曲/切歌竞态/同行展开收起/答题回应/底部白底的计算样式；另5项覆盖试玩、十题手动确认及真实PNG导出。数字音频解码检查确认时长、波峰和非静音，并记录SHA256。

这些是逻辑、DOM、CSS计算与数字音频检查，不能代替浏览器布局、实际扬声器听感、真实帧率或用户回访。浏览器此前受URL政策限制，没有用其他浏览器或调试协议绕过。

## 保存与运行

A-v37和B-v38封存在比赛包21目录，保持不变。当前B-v39继续在独立B工作目录开发，预览5198，使用原来的B测试数据目录；A预览5191及其真实账号/答卷不动。正式部署、完整视频和比赛提交仍由实际流程验收。源码和运行包不含私有环境、真实数据库、密钥、音频工具依赖或node_modules。

音乐生成脚本复现时可安装numpy和soundfile==0.13.1；发布文件已经编码，站点不需要Python、音频编码库或外部音乐服务。旧64秒WAV在封存B-v38中，本版不重复分发。

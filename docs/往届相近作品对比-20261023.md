# 往届相近作品对比 · 2026-10-23

## 判断

Campus Insight v32属于完成度较高、具备参赛竞争力的小型全栈MVP。它已经超过只做首页、静态图表或聊天框的展示型原型；但现有证据不足以宣称领先往届国一，更不能把内部80～86分预审区间当作排名或获奖概率。

相对优势是可实际走通的邀请收卷、规则可追溯、换答预览、明确的来源/同意/小样本边界、可交接的本机部署与恢复。主要短板是实际效益尚未被真实班级验证，产品叙事横跨个人趣味画像、班级收卷和3D参观，完整公网、真实多设备与最终同版视频还没完成。现在继续堆装饰或为了数量硬加AI接口，收益小于把已有闭环证明清楚。

## 比较依据与限度

用户提供了第八届作品合集截图和WPS链接，随后明确同意改为直接搜索公开作品，不继续处理网盘。对比选取3个同类AI Web公开作品及1份能核实国赛一等奖的高校展示。这里只评公开可见证据，不下载或运行他人程序，不比较无法取得的源码质量、后端权限或模型准确率。B站部分演示未能稳定读取/播放，因此其功能列仅采信作者公开简介，不能写成已完整观看视频或已实操。

不同赛道可借鉴呈现质量，奖项与技术要求不能直接互换。2026年10月9日高校转发的赛道通知，将个人“AI创新应用”描述为AI编码与人类意图引导，将团队“AI Web”另列为AI驱动前端应用。它支持两者侧重点不同的判断，不足以替代报名系统当前完整细则，也不据此断言某个接口绝对必做或必不做。[通知来源](https://bgs.zjtu.edu.cn/content/ggtz/202610/2256.html)

## 我们现在处于什么水平

| 方面 | 判断与证据 |
|---|---|
| 视觉 | 现有森林绿、暖纸与校园插图风格完整，移动端可用；与所见国一后台截图相比没有明显“页面做不出来”的差距。属于主观视觉判断，不能推导总分高低。 |
| 功能 | 本机实际走通个人测评、规则解释、多人邀请填报、管理员原始答卷/汇总、导出与交接，属于可用MVP。业务广度小于作者简介中的大型内容/社区平台；功能多不等于验证充分。 |
| 可信度与工程 | 自己的检查、隔离账号操作和包校验有记录；模拟基准与小样本边界明确。我们可以证明这些自身行为，不能凭公开简介断定比他人的后端更安全或工程更强。 |
| 实用价值 | 省掉逐份传CSV的操作路径已实现，真实节省时间、班级使用效果尚无数据。与目标单一的农业检测案例相比，当前更需要证明“为什么要用”。 |
| 参赛呈现 | 还有同版仓库同步、完整公网/多设备与最终视频缺口。这些会影响评委能否复现已有功能，优先级高于新增模型接口。 |

## 最划算的最后三件事

1. 视频先走一条实线：管理员邀请→成员十题→确认提交→管理员直接收到→逐题人数→解释贡献。3D自由参观放在末尾十几秒，作为表现力补充。
2. 找少量真实新用户完成同一任务，记录是否迷路、是否完成与实际用时；不要把代理测试和48人合成示例写成真实班级试用。
3. 用同一版本源码包、运行包、截图与视频送审。公开旧静态站和旧Git HEAD不能冒充当前完整服务。

本报告没有给获奖承诺，没有把API接入数量当质量分，也没有使用他人素材替换本作品资产。

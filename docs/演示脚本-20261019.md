# 6 分 30 秒演示脚本（录制草稿）

本脚本按已提供的赛题资料安排：MP4、1080p、5-8 分钟，其中至少 2 分钟呈现 AI 协作。当前尚未录制，不得把脚本当成视频完成证明。

| 时间 | 屏幕操作 | 讲解重点 |
|---|---|---|
| 0:00-0:25 | 打开首屏，停留在标题与示例 | 个人不需要先有表格；班级数据也能在同一套规则下分析。用校园选择建立参与感。 |
| 0:25-1:00 | 切换自习派、探索派、松弛派 | 示例通过正式计算路径生成，明确标注不是用户结果；基准是模拟记录。 |
| 1:00-1:45 | 完成十题；必要时演示上一题与恢复 | 不是考试，没有标准答案；页面减少等待，刷新可恢复本标签页进度。 |
| 1:45-2:15 | 查看称号、三项读数，保存 PNG，导出答题 CSV | 区分“能分享的成品”和“能用于班级汇总的数据”；每个数字与报告同源。 |
| 2:15-3:00 | 导入 48 人示例 CSV，查看质量卡和班级画像 | 48 条有效，0 条剔除，学术型 12 人、25%；说明中位数与 Q1~Q3。 |
| 3:00-3:30 | 下载统计摘要；简短展示地图一到两步、撤销 | 摘要不含个人作答；可选地图展示取舍，不阻塞两条主线。 |
| 3:30-4:15 | 展示真实对话、最初页面与首屏改动 | 从“立即吸引注意力”的需求，到直接入口、可切换示例和结果揭晓。保留真实上下文。 |
| 4:15-5:15 | 展示派生维问题、定位代码和修复 | 八维账本漏算派生值，导致默认 50；统一计算边界后，与原问卷一致。不要重新摆拍成从未发生的对话。 |
| 5:15-6:00 | 展示地图撤销、回归检查、npm run check | 解释如何约束 AI：不硬编码百分比、不引入地图源码、不破坏数据契约；验证实际行为而非只看编译成功。 |
| 6:00-6:30 | 数据流与范围说明 | 当前本地规则解读；在线模型未验证。说明模型只写受约束文字，时间曲线为推算，不是心理评估。 |

## 录制前准备

1. 使用干净标签页和正常桌面宽度，先确认 `npm run check` 通过。
2. 准备本轮真实对话或原工具导出，与至少三条核心功能的完整原始 Prompt 链。当前 `prompts/` 中的整理稿不能代替原始链。
3. 若已配置真实模型，补录流式生成与失败回退；若未配置，保持“本地规则解读”的真实状态，不改标签假装在线调用。
4. 个人 PNG 与班级统计文件已经能下载，可在录制中现场打开核对。
5. 本脚本不要求重新开发额外功能；优先讲清输入、计算、结果与一项有证据的真实修复。

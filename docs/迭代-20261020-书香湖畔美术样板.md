# 书香湖畔美术样板

日期：2026-10-20。当前是局部样板，范围为图书馆与一段湖岸；尚未扩展到整个校园。

## 用户确认的方向

用户指出原地图与真实校园有多处不符，随后选择“先做好看的校园示意图，明确标注非真实布局”。本版因此采用艺术化布局，页面顶部、侧栏和建筑说明均明确示意属性，不提供真实导航，也不宣称还原了图书馆外形。

## 本轮实现

- 图书馆改为暖石色双翼、玻璃中庭、错层屋面、入口雨棚、台阶和花池；窗带与建筑标识采用共享贴图。
- 湖岸增加木栈道、观景平台、栏杆、长椅、花带和 7 棵多树冠样板树；保留低成本湖面纹理与柔和接触阴影。
- “书香湖畔”取景同时展示图书馆与栈道；选择图书馆可查看说明和近景。
- 继续使用实例化、共享几何和按需渲染，默认关闭自动环绕。手机关闭 3D 的分流逻辑保持不变。
- 修改集中在 `map-src/web/`、地图生成脚本和对应检查；`public/map/` 与 `dist/` 已重新生成。主要问卷、报告、四时段行动账本未因本轮调整。

## 参考素材与边界

用户提供了 720yun 链接和本机 5182 素材服务。720yun 页面显示扫码广告/解锁入口，本轮没有完成广告解锁，也没有取得清晰的完整全景；未支付、未绕过访问限制。

实际查看了本地 `map-assets/official-360/overview.jpg`、`outdoor/27837116_d.jpg`、`outdoor/27836784_d.jpg`，并参考其中的蓝灰色金属屋面、暖色墙面及灰色铺装。照片未复制进网站，材质由 Canvas 程序生成。现有照片不能确认图书馆的完整外形，样板建筑仍属概念设计。

## 验证与性能

最终 `npm run check` 退出码为 0，共 612 项离线断言通过，其中地图 14 项。新增两项验证示意声明、样板拾取映射、树干不落入湖内及输入数据不被改写。原坐标测试仅修正了不适合当前目标的标题，断言未放宽；对象不超过 32 批、实例不超过 1500、三角形不超过 25000 的原预算保留。

生产页面实际记录：29 次绘制、19,970 个三角形、11 份几何、12 份贴图，场景 1172 个实例。桌面地点下拉选择与图书馆说明正常，控制台未见 error；相邻两次空闲读取帧计数均为 39，符合停止重绘的预期。数据不代表所有设备上的固定帧率。

手机分流离线检查通过；上一版已做 390×844、320×568 浏览器模拟。本轮尝试新的尺寸模拟时，测试页实际仍为 1280×720，因此不把该次操作记作新的手机视觉验收。没有真实手机硬件测试。

`git diff --check` 通过，仅提示已有工作区文件的换行符规范化。最终 dist 共 49 个文件、3,383,381 字节。检查日志及改前备份位于 Codex 工作区 `work/`，不随站点部署。

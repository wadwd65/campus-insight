# 第三方依赖与素材署名

本项目从零组织校园问卷、规则计算、报告、圈子收集和地图交互，没有将一个现成的完整应用改名后参赛。开发使用 AI 辅助；基础库、运行环境和外部素材属于其原作者，不宣称由本项目原创。

本轮整理启动、复现和提交材料，补齐公开仓库的署名与许可文件，不增加业务功能。本版未配置在线大模型服务，个人文字解读由本地规则生成；AI 协作开发记录与在线模型接入是两件不同的事。

## 基础库与运行环境

主要复用 React、Vite、ECharts、Zustand、Papa Parse、Framer Motion、tsParticles、Tailwind CSS、Three.js 以及 Node.js。具体依赖名称、版本和许可字段以 [依赖清单](第三方许可/依赖清单.json) 与仓库根目录 `package-lock.json` 为准。

[依赖许可目录](第三方许可/依赖许可/) 保存原包收录的 119 份许可证原文；依赖清单记录 173 条依赖条目，两者计数口径不同。许可证中的版权人、联系方式和原始条款原样保留。后续更新依赖时，需重新核对锁文件与许可材料，不把本目录当作永远适用于所有新版本的授权。

独立 3D 页面内嵌 Three.js r149，原文件已保留版权与 SPDX 标记。本轮另补齐 [r149 的完整 MIT 许可](第三方许可/three-r149-LICENSE.txt)，来源为 [Three.js 官方 r149 标签](https://github.com/mrdoob/three.js/blob/r149/LICENSE)，不将其算入上面的 119 份历史依赖许可。

Windows 即用包如附带 Node.js 运行时，应同时附带 [Node.js 完整许可](第三方许可/Node.js-LICENSE.txt)。系统字体仅由用户操作系统提供，本仓库不分发字体文件。

## 网站内的九首音乐

网站使用既有录音，不将其声明为本项目原创。五首作品按既有 CC0 来源记录使用，四首国内作品保留黑耀作者的 CC BY 4.0 署名。作者、作品页、许可链接和处理说明见 [音乐来源与授权](第三方许可/音乐来源与授权.md)，文件摘要、时长与修改记录见 [music-credits.json](第三方许可/music-credits.json)。

这些音乐作为网站功能的一部分提供，不另外制作独立音乐素材包。视频另行选用的配乐，应以视频交付包中的署名清单为准，不能用网站曲库清单代替。

## 图像、地图与数据

角色立绘和界面场景沿用项目既有 AI 生成资产。已保存的生成方式和后处理记录见 [历史图像生成记录](第三方许可/历史图像生成记录.md)。该文件是早期记录，其中“未使用第三方音乐”等表述仅描述当时状态；当前音乐范围以上述九首曲目清单为准，不将历史记录改写成当下的完整素材审计。

3D 校园布局参考公开导览资料，建筑与位置为人工标定的艺术化表达，不宣称精确测绘、数字孪生或官方导航。既有布局、照片和底图参考链接仍保留在源码及相关开发记录中。

问卷基准的 2,000 条记录与班级示例的 48 条记录为模拟生成数据，并非真实学生调查。交付包不包含用户账号库、私有填报、API 密钥、报名个人材料、图像模型权重或配音模型权重。

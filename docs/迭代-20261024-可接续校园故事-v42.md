# B-v42 · 从一次性体验到可接续校园故事

用户反馈：自己也不想第二次进入，答题后缺少继续玩的理由。本轮完成此前中断的拖动和彩蛋，并制作一条完整的校园故事支线，供真实用户再测。

## 可以怎么玩

主页右侧打开“晚风放映计划”，或直接访问`/#/story`。故事无需测评或登录，也不等待基准数据加载。报告页在圈子提交区域之后保留接续入口，从报告进入后返回会回到本轮报告。

第一幕在设备、场地与朋友之间选一条准备路线；第二幕带回具体资源；第三幕根据已有资源改变放映方案；第四幕决定如何通知同行的人。每次行动先展示后果，确认继续后才到下一幕。没有真实倒计时，也不逼用户当天回来。

四种可到达收尾：白墙首映、雨棚下的加映、没有电影的首映、一张留到下次的票。提前准备会实际开放或关闭部分方案，最后的邀请也改变结尾文字。收藏只记录实际走到的结局，换路重玩保留已发现收尾；途中重开需要明确确认。

随时离开会保留当前幕、反馈阶段和路线。重新打开主页能看到“接着上次”的入口。匿名与不同账号按浏览器存储作用域隔离，登录后不自动合并匿名进度；剧情没有云端同步。存储被禁用或满额时明确提示不能保存，但仍可完成当次体验。损坏或不兼容进度会安全回开场。

剧情是虚构的校园支线；其时间和资源均为剧情信息。没有把故事选择写进问卷答案、矩阵、CSV、百分位或管理员收卷。浏览器仅保存剧情版本、动作ID、是否等待继续、已发现结局，不保存报告或原始作答。

## 同行与原彩蛋

立绘支持鼠标/触摸pointer拖动、方向键微调、Home或“归位”复位，保留位置偏好。拖动阈值6px，手势结束产生的兼容click不进入彩蛋计数。pointer取消、捕获丢失和窗口失焦均可结束手势。

恢复原滑动60秒内10次点击彩蛋，保留真实趣评计算、无数据兜底、问卷CSV下载/去答题/行动报告动作。切换账号或数据后清除旧彩蛋。彩蛋保留至关闭，方便阅读。收起时不会再把38px按钮的尺寸写成472px立绘的保存比例；折叠后刷新回归已覆盖。

## 范围与验收

当前只有一条完整支线及四种收尾，不声称已有无限剧情或持续内容更新。它提供未完成时的接续理由和完成后的分支重玩理由，是否真正提高二次体验意愿仍需真人测试。

保留A和已封存B-v38/v39/v40，v41中断开发由本版收尾。四首现成CC0场景配乐沿用v40，默认静音及暂停意愿不变。原矩阵1、账号权限及提交前同意流程保留。

完整check、边界/分支测试、离线React事件和公开HTTP核对见对应验收记录。离线DOM的几何、pointer capture和媒体被模拟，不代表真实浏览器鼠标/触摸、视觉、听感或留存率验收。原浏览器URL限制仍遵守，没有换工具绕过。未新增公网部署、Git推送、视频或赛事提交。

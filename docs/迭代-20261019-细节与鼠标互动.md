# 细节与鼠标互动

延续独立入场片头和固定排版，增加轻微、可发现的装饰互动。

## 变化

- 新增原生 SVG 书页、星轨、罗盘星与星点连线。它们位于文字之外，装饰层不接收点击、不进入无障碍阅读顺序。
- 桌面鼠标移动时，装饰按不同方向与幅度产生轻微视差；中央纹章轻微倾斜，柔光跟随鼠标。标题、说明和按钮的布局不参与视差，原生鼠标指针保留。
- 中央纹章是可操作的原生按钮。悬停出现提示，点击或回车可点亮暖金色光晕，再点一次恢复；`aria-pressed` 表达当前状态。此互动仅改变视觉，不修改问卷或地图数据。
- 按钮补充边框、光泽、箭头与按下反馈。主页延续淡绿色纹样，示例档案的衬纸有约几像素的响应，正文保持稳定。
- 鼠标离开、窗口失焦、页面进入后台或动态效果设置变化时重置视差。组件卸载清除全部监听和待处理帧。
- 768px 以下、触摸 / 粗指针设备和减少动态效果模式关闭鼠标跟随。手机保留精简静态纹样，仍可点击纹章。
- 不新增依赖、位图或外部资源。鼠标事件在一帧内合并，只在有输入时更新；柔光使用小尺寸渐变层的位移，没有全屏实时模糊。

## 验证

完整 `npm run check` 退出码 0，579 项离线检查通过。新增鼠标互动测试覆盖帧合并、位移上限、离开复位、触摸降级、动态效果设置变化、后台复位和卸载清理。在线模型验证仍明确未执行。

浏览器实际检查：

1. 鼠标分别移到左右区域，横向输入约为 -9.57px 与 +9.37px，装饰实际发生移动；标题与进入按钮的 x / y 坐标一致。
2. 点击纹章后 `aria-pressed` 为 true，出现暖金色光晕与提示；键盘 Enter 可切换，Escape 可从纹章焦点退出片头。
3. 390×844、320×568、650×720 检查无横向溢出。320×568 下进入按钮底部为 534px；650px 下纹章按钮与 SVG 均为 82px，尺寸匹配。
4. 手机宽度下柔光层为 display:none，鼠标跟随未激活。
5. 最终生产构建完成「片头 → 跳过 → 十题 → 个人报告」和「主页 → 选择本地 CSV → 48 人群体页」两条主线，控制台未记录错误。

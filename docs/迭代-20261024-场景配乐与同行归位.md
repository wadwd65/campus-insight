# B-v40 · 场景配乐与同行归位

用户反馈上一版角色位置奇怪、太小，配乐情绪相似且偏伤感。本轮保留A-v37与B-v39，继续修改当前B预览。

- 同行恢复固定在右下角，桌面立绘138×472，脚部贴近页面底部；可收起、恢复和关闭提示。窄屏按比例缩小，减少动态/后台仍停止持续动作。不是骨骼角色。
- 替换四首合成配乐，改为四首作者在各自作品页标注CC0的现成录音。完整来源、作者、处理方式、时长和文件SHA256见`音乐来源与授权-v40.md`及`public/audio/music-credits.json`。
- 默认跟随页面场景：主页和圈子为Happy Moments；答题、数据整理为Synthwave 4k；报告为Vaporware；主站行动地图为Happy Beat。地图独立3D窗口不自动继承播放，避免两个窗口叠音。
- 选曲或上下首切换为手动模式，支持顺序、随机、单曲，随时可重新开启跟随场景。在同一阶段循环当前配乐，避免答题中途换成热闹节拍。
- 默认静音；主动点音乐才加载当前一首。暂停或切到后台后，页面变化不会自行恢复音乐。切歌复用单个原生audio，不引入音频合成器和额外逐帧循环。
- 根据页面切换，不读取答案判断情绪。原题库字段、矩阵1、CSV、账号和同意后提交圈子的流程保持。

运行包中包含本地MP3，不需要连接来源站点；可在顶部曲库查看署名和来源。主站和3D地图的体积预算独立于按需音乐，不放宽原核心代码体积限制。

验收以记录为准。离线媒体API模拟能验证按钮、切歌、后台暂停及竞态，不能证明真实扬声器听感、浏览器布局或帧率。浏览器原URL访问限制继续遵守。

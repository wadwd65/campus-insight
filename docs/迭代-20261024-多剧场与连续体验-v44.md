# B-v44 · 四段小剧场，把故事接回真实日常

## 从新用户顺序发现的问题

之前首页虽能进入故事，但只有“晚风放映计划”，不同路线仍围绕同一场电影。结束按钮直接把用户送入普通问卷，题目回应也按整题复用；报告又推回同一故事。地图、圈子和CSV有自己的用途，却没有交代与当前体验的关系。加背景和音乐不能补上这些内容与流程断点。

## 本轮成品

- 四段完整虚构剧场，每段四幕、约2–4分钟。电影救场保留四个结局；新增“17号失物柜”（调查核对）、“旧物复活夜”（资源与修复）、“今晚的空白电台”（声音采集与编辑），各三个结局，共13种。所有合法路径共116条，准备物品/线索影响下一幕哪些方案可用，每幕至少两个可行选项。不是116段完全不同的原创剧本，而是共享节点的116条完整选择路径。
- 首页直接展示四种题材；故事页可以随时换段，每段、每个账号独立保存。当前选中的剧场也在本机记住；重新开场只清本段本轮路线，保留本段结局收藏。v42/v43电影存档原键与原字段继续可读，存档版本仍为1。新剧场另加episodeId并使用独立键，不覆盖老故事。无法保存时诚实提示，当次仍能玩完。
- 三段新故事有各自SVG场景：失物柜与钥匙、旧收音机工作台、ON AIR广播台。选择触发相应消息、图纸、票券、声音等轻量反馈。沿用v43九首本地授权配乐、场景跟随、用户手动优先、默认静音、后台暂停与减少动态设置，没有新增逐帧脚本或素材请求。
- 故事结尾的主要下一步改成“带着这一幕，写我的日常”，也能直接开始另一段故事或重走本段。只传递白名单剧场ID/结局ID，虚构选择不代填、不参与真实报告计算。
- 十题改成十个具体镜头，五站都有当前剧场的现实引子；每个选项有不同的生活回应，相邻两题会保留前题实际所选内容。四个剧场共20条站点引子。实际题目范围仍是到课、复习、生活费、宵夜、兴趣、运动、夜间地点、应对、相册与记忆。原矩阵、字段、选项值和2000人模拟基准保持，不把这一轮包装成新心理量表或已重建统计模型。
- 暂停后继续：本标签页原真实答案和题号恢复，故事引子也一起恢复；旧草稿仍可读。圈子答卷不包含故事字段，提交仍需单独同意。正式填报可以跳过全部故事。
- 报告新增连续体验区，带回剧场收尾，并从本次有效真实答案中展示兴趣/运动/记忆三帧。下一步可进入行动地图、返回原剧场或开始另一段。地图显示来路，往返剧场不清地图账本；再生成报告仍能接住本次行动。
- 登录/注册、圈子填报、CSV分析和48人模拟汇总继续按原职责工作，入口仍可直接使用。它们不是必须逐一完成的关卡；3D参观仍为独立体验，不虚称与剧场剧情联动。

## 验收与边界

完整npm run check通过；新增模型验收8项穷举116条路径，覆盖13种结局、资源条件、旧存档兼容、四段隔离、坏数据、禁用存储、答案边界、逐选项回应与暂停恢复。

真实App离线整站8项：使用实际App路由和懒加载页面，从首页进入失物故事，完整结束后答题，暂停/续答、生成实际报告、换另一段故事并返回、去地图入账、返回原剧场再回地图，最后再次生成报告；同时核对圈子登录/注册入口、CSV和模拟班级。仅使用合成账号响应和本地公开CSV，没有访问真实账号、数据库或密钥。旧故事8项、雨幕音乐8项、立绘与彩蛋12项、答题/实际PNG导出5项回归通过。

离线环境模拟浏览器几何、媒体、dialog和系统查询，图表使用本机画布后端。它证明真实组件动作和数据衔接，不等于浏览器布局、扬声器听感、FPS或复访率验收。图表已有grid.containLabel迁移提示不在本轮改动范围。尊重原浏览器URL访问限制，没有换工具绕过。

程序可刷新5198体验，旧A/B版本保留。没有部署公网、推送仓库、合成最终视频或提交赛事。实际趣味性仍需测试者试玩验证，尤其观察是否主动打开第二段、是否愿意完成现实回声，以及报告后的下一步是否清楚。

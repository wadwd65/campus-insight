# v12：校园色调、静态投影与已解锁全景核对

日期：2026-10-20。用户要求地图增加色调与光影，明确仅需静态阴影，避免动态卡顿；随后由用户自行完成720yun解锁。位置继续沿用已确认的v10导览图，34个地点的锚点、比例、旋转、路网与湖界均未改变。

## 画面与性能实现

- 增强蓝灰屋面、暖砖与分层绿色的关系；新增“晴日校园”和“暖金傍晚”，在“画面与操作 → 校园色调”切换。色调通过光源、曝光、材质颜色调整，不替换几何、反复分配纹理或引入后期滤镜。
- 楼体、屋面与树冠共297个投影体，采用方向光投影到地面，合成到一张1024²透明阴影贴图；197个原接触阴影也合入该图。替换原分散接触阴影批次，不增加原绘制对象上限。
- 关闭所有画质档的实时shadow map。启动时只生成一次固定投影；转动、缩放、切换画质、切换色调、显隐阴影均复用贴图。
- 日光滑块仅在change提交时重新生成阴影，不在渲染循环或每个pointermove中重算。无自动昼夜轮转，自动环绕仍默认关闭。
- 投影层不参与拾取、不写深度，与建筑共享场景深度遮挡，退出时释放贴图、几何和材质。省电档仍可显示这张静态投影。手机仍不加载3D。

这是轻量地面投影，未做逐屋面互相遮挡、真实日照分析、光线追踪或动态软阴影。太阳角度和色调是展示参数，不代表校园实测光照。

## 360全景证据更正与新增细节

早期只读到页面标题、canvas与广告遮罩，不能据此声称看见全景。手机尺寸测试仅改变视口，没有改变UA，页面仍显示“广告仅解锁10个场景，不支持电脑端观看”。付款、认证由用户自行完成，本轮没有操作支付、绕过访问限制或代解验证码。

用户告知已解锁后，实际截图可见校园、球场、建筑及场景缩略图，遮罩消失。页面随后持续自动漫游，导致点击场景名与稍后截图的实际场景可能不同。因此，不将“点了教学区”当作已完成教学区图像核对；部分工作区截图文件名也不能充当场景身份的证据。

采用[实际标注9栋与10栋的全景帧](map-review/全景已解锁-公寓9与10栋-20261020.png)作为本轮新增外观依据。该帧是在保持鼠标操作时截取，楼号、双坡屋面、浅色山墙、上部深灰蓝立面与浅色窗框可见。

- 9、10栋增加单独的双坡屋顶分支；其他公寓继续使用原有屋顶，未强制全部套用。
- 公寓立面图集补上深灰蓝上部与浅色窗框，保留下部暖卡其墙、阳台和服务露台。
- 白色山墙与蓝灰金属坡面共用一张屋面图集；实例化双坡几何不逐瓦建模。
- 参考表增加9、10栋的可见外观记录，仍明确楼翼长度、背面与精确对称关系未实测。不能据此宣称全校全部建筑已逐栋完整还原。

完整全景照片与付费画面没有放进public或dist；私有工作记录中的截图仅用于本次核对。已解锁标签页保留，不刷新或重新创建来替代当前会话。

# v30 · 登录注册分离与6～12位密码

2026-10-22。用户要求独立的登录、注册入口和更简单的表单。

原因：`setupRequired` 原来覆盖表单模式，站点尚无账号时，登录入口被“创建首位管理员”强制替代。现在登录、注册始终可切换；默认登录，邀请链接可直接打开注册，但已有账号仍能切回登录。

登录只需要账号和密码。新注册及修改密码要求6～12位，纯数字也可；显示名称选填，留空默认账号名；自动带入的邀请码不重复展示输入框。首次站点创建仍需一次私有初始化口令，成员注册仍需邀请。

服务端与前端均校验新密码长度，拒绝5位/13位。已有12～128位历史密码可照常登录、验证当前密码并修改为新规格。数据库哈希格式、会话、邀请和圈子权限没有迁移，不重置已有数据。

桌面立绘在未登录圈子页改到左侧，避免遮住密码显示和提交按钮；手机沿用隐藏装饰及表单优先布局。

验证：完整npm run check通过，账号53项、部署26项、Windows真实CMD和导航专项通过。最终补充前端长度反馈/立绘调整后，SSR、构建及隐私检查再次通过。合成账号浏览器实测6位注册、12位邀请注册、已有账号无邀请码登录、邀请页切换登录、5位错误、切换清错、显示密码及刷新保持；390×844无横向溢出。测试站使用localhost，主站127.0.0.1账号和数据未改。

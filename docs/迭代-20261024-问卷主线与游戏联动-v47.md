# B-v47：问卷是根本，游戏选择参与问卷

用户指出 v46 把地图游戏提成主线、把问卷藏在折叠区，走完后只有路线回顾，原来的个人判断与图表没有自然接上。又明确纠正：不能简单恢复两个互不相关的入口；应该让小游戏选择影响调查问卷。

## 最终流程

首页提供“填写校园问卷，生成我的档案”和“先在地图里选择，再带入问卷”。两条路最终进入同一个十题问卷、同一份个人报告、同一个圈子确认提交流程。

地图行动发生时，会显示它关联的问卷主题和建议。例如合奏关联乐队，跑步与旁观关联不同的运动选项。可以走完整天后带入，也能中途带着已有选择进入问卷。问卷逐题显示行动来源、带入建议及限制，允许修改。已有草稿优先保留，不被新游戏覆盖。

一次晚饭不能推断宵夜频率，模拟餐券不能推断家庭收入，因此这些题保留待答。没有有效对应项的其他题也不补造答案。用户逐题核对、补齐后才生成报告；最终评分只按十题原矩阵计算，不再额外累加新游戏地点分数。结果页显示完整“游戏行动 → 最终回答”记录，能区分沿用建议、自行改答和亲自补充。

原三维参观、旧行动地图和额外故事仍保留；新游戏结果不再套用“地点向量 → 原问卷2000条基准”的个人报告。游戏路线小记仍可保存。正式问卷原字段、选项、矩阵版本保持兼容，提交圈子只发送最终确认的十题，不自动上传路线或暂存建议。

## 报告修复

- 十题完成后直接显示本地个人解读、雷达、时间倾向、曲线和实际回答记录；不需要在线模型。
- “换个回答”展示完整计算预览。确认应用后，主图、文字、记录和导出一起更新；原圈子答卷不自动覆盖，共享确认重置。
- 雷达浮层逐轴显示模拟百分位，修复原来把整段数值数组当成单个百分比的问题，去掉“真实大学生排名”的误称。各百分位不相加。
- 时间图采用同一份已归一化、修正舍入的数值，图标签和浮层不再二次取整。五类合计100%，是固定规则估算而非实测时间。
- 已完成的十题及经校验的游戏来源暂存在当前标签页，可从首页重看，刷新仍可恢复。退出或切换身份清除上一身份结果，不存密码、密钥或任意扩展字段。禁用存储时当次计算仍可用，但无法保证刷新恢复。

实际 React App 离线交互覆盖：直接问卷、完整地图十选择带入、逐题核对与改答、报告来源记录、主图和复制文本更新、刷新恢复、管理员准备交卷、改答重置共享确认、无自动网络写入。DOM几何、dialog和媒体模拟，因此不代表浏览器布局、移动设备、真实听感或公网新版验收。

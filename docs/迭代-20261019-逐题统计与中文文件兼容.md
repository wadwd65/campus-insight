# 2026-10-19 继续迭代：逐题统计与中文文件兼容

## 产品变化

群体画像原先只能查看属性百分位和规则分组，很难回答「这道题大家究竟怎么选」。现新增逐题作答分布，放在班级概览后、模拟基准雷达前，优先呈现文件中直接可核对的事实。

- 可切换十道题，显示每个选项的人数和占比。零人选择的选项保留，并列最多时全部列出，不强行选出一个第一名。
- 柱形长度的分母为该题有效作答数，与模拟基准无关。示例数据依然明确标注为模拟数据。
- 可导出十题汇总 CSV。每行是一个选项的统计，含题目、选项、人数、占比与本题分母，共 48 行。没有个人编号、原始行号或逐人作答记录。
- 文件读取兼容 UTF-8、GBK / GB18030、带 BOM 的 UTF-16LE / BE。不同编码分别解码后按列名合并，界面显示识别到的编码。
- 误选 XLSX / XLS 工作簿或 PDF 时，给出针对文件类型的转换提示。损坏编码不静默转换成替换字符。单文件仍限 5 MB，新增每批合计 10 MB 限制。
- 首屏示例的雷达顶点在 460ms 内平滑过渡，快速连续切换会从当前形状接着过渡。没有持续的额外动画循环；系统减少动态效果开启时直接显示最终形状。
- 群体页章节改为二级标题，修正相似度说明：按八个基础属性计算，派生维度不重复计权。移除 JSX 文案里直接显示的 Markdown 星号。

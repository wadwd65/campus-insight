# v34 自主注册、档案提交与便捷启动

日期：2026-10-23。本版本承接v33，调整了用户在练习中发现的三个流程问题。

## 用户现在怎样使用

1. 网页始终分开登录与注册。注册选择“创建圈子，我当管理员”，自设账号和6～12位密码，自动创建自己的圈子。不再要求查找初始化口令。选择受邀加入时仍验证邀请码，权限仅为成员。
2. 已登录用户从首页答完十题，“我的档案”直接显示“提交到我的圈子”。一个圈子时直接继续核对，多个圈子时先明确选择。沿用本次答案，无需重答。阅读共享说明、勾选同意后才提交。
3. 管理员自己的填报入口直接显示在工作台，不再藏在页面底部的折叠区。
4. 管理员包最外层提供“开始使用.cmd”“备份我的数据.cmd”“打开数据文件夹.cmd”和“先看这里.html”。本机试用无需先填写端口或监听地址。正式服务器配置仍放在deploy进阶入口。

## 数据与权限

已有账号、密码和答卷沿用原私有数据库，无需迁移。注册成为管理员只获得自己圈子的权限，不是全站管理员，不能查看其他圈子的答卷。圈内共享仍须用户确认。新的空站点不生成setup-key.txt。旧的显式配置setup接口仅保留兼容性，当前网页不调用它。

便捷启动工具不改写现有.env.local，不重置数据。已配置正式网站时，它提示使用正式启动方式，避免把正式站点误改为本机模式。初始化口令不再属于普通部署流程。

## 交给另一位部署者

请使用v34完整管理员包，参照“给部署者的交接.md”。部署账号后台需要Node服务与私有持久磁盘，仅静态发布不能提供圈子账号。国内云部署继续由用户指定的另一位AI负责，本轮不代表已经上线。

## 本地验收依据

新增自主注册与管理员本人提交的隔离接口检查，覆盖首位与后续管理员、跨圈隔离、邀请成员权限、共享确认和重启保留。渲染检查覆盖档案页显式提交按钮、核对表单和未同意时禁用。

检查结果、运行包哈希与启动实测记录随本轮交付提供。当前浏览器工具因URL策略无法操作本机页，未把接口或SSR检查记作真实浏览器点击验收。用户在5191预览刷新后可进行实际练习。

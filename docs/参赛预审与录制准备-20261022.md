# v29 参赛预审与录制准备

用户要求按比赛评分标准优化网站 UI、登录入口和动效，准备今晚录视频与预提交。随后明确暂时没有 AI 协作录屏，先准备录制素材；项目由两个 AI 完成，另一边原始记录将另行提取。因此本轮交付为网站修订版与可审阅材料包，**尚无最终 MP4 或比赛提交回执**。

## 已完成的网站修订

- 统一森林绿、暖纸白与低饱和金色；账号入口固定在主页、问卷、报告与圈子页右上角。重播开场降为次要入口，保留原有天空和角色风格。
- 重做登录、邀请注册、首次建号表单；桌面双栏、手机表单优先，提供密码显示、加载、错误及隐私说明，新增原创 SVG 插图。
- 邀请链接使用片段携带令牌，进入页面后清理地址，不保存到本地存储。新账号注册后进入圈子；已有账号登录后仍需确认加入，旧答卷不会自动共享到新圈。
- 圈子注册、返回和刷新会恢复所属圈子；页面路由支持前进、后退，同会话内刷新不重播开场。只记页面名与按账号限定的圈子 ID，不持久化答案或邀请。
- 管理员优先看到收集进度、成员数和已交/未交数；名单支持名称搜索和状态筛选，导出始终覆盖完整本圈当前题库最新答卷。本人填报与建圈、加入等次要操作折叠。
- 动效保持短暂淡入、按钮状态和进度反馈，尊重减少动态设置。已有粒子在页面后台时卸载，渲染检测用完释放临时 GPU 上下文；没有增加新的常驻 3D 场景。不声称已定位或彻底修复 Codex 闪退原因。

## 按评分存档预审

依据本地 2026-09-13 官网存档及后续复核记录：过程可复现性 25%、实用价值 25%、意图控制 20%、工程 15%、体验 15%。2026-10-22 官网首页可访问，原详情链接跳转到赛道提示，未能核实当前细则全文；最终以比赛个人中心显示为准。

| 维度 | 已有证据 | 仍缺的证据 |
| --- | --- | --- |
| 过程 / 复现 25% | 历史 Git、锁文件、部署包、真实 Windows 入口与备份恢复 | 本轮改动同步到参赛仓库；两边至少三条完整原始 Prompt 链 |
| 实用价值 25% | 个人与管理员完整任务，省去逐份收 CSV 的步骤 | 真实班级试用与实际效益数据 |
| 意图控制 20% | 解释边界、模型内容闸门、Windows 问题的对照实验与修正 | 原始提问、AI 输出、作者纠偏与验证的可回溯关联 |
| 工程 15% | 分层、私有存储、逐圈权限、检查、回退和交接 | 真实公网、容器、多设备并发与长期运行 |
| 体验 15% | 统一 UI、明确账号位置、邀请、恢复、筛选、手机验收 | 不熟悉项目的新手独立测试 |

不把内部主观分数当作评委成绩，也不承诺满分。比增加装饰更重要的剩余工作，是把程序、仓库、原始对话、视频和文档固定为同一版本。

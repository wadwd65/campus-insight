# v35 · 校园小车与可进入的示意室内

用户要求“加一个车车，加一些可以进去的建筑，只要最基础的功能”。本轮只扩展电脑端独立3D地图，不改账号和测评数据。

## 怎样玩

- 打开校园地图，底部点击“开小车”：W/S或上下方向键前进倒车，A/D或左右方向键转弯，空格立即刹停，E或“下车”安全下车。车边按E可重新上车。下车前会自动刹停，若两侧均无可站位置会提示换个宽处；“回到湖畔”始终可恢复。
- 左侧“进去坐一会儿”有图书馆、自习室、食堂三个直接入口。选中相应建筑的地图详情或第一人称建筑卡片，也能点“进入示意室内”。其余楼宇保留查看功能。
- 室内WASD步行、拖动转向、空格跳跃。顶部“返回校园”随时可用；门边按E或未锁定鼠标时按Esc也可返回。返回原进入位置，再点“退出漫游”回到地图。

## 实现和性能

新增`map-src/web/campus-play.js`，使用本地Three.js现有能力，无新依赖或外部模型。小车约几百个三角形、8个渲染批次，共享箱体和轮胎几何。车体按完整占地检测现有墙、树、湖岸和边界，分步移动防止穿过薄墙；步行不能穿过车体。速度上限12米/秒，倒车4米/秒，松键有减速。

三间房是独立、简化的示意空间，不是对既有外部楼体的实测内部复刻。图书馆有书架和阅览桌，自习室有黑板与桌椅，食堂有柜台和餐桌。家具按颜色合批，室内最多16批，共享一个箱体几何。仅进入时创建一间，离开时释放全部几何和材质；进入室内期间不绘制外部校园，也不更新外部实例可见性或动态水。没有新增逐帧阴影、反射、物理引擎或后台常驻动画。

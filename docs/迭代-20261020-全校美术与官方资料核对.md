# 全校美术重做与官方资料核对

日期：2026-10-20。用户要求按刚才提供的全景图重做所有地方，并允许搜索学校平面图。本轮从 v8 局部样板扩展到当前地图的全部 38 组地点，以及湖、跑道和公共景观。

## 结果与范围

| 区域 | 本轮结果 |
| --- | --- |
| 教学、实验 | 砖红墙、连续窗带、四坡金属屋面、檐口与屋脊、白色二层连廊、浅灰内院；教学楼增加竖向饰条 |
| 计算机中心、拓新楼 | 使用阶梯式组合体量与玻璃立面，区别于实验楼围院 |
| 公寓 | 卡其色墙面、六排阳台窗纹理、坡屋面、连廊、屋顶设备轮廓与院落绿岛 |
| 体育馆、运动场 | 浅色体育馆与玻璃入口，凌云网球场放到屋顶；网球、羽毛球、篮球分别绘制配色与场线，跑道改为八道 |
| 食堂、生活街 | 门廊、遮阳棚、玻璃店面、步行铺装与花池 |
| 湖、亭、入口 | 环湖步道与局部木栈道，保留图书馆样板；抱璞亭在湖边，迎日亭和望月亭移到东门广场一带；增加概念校门与入口铺装 |
| 道路、绿化 | 灰色车道、黄色虚线、粉色人行道、斑马线、入口连接步道；132 棵树，其中 90 棵沿路种植，其余为园林种植；共享柔和接触阴影 |

“全部”指当前网页地图的全部地点分组，不代表实测了全校建筑总数，也不表示重建了 63 个室内机位。图书馆、体育馆、食堂、校门等完整体量仍有概念设计成分，不应当作真实建筑模型。

## 布局修正的依据

官方文本支持的是相对关系，尚不支持精确坐标。本轮先修正屋顶球场、东门两亭、湖边一亭的关系；另将压在车道上的两组教学楼、实验楼及超市示意体量移开，适当留开食堂与体育馆的车道边距。这些避让是视觉与几何修正，不是新的测绘坐标。

页面继续在显著位置标注“艺术化示意 · 非真实布局”，地点说明分别注明航拍特征参考或概念设计。38 组中仍有旧数据的重复教学楼分组，名称在选择框中以“· 2”区分；未把这些分组解释成真实建筑计数。

## 验证

最终 `npm run check` 退出码 0，共 616 项检查通过，其中轻量 3D 18 项。相对 v8 新增：屋顶球场高度与落位、亭子区域关系、全部地点都有可拾取实体、车道中心线不穿过建筑主体。测试发现并修复了原来亭子没有直接点选实体的问题。

性能预算仍为不超过 32 个场景绘制对象、1500 个实例、25000 个三角形，未放宽。当前为 26 个实例批次加 4 个独立网格，共 30 次绘制、1463 个实例、21,848 个三角形；生产浏览器标准档记录 11 份几何、17 份贴图，未见控制台 error。提交耗时不等于 GPU 帧率，没有真实手机或低端显卡帧率结论。

电脑生产构建检查了五个取景、下拉选地点、详情收起与相机过渡；静止时按需绘制。手机分流、资源释放及减少动态效果的离线检查继续通过，手机仍不加载引擎、场景或布局数据。本轮未把桌面画面误记为新的手机尺寸视觉测试。

两条主线的算法、问卷、CSV 统计和四时段行动地图未因本轮修改，整站检查含原有主线冒烟检查。本轮浏览器验收集中在 3D 页。未提交或推送 GitHub，未更新公网。

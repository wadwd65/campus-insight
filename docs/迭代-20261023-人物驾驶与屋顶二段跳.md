# v36 · 车内第一人称、实体人物与屋顶二段跳

本轮用户要求增加小车第一人称、实体人物建模，并用二段跳登上一些建筑。功能仍限于电脑端独立3D校园，不改变主站账号、问卷和圈子答卷。

## 操作

1. 点“开小车”默认进入车内第一人称。W/S前进倒车，A/D转弯；鼠标拖动环视，或点“自由转向”锁定鼠标；V/顶部视角按钮切换车内和跟车视角。空格刹停，E下车。环视只改变视线，不改变车头或转向。
2. 步行时按V切换第一、第三人称，第三人称可看到有头身、四肢、头发、鞋子和背包的校园人物。移动时四肢摆动，开车时改为坐姿。本人第一人称隐藏头部，避免相机被自己的脸遮挡。
3. 空格起跳，接近第一跳最高点（约0.3～0.4秒）时松开再按一次空格，同时按W向前。第三次在空中按空格无效，落地恢复两次。按住空格不会自动连跳。
4. 左侧“练二段跳”将人物放到生活区小楼门廊前并切为第三人称。先跳上门廊，停稳后可再次起跳到主屋顶；湖边三个廊亭也有可落脚的顶面。顶部“回到湖畔”随时返回地面。

屋顶不保证每栋楼都能从地面直接跳上。保留原普通起跳高度约1.25米，空中补跳提供更强的探索冲量；接近顶点使用补跳时，总高度约8.36米，需要利用低屋面继续攀登。玩法为艺术化探索，不是现实攀爬或楼宇导航。

## 实现

- 新增`campus-character.js`，共享4种几何、6种材质，关节组控制四肢；单个人物约一千余三角形，无外部模型、蒙皮、物理引擎或新依赖。室内外移动同一个人物对象；卸载统一释放资源。
- 小车座椅、透明挡风玻璃和方向盘配合真实车内眼高。第一人称近裁剪为0.06，视线相对车头独立限幅；第三人称保留防贴墙跟车镜头。
- 场景建造时记录实际薄屋面、平台和檐口，包含原来的缩放与旋转。分翼建筑保持院落空洞，不把整栋楼包围框当作地板。
- 地面`canStand`继续供车辆和安全出生使用。步行采用高度感知的`canOccupy`、`supportAt`和垂直分步落地；屋顶有支撑，走出边缘会下落，屋檐底阻挡上升。补上实体墙顶/檐口支撑，防止下落时卡在内收屋面和外立面之间。
- 跳跃次数、屋顶状态显示在画面上。静止落稳后仍按需绘制，人物没有额外常驻动画循环。

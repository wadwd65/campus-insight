# 方向 6 · 具体方案候选

> **选题方向已定**：方向 6 · 校园 / 垂直社区全栈 MVP（数据看板类）—— 2026-09-14 由本人拍板。
> **具体产品形态待定**：本文件并列三个候选，供选型。三者技术链路相同，差别在「数据讲什么故事」。

---

## 一、官方对方向 6 的原始描述

> 数据源（CSV / JSON 或公开 API）→ ECharts / D3 动态图表大盘 → 大模型对长尾数据做趣味解读

技术链路固定为三段：

```
一份表格数据  →  图表呈现  →  大模型写一段人话解读
```

三个候选的差别**不在技术，在数据**：同样三段链路，喂进去什么数据，决定了产品有没有意思。

---

## 二、选型要看的五个维度

| 维度 | 为什么重要 |
|---|---|
| 数据从哪来 | 评委 clone 后要能一键看到效果，不能让他们自己找数据 |
| 大模型解读能产出什么 | **这是加分核心**。画图表 ECharts 自己就会，人人都能画；差异全在解读那一步有没有真洞察 |
| 退守路径 | 中途卡住时，能不能缩水成「仍然可交付」的产品 |
| 开发量 | 直接决定 token 消耗，也决定能否赶在 09-26 前拿下主体 |
| 演示说服力 | 录 5-8 分钟视频时，这个故事讲不讲得动人 |

## 三、候选 A · 个人消费分析看板

**产品一句话**：拖一份记账明细进去，出图表，AI 告诉你钱花到哪了。

**数据字段**

```
日期, 金额, 分类, 支付方式, 备注
2026-03-01, 28.50, 餐饮, 微信, 食堂午饭
```

**图表**：分类占比环形图 / 月度趋势折线 / 时段分布柱状 / 支付方式对比

**AI 解读能说出什么**

- 「外卖占餐饮支出的 62%，其中 27 笔发生在 21 点之后」
- 「房租之后最大单项是奶茶，三个月 27 笔，合计 486 元」
- 「存在月末效应：每月 25 号之后支出平均是前 25 天的 1.8 倍」

**五个维度评估**

| 维度 | 评价 |
|---|---|
| 数据从哪来 | 好。人人可造，内置一份 3 个月模拟明细即可 |
| 解读洞察 | **中**。维度只有金额、时间、分类，容易退化成「占比 + 趋势」的复读 |
| 退守路径 | 三级。满配 → 图表 + 固定文案 → 纯图表工具 |
| 开发量 | 小 |
| 演示说服力 | 中。观众有共鸣，但**「记账看板」是这类比赛里出现频率最高的作品**，评委大概率已看过多个 |

**最大风险**：不够新。功能全对，但评委记不住。

## 四、候选 B · 学业成绩画像看板（校园向）

**产品一句话**：上传成绩单，出成绩画像，AI 给出学业诊断。

**数据字段**

```
学期, 课程名称, 课程性质, 学分, 成绩
2025-2026-1, 高等数学, 专业必修, 4.0, 78
```

**图表**：学期 GPA 趋势 / 课程性质得分对比 / 学分-成绩散点（气泡大小 = 学分）/ 各科雷达

**AI 解读能说出什么**

- 「你的算术平均 82.4，但**学分加权后只有 81.1** —— 说明高学分课程（4 门）拉低了真实水平，其中高等数学 4 学分仅 78 分」
- 「专业必修平均 79.2，通识选修平均 86.5，两者差 7.3 分 —— 你的短板集中在专业课」
- 「大三上出现唯一一次连续下滑，涉及 3 门课，且均为同一课程性质」

**五个维度评估**

| 维度 | 评价 |
|---|---|
| 数据从哪来 | 好。个人成绩单即可；内置一份脱敏模拟成绩单 |
| 解读洞察 | **高**。「加权 vs 算术平均的差异」是一个真实存在、但不点破就想不到的结论 —— 这正是「大模型解读」该干的事 |
| 退守路径 | 三级。同上 |
| 开发量 | 小偏中（多一个加权计算的纯函数模块） |
| 演示说服力 | 中偏高。**贴合官方「校园」定位** |

**可选的社区增强**：再允许上传一份**班级匿名成绩**，出「你在这个班的段位 + 班级整体画像（哪几门课是全班瓶颈）」。这样就有了「垂直社区」的横向对比属性，而不只是个人数据。代价是多一份数据、多一层合并逻辑。

**最大风险**：涉及真实成绩数据 —— 用模拟/脱敏数据解决，并在 README 里写清「示例数据为模拟生成」。

## 五、候选 C · 学习投入诊断看板（备考向）

**产品一句话**：上传每日学习记录，出投入画像，AI 诊断你的学习模式。

**数据字段**

```
日期, 科目, 时长_分钟, 完成题量, 正确数
2026-03-01, 数学, 150, 30, 19
```

**图表**：科目时长占比 / 每日时长热力图（按周×星期）/ **投入-产出散点（时长 vs 正确率）** / 进度趋势

**AI 解读能说出什么**

- 「数学占了你 47% 的时间，但正确率最低（63%）—— 投入与产出背离，可能是方法问题而非时间问题」
- 「英语正确率在连续 14 天内下滑 11 个百分点，下滑起点与数学时长增加同步」
- 「你的高效时段是上午（正确率 78%），但最难的数学被安排在了下午（62%）」

**五个维度评估**

| 维度 | 评价 |
|---|---|
| 数据从哪来 | 好。你自己备考就在产生这类数据；也可内置模拟记录 |
| 解读洞察 | **最高**。「投入-产出交叉分析」天然能出非平凡结论，且每条结论都指向一个可行动的建议 |
| 退守路径 | 三级。同上 |
| 开发量 | 中。散点图比柱状/折线复杂一档；需要处理「某天没记录」的缺失数据 |
| 演示说服力 | **高**。你自己就是这个产品的用户，视频里能讲真实的故事 |

**最大风险**：需要「正确率」这类字段真实存在。如果示例数据是编的，逻辑要自洽（不能出现「时长很长但正确率也莫名其妙很高」的假数据）。

## 六、三者对照

| | A · 消费 | B · 成绩 | C · 学习投入 |
|---|---|---|---|
| 数据字段数 | 5 | 5 | 6 |
| 大模型洞察力 | 中 | 高 | 最高 |
| 开发量 | 小 | 小-中 | 中 |
| 贴合官方定位 | 一般 | 高（校园） | 中 |
| 市场新鲜度 | **低**（最常见选题） | 中 | 中高 |
| 评委复现难度 | 最低 | 低 | 低 |
| 退守路径 | 三级 | 三级 | 三级 |

**三者的技术骨架完全一致**：读 CSV → 算 → 画 → 调大模型写解读。所以选哪个，**不影响前三周的开发方式**，只影响「算」和「解读」这两层的具体内容。

## 七、我的建议倾向（是建议，不是决定）

如果只按一个标准选 —— **「大模型解读那一步能不能说出让人一愣的话」**，我倾向 **候选 C**，理由是它的数据里有「投入」和「产出」两个维度，可以做交叉分析；A 只有「花了多少」，B 只有「考了多少」，都偏向单维度描述。

第二顺位是 **B**，因为「加权分低于算术平均」这类结论同样非平凡，且更贴官方「校园」定位。

**这三个我都不替你定。** 你选哪个，或者想调整字段、换个数据对象（比如图书馆借阅、食堂菜品、宿舍水电），说一声即可。

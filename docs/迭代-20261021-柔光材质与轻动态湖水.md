# v19 柔光材质与轻动态湖水 · 2026-10-21

本轮回应用户对蓝色玻璃、立面粗糙与大块感的反馈：去掉强蓝反光，增加窗格层次，调暖天空与日光，并加入轻微、低开销的动态水面。沿用 v18 建筑体量与人工校准的位置、路网及湖岸，不重新铺设校园布局。

## 玻璃与柔光

- 重绘图书馆及通高中庭的共享玻璃贴图。暖灰、香槟灰与少量灰绿替换整面蓝灰渐变；逐格加入浅窗帘、室内明暗与细边框。室内层次是贴图示意，不是可进入的室内模型。
- 教学楼、公寓与石材立面中的窗带同步去蓝，增加克制的窗格变化。湖畔馆增加四根细木色横框，分解通高玻璃面的整体感。没有逐窗新增对象。
- 降低大块玻璃的高光强度，采用温和暖白日光、较中性的地面补光、暖灰阴影及静态天空渐变。默认为“柔暖晴日”，另保留更暖的“杏金傍晚”。第一版曾偏黄，已收回默认日光白平衡，避免整座校园泛黄。

## 轻微水纹与性能边界

水纹复用原湖面多边形、UV、贴图和同一次材质绘制，通过一个时间变量轻微改变水面的亮纹。没有新增水面网格、实时反射、反射渲染目标、后处理、动态法线贴图或每帧上传贴图。

- 空闲时最多每 250 ms 唤醒一次，约每秒 4 次；摄像机已有绘制时合并更新，不额外叠加动画循环。没有为水纹建立持续 60 fps 的 requestAnimationFrame 循环。
- 水纹唤醒仍会重新绘制整幅场景，因此不是零开销，也不宣称只重绘湖面。限频及暂停机制用来控制这部分成本。
- 页面隐藏、湖面离开镜头、减少动态效果、省电画质、低内存设备、WebGL 上下文丢失或场景销毁时停止水纹。默认不在 deviceMemory≤4 的设备上启用。用户可在“画面与操作”里手动关闭“轻微水纹”。
- 若水纹刷新期间的 CPU 提交耗时连续三次超过 24 ms，本次会话会自动静止。该读数不是 GPU 耗时，也不是功耗测量。
- 停用时保留静态湖面，阴影仍为固定图集，不随水纹重新烘焙。

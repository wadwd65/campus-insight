## 先修公网登录

已实际只读请求 `https://campus-insight.app.workbuddy.host/api/campus/session`，得到HTTP503：

```json
{"error":"上线前请配置 APP_ORIGIN 为网站的 HTTPS 地址"}
```

原因是运行实例缺少正式网站来源配置，账号服务主动拒绝公网请求。不要重建数据库、重置管理员或关闭来源验证。

在原实例的**运行环境变量**补上以下值，然后重启账号服务：

```dotenv
APP_ORIGIN=https://campus-insight.app.workbuddy.host
HOST=0.0.0.0
```

APP_ORIGIN无末尾斜杠。保留平台现有PORT和持久CAMPUS_DATA_DIR，先备份原数据；不要上传本地隔离测试库。配置样例在 `deploy/workbuddy.env.example`，**这个样例不会自动生效**，必须由平台注入环境变量，或只把所需字段合并进服务器现有私有.env文件，不覆盖其他配置。

若平台仅能设置Linux启动命令，可在原启动命令中明确注入：

```sh
APP_ORIGIN=https://campus-insight.app.workbuddy.host HOST=0.0.0.0 npm start
```

域名变更时必须相应修改APP_ORIGIN。不要使用通配来源、信任任意Host或放开CORS代替配置。可信代理范围保持现有已确认值，不猜测全网范围。

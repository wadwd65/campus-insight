# B-v45 · 重做核心十题，让选择直接发生在地图中

用户纠正：问题不在额外小剧场数量，而在原十题本身太单调，且与下方地图分离。v44只增加题外故事、换题目标题和反馈，并没有解决这个核心问题。本版将首页核心流程替换为“地图中的十个决定”，旧v44完整留档。

## 核心十题已换成什么

1. 07:50：今天从教室、图书馆还是宿舍开场？
2. 10:20：利用空堂做装置、和人讨论，还是去湖边？前一步的笔记影响本幕情境，去实验楼能借到工具。
3. 12:10：六枚模拟餐券怎么安排午餐？每种消费和精力恢复实际记账。
4. 14:00：合奏、球馆、拍照散步，带来同伴、伞或避雨点。
5. 15:10：午后阵雨如何改变路线？有同伴才能接回活动室，有伞或避雨点才可去湖亭；另一版天气为晴天，有不同事件与可选行动。
6. 16:00：展示临时出故障。上午拿到工具，才有修接头方案；也能补印、梳理讲稿，或帮忙转达后休息。
7. 18:00：根据剩余精力运动、组队或休息。体力不足或没有同伴时，相应方案不可用。
8. 19:20：晚饭和散步，继续使用剩余餐券；不消费的去处也能继续。
9. 21:00：送别、湖边缓冲或回宿舍通话；下午是否帮过忙会进入这一幕的来信情境。
10. 22:15：从本次确实去过的地方选纪念章。拍过照片/收过手绘小票，也会影响提供的纪念地点。只回看，不添加第十次虚构移动。

这些是模拟事件中的选择，不再把“你平时属于哪一类”的调查问题作为核心试玩。每幕有不同的任务、资源与实际后果，两种天气共享十个事件结构；合法路径数量不是独立剧本数量，也不承诺无限内容。

## 地图就是操作现场

- 使用现有校园地图SVG、同一套地点与坐标。地点按钮和行动卡双向选中；先显示虚线预览，确认后才移动小人、连接实线路线、扣资源并记录行程。
- 背包包含笔记、工具、同伴、伞、避雨点等；不是仅显示图标，资源条件直接改变之后哪些行动可执行。餐券不足/精力不足有明确说明，并至少保留两个可行方案。
- 九次实际行动加一次纪念决定。结果先展示具体行程和十个决定的后果，可保存真实TXT路线小记；不再把人物标签放在主结果位置。
- 可退回任意决定改线，需确认；只保留之前的前缀，之后路线、物品、精力、餐券和结局全部重新计算，不保留已经不可能发生的后续。完整走完后可换天气重开。
- 当前匿名/账号各自本机存档，刷新或回首页可接回同一幕和反馈阶段；禁用存储仍可当次玩完并提示无法保存。不会自动合并匿名和登录账号进度。
- 桌面为地图与行动并排，小屏先看地图再选卡；普通按钮可用键盘。地图小人只用transform过渡，路线预览用CSS，减少动态/后台暂停规则保留，没有新增逐帧循环或渲染引擎。

## 其他功能如何处理

原真实十题没有被改写成模拟事件的答案。成员正式填报、旧草稿、CSV字段、矩阵1、2000人模拟基准、权限与提交同意流程保留；从“我的圈子”或展开区“填写真实问卷（非地图游戏）”进入。原自由行动四时段地图、额外四段小剧场、3D参观和示例也保留在展开区，不再抢核心体验入口。

游戏进度只存版本、天气、动作ID和反馈阶段，没有伪造真实答案。游玩不会写入原问卷账本，不会向账号/圈子发送提交。原有真实问卷草稿经过整站测试确认保持。可选“规则图谱”直接以模拟地点向量演算，明确标注为模拟行程、程序生成对照；不冒充真实填报、本人排名或心理结论。它不会提供圈子提交面板。

九首本地授权配乐沿用v43。阵雨时有原轻量雨幕与对应音乐场景，默认静音、用户暂停优先，手动选曲保留。国内CC BY 4.0录音仍需署名，录屏使用docs/录屏配乐署名-v43.txt。

## 验收

完整npm run check和全部既有模型/账号/部署/地图检查通过。新增地图十决定模型6项：两种天气穷举所有合法路线，检查每一步至少两个可行行动、资源不为负、可在十步完成；验证资源门槛、回退重算、纪念地点确实去过、九次行动与向量同源、存档隔离与坏数据恢复。枚举的是共享事件结构的选择路径，并非不同剧本。

新增实际App离线整站10项：主入口进入地图、地图与行动卡预览、确认移动、重算回退、暂停恢复、雨天真实锁定条件、完整十步、结果与真实TXT导出、规则页不提交、改准备后改变后续、旧问卷恢复与账号隔离、禁用存储和换天气重开。旧故事、音乐、立绘/彩蛋及正式答题/PNG导出回归继续检查。v44整站脚本以旧主页为前提，由本版十项主流程验收替代，不能混称旧主页流程仍为本版核心。

离线环境采用实际React组件与App路由，账号响应为合成只读会话，基准CSV从公开本地文件读取。几何、原生媒体和dialog被模拟，画布用本机后端；它不是浏览器布局、真实听感、帧率或用户趣味性验收。原浏览器URL限制继续尊重，没有换工具绕过。趣味性改善仍需测试用户实际试玩判断。

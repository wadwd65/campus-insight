# 轻量 3D 校园与部署说明

日期：2026-10-20。用户要求降低原高精度地图的网页负担，并明确补充：手机不用提供 3D，手机看图不方便。

## 当前结果

- **电脑**：在网站主页与四时段行动地图页进入 3D 导览。支持鼠标拖动旋转、右键 / Shift 平移、滚轮缩放、点选建筑、下拉选择地点、四个取景、复位、手动日光方向、可开关的自动环绕和三档画质。
- **手机**：主页和行动地图隐藏 3D 链接。直接打开 3D 地址仅显示“3D 校园留到电脑上看”和返回网站，不创建 WebGL 画布，不导入 Three.js、场景代码或布局 JSON。宽度不超过 760px，或粗指针设备宽度不超过 1024px，均使用此模式，覆盖常见手机横屏。
- 电脑画布切到手机范围时释放场景、材质、贴图、阴影与渲染器；回到电脑范围可重新初始化。测评、CSV 和原四时段行动地图不受此限制。
- 本轮没有更新旧的 Sites 公网版本，部署交给用户安排的另一个 AI。本地源码、dist 和下述部署包已更新；没有提交或推送原 GitHub 仓库。

## 优化方式与取舍

保留 `tower-10-campus.js` 中的边界、道路、湖岸、跑道和 38 组建筑落位，以及 `tower-08-batch-main.js` 的名称和公寓元数据。不再运行原高精度立面、屋面、街道家具与城市场景的整套构造代码。

建筑改为简化体量；窗户与跑道线使用共享 Canvas 贴图，重复构件使用 InstancedMesh。场景有 40 处可选择地点（38 组落位 + 湖 + 跑道）、210 棵低面树、1004 个实例，约 16,252 个三角形。实测主画面每帧 19 次绘制、8 份几何、4 份贴图（标准档含阴影资源）。

静止时不重复绘制；相机、选择或日光发生变化才请求帧。自动环绕默认关闭、开启时限制约 30 次/秒更新，页面隐藏时暂停。阴影仅在需要时更新，标准档 1024，清晰档 2048，省电档关闭；最高像素比 1.5。单帧 CPU 提交耗时不是 GPU 帧率，未声称所有设备都能达到固定 FPS，也未重新测量旧版内存来编造性能倍数。

这是一张正常可转动的 3D 场景，未烘焙成一张可拖动图片。代价是取消精细窗台、空调、屋顶棱条等近景细节，不能当作测绘或导航模型。旧高精度源文件仍保留，不再作为网站默认运行链。

## 唯一网页构建入口

```powershell
cd C:\Users\123\WorkBuddy\2026-09-10-15-40-22\campus-insight
npm run build:map  # 仅更新 public/map
npm run build      # 先生成地图，再构建整个网站
npm run check      # 含构建及所有检查
```

源文件为 `map-src/web/`：HTML、CSS、轻量分流入口、3D 应用、场景和纯逻辑。`scripts/build-campus-web.mjs` 有界提取既有元数据、验证 38 组落位和湖岸数据，再生成 `public/map/`。页面只请求同目录资源，无 CDN、字体服务或地图 API。`src/` 不导入 `map-src/` 或 Three.js，未增加 npm 依赖。

**不要再手工修改生成的 public HTML**。旧 `build-campus.py` 仍可用于历史高精模型，不能拿它的产物直接覆盖新版网站。源构建说明顶部已添加当前链路提示。

## 给负责部署的 AI

最新部署包：桌面 `campus-insight-dist-20261020-v7.zip`。将 ZIP 解压后的全部文件部署到静态站点根目录，根目录应直接包含 `index.html`、`assets/`、`art/`、`data/`、`map/`。不要再上传昨天的 v6，也不要只上传一份 3D HTML。

`map/` 必须整体保留，包括 `three-r149.min.js`、`campus-boot.js`、`campus-app.js`、`campus-model.js`、`campus-scene.js`、`campus.css`、`campus-data.json` 与中文入口 HTML。需用 HTTP(S) 访问；新版 ES 模块与 JSON 不支持直接双击本地 HTML 当成离线单文件使用。

整个 dist 约 3.22 MiB；地图所有资源约 0.63 MiB，较本轮开始时约 1.0 MiB 的地图减少约 37%。真正的主要优化是减少场景构件、绘制提交、阴影重算和空闲绘制，不能只按文件体积推断运行速度。

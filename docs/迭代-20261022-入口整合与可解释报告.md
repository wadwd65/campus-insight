## 最终行为

- 首页保留问卷为主入口，行动地图明确为「四个时段的选择写入画像」，3D 校园明确为独立自由参观。3D 从首页或行动地图另开标签页，原答案和账本保留；手机不加载 3D。
- 报告新增九维解释，展示原始矩阵分、推高/拉低增量、模拟基准百分位与具体来源。问卷轨迹不重复计算；地图按已记录的实际 delta 解释，含重复访问衰减；没有轨迹的分数不会伪造来源。
- 临时替换一道答案并切换维度，查看公式重算结果，保留原报告与已有地图行动。这是规则敏感性预览，不是习惯干预的效果预测。
- AI 改走同源 Node 服务。浏览器不再读取 VITE 密钥；个人仅发送已知答案和九维位置，班级仅发送汇总统计。服务端重建固定提示词，不接受前端覆盖模型、地址或任意 messages。
- 服务端提供配置状态、正文 SSE、请求大小限制、每来源每分钟 6 次/同时 2 次、全局同时 8 次、超时与离页取消。供应商推理字段及错误正文不转发；缺少结束事件的断流不能算成功。密钥文件保持在本机，不复制到前端或交付包。

## 实测发现与修正

首次真实个人输出虽通过原数字校验，却把规则曲线写成真实年级经历。调整三段式为「具体答案—选择取舍—可自愿尝试的行动」，保留假设题情境；新增未选答案和未提供大学经历的硬错误检查。

首次班级输出用较宽 IQR 推断「中间地带不厚」，属于未经计算的密度结论。新增分布形态检查，明确 IQR 只能描述中间一半的范围；九项原始属性分不允许跨维比较，不从类型推断个体需求，不根据匿名汇总点名或按强弱结对。初轮问题输出与后续真实页面记录分别保留，没有把初次联通当作内容验收。

这些检查能拦截已覆盖的典型错误，不能证明任意自然语言推断都正确。页面保留来源标识、失败原因与核对提示；活动建议仍需向同学确认。

模型配置依据 [DeepSeek 官方模型说明](https://api-docs.deepseek.com/quick_start/pricing/) 与 [Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)，本次使用 deepseek-flash，并显式关闭思考模式。未修改问卷选项、评分矩阵或模拟基准。

## 交付与运行

交付目录：原工作区 `交付文件/campus-insight/v25-入口整合与可解释报告/`。

- `campus-insight-v25-static.zip`：dist 静态页面，可直接托管；没有同源 API 时使用本地解读。
- `campus-insight-v25-node.zip`：dist、Node 服务与实际依赖的本地纯 JS 模块、配置示例和启动说明；无需 npm 运行时依赖，不含环境文件或密钥。

# v16 全校建筑艺术化重做 · 2026-10-20

本轮按用户最新要求，将目标由逐栋核对全景改为「布局合理、建筑好看」。模型采用统一的暖石、陶土、蓝绿玻璃与木色语言，建筑属于艺术化设计，不能作为实景复原、测绘或导航资料。位置、道路、湖形仍保留此前用户导览图的校准底稿；没有重新引入已被否定的旧 tower 布局。

## 建筑与景观

- 11 栋/组公寓分为三种生活片区：枕霞苑坡顶围院、梅香苑退台双翼、松涛苑双坡屋面与玻璃连廊。保留楼号，增加楼端采光塔、入口双拱、局部屋面天窗、真实阳台和院落铺装。
- 四栋教学楼采用高低翼楼、玻璃连桥、入口拱廊与屋顶花园。实验楼改为浅石双翼、采光中庭、屋顶天窗与遮阳肋片；综合楼使用错层体块与退台露台。
- 计算机中心采用通高玻璃立面、竖向框架与错层屋面；拓新楼采用暖砖长楼、拱廊和木格屋顶。
- 两处图书馆采用不同体量：湖畔馆是石材双翼、通高玻璃阅览厅和折脊屋面；桂香苑馆为低矮坡顶阅览翼与花园门廊。
- 晴味堂改为退台餐厅、市集拱廊、分段雨棚和木格露台；商业区增加连续橱窗与遮阳；体育馆增加结构肋与大雨棚，楼顶球场保留；三处廊亭重做台基、柱、檐和座椅。
- 添加 20 段通过障碍检查的步行连接，完善广场铺装、入口台阶、屋顶女儿墙与种植池。132 株主景树中包含少量低饱和花树；种植避开建筑主体和入口前场。

## 交互与显示修复

- 近景按新入口朝向取景，略微靠近并降低俯角，支持屋面与另一侧查看；点选增加浅金色地块轮廓。
- 点击拾取跳过没有地点键的装饰表面，实体与地点选择框都可正常选中图书馆。
- Three r149 共享材质的实例批次统一提供颜色属性，修复新拱廊偶发纯黑；增加专项回归检查。
- 桌面切到手机时释放画布及三维资源，回到桌面后画质、日照与开关状态一致恢复。
- 页面统一显示「艺术化建筑」，外观对照折叠区改为建筑设计笔记，不再暗示新造型已被真实全景逐栋验证。

# v31 · 新手指引与体验优化

2026-10-22。接续 v30 的登录、注册分离和 6～12 位新密码规则。本轮重点是让不熟悉电脑的用户知道下一步该做什么，并允许稍后再做；不增加新的测评结论或自动提交行为。

## 用户需求与处理原则

用户要求优化功能和 UI，考虑不会操作电脑的人，提供较强的指引及跳过入口。用户也允许使用已打开的秋绘工具制作视觉素材。本轮使用代码内原创 SVG 校园档案插图，没有调用秋绘，没有生成新的位图资产。

将入口说明、操作反馈、出错后的恢复办法放在对应步骤旁边。跳过引导、暂不登录、稍后填写、稍后提交分别表达不同含义，不能用同一个“跳过”代替所有操作，也不能通过跳过补出虚构答案。

## 已实现

### 首页与轻量新手指引

首页增加“个人十题无需注册”的明确入口说明和内联“使用帮助”。首次访问可打开三步指引：选择用途、看懂怎么用、准备开始。用途只有“我想看看自己的画像”和“我要填报 / 收集答卷”，避免给新用户增加过多选择。

指引解释成员使用邀请、管理员可以创建圈子；全新站点先由网站管理员开通，普通成员向管理员索取可用邀请。它只负责说明与导航，不创建账号、确认加入、填写答案或提交答卷。

右上角“跳过引导”和 Esc 均可关闭。完成或跳过后，在当前浏览器记住引导偏好；以后仍可从首页、圈子页的“使用帮助”重新查看。持久化内容仅为版本和完成 / 跳过状态，不包含账号、答案或邀请码。存储被禁用或满额时，本页面生命周期内使用内存兜底，避免组件重新挂载时反复自动弹出；无法承诺跨刷新保存。

原生 `dialog` 处理背景交互和焦点约束，换步骤回到内容顶部，关闭后恢复可用的原焦点。插图、森林绿和浅纸色沿用当前视觉基调；装饰不依赖大图片，按系统设置减少动态。

### 登录、注册与个人体验

登录和注册保持独立入口。错误输入在当前表单中用中文说明，并把焦点放回需要修改的字段；切换模式清除旧错误。新密码沿用 v30 的 6～12 位规则，允许纯数字，历史长密码仍按原兼容策略登录。

普通成员看见未开通的站点时，会被告知先联系管理员；首次开通说明明确标为管理员操作。未登录页、连接失败页都可选择先体验个人测评。该个人入口会清除圈子作答上下文，个人报告不会出现圈子提交面板。

### 十题测评与报告

测评改为“先点选，再点击下一题”，避免不熟悉操作的用户误以为点选后已经跳题。显示第几题、共几题、已选状态及下一步说明；上一题可修改。答题说明可以收起、重新查看，键盘方式作为可选说明。

“稍后填写”保留本标签页进度，再回首页或对应圈子；“清空重答”先确认，可选择保留答案。手机底部保留可操作的下一题区域。圈子草稿按账号和圈子隔离，完成十题后仍保留待提交草稿，方便稍后继续。

报告说明按个人与圈子场景区分，明确“生成报告”不等于“交给管理员”。报告内阅读、保存及提交区域的导航只滚动到本页位置，不把锚点当作站内路由导致离开报告。

### 圈子收卷与提交

管理员和成员分别看到对应步骤、角色及下一步操作。管理员可创建圈子、生成邀请、复制链接、查看最新数据、读取原始十题和汇总；成员可加入、继续填写、核对后决定是否提交。自动复制失败时提供手动复制办法。

提交区显示目标圈子和当前身份，允许展开核对十题，明确共享原始答案、显示名称和提交时间。只有答完、身份匹配且主动勾选同意后，提交按钮才可用；稍后提交不会共享答案。成功后显示实际提交时间和次数，返回圈子可查看已交状态。

对写操作已成功、随后列表读取失败的情况，保留成功结果并提示刷新列表，避免误报“创建 / 加入失败”而诱发重复操作。新圈子加载后聚焦圈子标题；有引导弹窗时不抢夺焦点。网络中断导致无法确认提交时，先引导回圈子核对结果。

- 验收时浏览器控制台警告、错误均为空。

## 限制与交付边界

本轮是开发者模拟新手路径的实际操作验收，尚未邀请不熟悉电脑的真实用户做可用性测试，不能把它写成已证实的易用性评分。没有新增公网部署、录制最终比赛视频或完成比赛提交，也不宣称所有浏览器和设备都已经覆盖。

测评和圈子草稿仅在当前标签页暂存；关闭标签页、退出账号或浏览器禁止存储时，不能保证继续恢复。没有在跳过时生成答案。页面仍保留之前的统计边界：对照基准是模拟记录，小样本圈子汇总不能代表真实整体人群；账号仍没有邮件找回功能。

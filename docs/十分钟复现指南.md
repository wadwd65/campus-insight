# 第一次打开校园行迹

先选一条路线。评审想体验作品，选“直接运行”；想验证源码能重新生成网页，选“从源码重建”。两条路线都包含完整Node服务、问卷报告与圈子接口，不是只打开一个静态HTML。

## A. Windows离线即用包：全部解压，再双击

1. 在参赛工程包中找到 **Windows离线即用包.zip**，右键选择“全部解压缩”。不要在压缩窗口里直接运行，也不要只取出一个启动文件。
2. 打开解压出的文件夹，双击 **开始使用.cmd**。包内已带运行工具，不需要先装Node、Python、Docker或npm依赖。
3. 浏览器会打开本机网站。若没有自动打开，复制启动窗口显示的地址；默认是 **http://127.0.0.1:5191/**。
4. 在首页点“填写校园问卷”，完成十题并查看报告。个人体验不必注册，也不必配置模型服务。
5. 要保存桌面入口，运行 **安装到此电脑.cmd**，按窗口提示完成本机安装；无需管理员权限。需要保留自己的账号时，更新前使用“备份我的数据”。

启动窗口保持打开；停止时按Ctrl+C。安装器和启动器显示的路径才是这次安装的实际位置，不要为了“重装”删除数据文件夹。

**已有账号先看这里：**安装版使用独立数据目录，不会自动迁移便携版的账号和答卷。可以继续用原文件夹的“开始使用”，或先在原入口备份，再按[备份恢复说明](双方案部署与交接.md)迁移到新的空数据目录。安装根目录也提供“备份我的数据”和“打开数据文件夹”。不要用创建空账号代替恢复原数据。

## B. 从公开仓库直接运行成品

### Windows，不熟悉命令行

在GitHub仓库点 **Code → Download ZIP**，下载后“全部解压缩”，双击最外层 **开始使用.cmd**。仓库已带网页成品 `dist/`。

启动器会先找包内或已安装的Node。若缺少合适版本，会联网下载并校验完整Node便携包，连同npm缓存到项目内，不需要修改系统环境变量。已经具备运行时后，日常启动不再需要这一步下载。

下载受网络影响；网络不便时，优先使用路线A的离线包。源码仓库ZIP不预装Node二进制，也不需要把 `node_modules` 加进仓库。

### 已有Node与Git的Windows/macOS/Linux

需 **Node.js 24.21.0或更新版本**；账号数据使用Node内置SQLite。

```sh
git clone https://github.com/wadwd65/campus-insight.git
cd campus-insight
node --version
node server/index.mjs
```

看到 `Campus Insight: http://127.0.0.1:5191` 后，在浏览器打开它。使用已提交的 `dist/` 时，没有外部运行时npm依赖，**无需 `npm ci`**。这一步验证成品与Node服务能运行，不能据此宣称已从前端源码重建。

## C. 从源码重新构建网页

**Windows直接双击“重新构建并启动.cmd”。**它会检查Node和npm，缺少时自动下载并校验完整便携包，然后依次安装锁定依赖、重新构建、校验产物、启动网站。不需要先手动安装Node或设置PATH。

本路线需要联网下载前端依赖。先停止之前的本地服务；已有完整Node环境时，也可在项目根目录运行等价命令：

```sh
npm ci
npm run build
npm run verify:dist
npm start
```

`npm ci`按锁文件安装依赖；`build`生成独立3D入口、主站网页和版本摘要；`verify:dist`核对构建资源；`start`运行这次构建及账号接口。

若Windows命令行找不到 `npm`，使用上面的“重新构建并启动”即可让脚本准备完整工具。macOS/Linux命令行路线需自行具备完整Node发行包，官方获取地址：https://nodejs.org/zh-cn/download 。不要把“成品启动成功”当成“源码构建成功”。

本次实际耗时、网络前提与仍待验证的项目记录在[交付验收](交付验收-20261112.md)。不要把开发者已有缓存、工具和账号的机器等同于全新电脑。

## 打开以后，怎样知道复现到位

| 路径 | 应看到的结果 |
| --- | --- |
| 首页→十题问卷→报告 | 十题可确认，报告同时有称号、解读、雷达图与时间图 |
| 暂停→返回续填 | 同一标签页保留进度，完成后可回看报告 |
| 校园一天→核对问卷 | 游戏带来建议，原有回答不被直接覆盖，确认后生成报告 |
| 创建圈子→邀请成员→提交 | 注册者可成为管理员；成员明确同意后交卷，管理员能看到本圈提交 |
| 首页独立3D入口 | 电脑上打开v30.2艺术化校园，可漫游；手机使用友好降级入口 |
| `/build-edition.json` | 业务版本B-v53.3及本次构建摘要；不用固定某个Vite资源文件名 |

首次启动不会带来参赛者旧账号或答卷。需要圈子时在网页上注册，自设6～12位密码，不需要“初始化口令”。所有演示和模拟基准应与真实用户数据区分。

## 常见卡点

- **双击后没网页：**看启动窗口是否提示缺少文件、下载失败或版本不合适。保留整包，重新“全部解压缩”；不要单独移动启动器。
- **提示端口占用：**如果刚才已经启动过，回到那个窗口显示的网址。不能把别的程序占用同一端口当成本网站已经启动。
- **想让同学从手机访问：**本机地址只在自己的电脑生效。把[部署交接](给部署者的交接.md)交给服务器维护者，配置HTTPS和持久数据目录，成员只需浏览器。
- **线上账号没有出现在本机：**不同站点各自保存数据，克隆仓库不会下载生产数据库。整站迁移必须由原维护者按备份恢复流程操作。
- **没有在线AI解读：**默认报告来自本地规则，图表按同一份答卷计算；复现基本流程不需要模型密钥。

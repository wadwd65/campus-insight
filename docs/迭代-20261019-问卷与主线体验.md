# 2026-10-19 · 问卷与主线体验

本轮目标：改善题目、报告阅读和真实使用流程，解决 10-18 预审中的可复现问题。基于 `cc9c87a` 及 10-18 已保留的 UI 修改继续工作；没有改选题方向或入口排序。

## 完成的改动

- 十道题改用在校生也能回答的措辞，去掉“必须毕业、经历完整四年”的前提。提示语避免评价家庭条件或声称能测出真实人格。新增题目主题标签。
- 问卷支持 A–E / 1–5 键盘作答；上一题可修改；题目切换返回顶部；选择反馈期间禁用重复操作。
- 草稿仅保存在本标签页的 sessionStorage 中。刷新后重新进入测评可继续；完成或主动清空后删除。草稿恢复验证版本、进度和选项，忽略陌生字段；存储被禁用时仍可正常答题。
- 报告缩短顶部天空窗，作答轨迹默认折叠并展示实际答案；地图体验提示移至主要结果之后。雷达说明使用实际轴数，区分八项基础属性、派生属性与五轴展示。
- 上传页和群体页增加稳定浅色阅读底。首页不再展示容易过期的固定自检数量。
- 区分本地规则解读与真实 AI 解读；未配置接口时不展示无实际意义的重写按钮。复制报告也附模拟基准与规则推算说明。
- 修复批量 CSV 合并：独立解析文件并按列名对齐，兼容列重排、后续文件新增编号、引号内换行。缺列、重复列、坏引号给出明确错误，不再静默丢失有效记录。
- 修正群体兜底文案：四分位距大不能推出“中间几乎没有过渡”；小样本不推断全班特征。
- “再答一次”直接进入新问卷，上传页与群体页“回到首页”实际返回首页。问卷写入账本后，从最新 store 读取快照，避免保留上次渲染中的旧属性。

## 数据与边界

仍为 10 题、48 个规范答案；CSV 字段、选项文本、属性向量、派生公式和 2000 人基准均未改变。矩阵版本维持 1。新增主题及题干属于展示与解释层的更新，不是重新验证过的科学量表。

没有新增对 map-src 的引用，3D 展示继续使用独立外链。背景保持静止，没有增加 backdrop-filter 或新的持续渲染层。未新增依赖。

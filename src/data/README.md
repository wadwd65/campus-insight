# src/data/ · 数据接入

**职责**：管「数据从哪来」——读取内置示例、接收用户上传的文件、保管当前会话的数据状态。

**和 `public/data/` 的区别**

| 目录 | 放什么 | 谁会用 |
|---|---|---|
| `public/data/` | 示例数据文件本体（CSV） | 评委点「加载示例数据」时通过 URL 取 |
| `src/data/` | 取数据的代码（fetch、读文件、状态管理） | 开发时引用 |

**注意**：示例数据是**模拟生成**的，不含任何真实个人信息，README 里已声明。

**预计落位的文件**

| 文件 | 做什么 | 任务编号 |
|---|---|---|
| `loadSample.js` | 拉取 `public/data/` 下的示例 CSV | T-24 |
| `readFile.js` | 读取用户拖入的文件为文本 | T-24 |

# src/lib/ · 纯计算逻辑

**职责**：只放「输入数据 → 输出数据」的函数。**不 import 任何 React**，不碰 DOM，不做界面。

**为什么单独分一层**：评委看架构就是从这一层看。把计算和界面分开，意味着同一份逻辑可以被页面用、被测试用、被导出报告用，改界面不会算错数。

**约定**

- 一个文件一类职责，导出纯函数
- 函数要能被单独调用验证（在浏览器控制台粘一行就能跑）
- 不做 `console.log` 式调试残留

**预计落位的文件**

| 文件 | 做什么 | 任务编号 |
|---|---|---|
| `parseCsv.js` | CSV 文本 → 对象数组；识别表头顺序变化 | T-05 |
| `validate.js` | 字段校验，返回人话错误信息 | T-06 |
| `cleanData.js` | 去重、剔除非法行并统计剔除数量 | T-07 |
| `aggregate.js` | 按科目 / 按日聚合 | T-08 T-09 |
| `diagnose.js` | 投入产出比、背离度、时段统计、趋势检测 | T-10 T-11 T-12 |
| `buildSummary.js` | 汇总成一份喂给大模型的结构化摘要 | T-13 |
| `llm.js` | 大模型接口封装（OpenAI 兼容 + 流式） | T-20 |
| `fallback.js` | 接口不可用时的本地模板文案 | T-23 |
| `exportReport.js` | 导出解读文本 / 图表图片 | T-27 |

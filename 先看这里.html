校园行迹 · B-v53.3 · 给第一次使用的人

解压、双击，先留下一份校园日常

1. 全部解压缩

右键你收到的ZIP，选择“全部解压缩”。进入解压后的文件夹，找到“开始使用”。不要在压缩包预览窗口里运行。

2. 双击“开始使用.cmd”

Windows x64即用包已经带齐运行工具，不用装Node，也不用输入命令。等待浏览器打开。如果从GitHub下载的源码ZIP没有运行时，入口会联网下载并校验独立运行工具，不修改系统设置。

这个启动窗口要留着。停止网站时在窗口按Ctrl+C。没有自动打开浏览器，就把窗口显示的完整网址复制进去。

3. 先填写十题，不用注册

网页点“填写校园问卷”，完成十题即可查看档案。需要班级或社团一起收卷时，再点“登录 / 注册”，选择创建自己的圈子，设置账号和6～12位密码。不需要初始化口令。

想放到桌面，下次更好找？

双击“安装到此电脑.cmd”。它安装到你的个人目录，创建“校园行迹”桌面入口，无需管理员权限。程序版本与账号数据分开放置，重复安装保留已有数据。以后从桌面入口启动。

数据放在哪里，怎样备份？

便携版默认把数据保存在当前文件夹的.campus-data；安装版的数据保存在个人应用目录，与程序版本分开。运行中的窗口会显示实际位置。双击“备份我的数据”生成备份，“打开数据文件夹”查看位置；换电脑或更新前先备份。

想验证源码能不能重新做出网页？

在完整源码目录双击“重新构建并启动.cmd”，或者按README运行npm ci、npm run build、npm run verify:dist、npm start。这条路线需要下载前端依赖；直接使用成品不需要它。

让其他人用手机访问？

127.0.0.1只代表这台电脑，发给别人不能用。需要持续运行的服务器、HTTPS和私有持久数据目录。把服务器包和“给部署者的交接.md”交给协助部署的人，保留原数据库，再验证注册、邀请、提交和重启。成员只需浏览器。

打不开时先看什么？

先确认已经全部解压、启动窗口还在。若端口正在使用，可能原网站已启动，先看原窗口给的网址。下载失败可用随包提供的Windows离线即用包。源码重建失败时保留错误信息，不要删除自己的数据文件夹。

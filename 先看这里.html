校园生活档案 · 给第一次使用的人

先在自己的电脑上试起来

Windows x64 即用包已经带好运行工具，解压后双击“开始使用”就能打开。通用部署包需要先安装一次 Node.js。不用找初始化口令，也不用输入技术参数。

1. 把压缩包完整解压

右键 campus-insight-admin.zip，选择“全部解压缩”。打开解压后的文件夹，能看到“开始使用”“备份我的数据”等文件。不要直接在压缩包窗口里启动。

2. 即用包可以跳过安装

如果文件夹里有 runtime 子文件夹，直接进入第3步。只有通用部署包需要下面这次安装。

打开 Node.js 官方下载页，选择 Windows 安装程序。使用 24.21 或更新版本，按安装程序提示完成。安装过符合版本的工具，可以跳过这一步。

它相当于网站的运行工具。管理员这台电脑装一次就够了，来填写的成员以后用浏览器访问正式网站。

3. 双击“开始使用”

回到解压文件夹，双击 开始使用.cmd。等待窗口提示“网站已打开”，浏览器会自动打开。如果没有自动打开，把窗口显示的网址复制到浏览器地址栏。

这个启动窗口请留着。只关闭浏览器不会停止网站。想停止时，在启动窗口按 Ctrl+C。

4. 注册，创建自己的圈子

  1. 在网页点击“登录 / 我的圈子”，切到“注册”。
  2. 选择“创建圈子，我当管理员”。
  3. 设置自己的账号和 6～12 位密码，圈子名称可以自己填写。
  4. 点击“注册并创建我的圈子”。你就能邀请成员，也可以自己答十题，在档案页点“提交到我的圈子”。

加入其他人的圈子时，使用对方的邀请。你创建的圈子由你管理，其他圈子的管理员无法查看你的答卷。

5. 下次打开，还是双击同一个文件

双击“开始使用”，登录原来的账号。不需要重新注册。只要保留原文件夹里的数据，账号、圈子和已提交的答卷会保留。

6. 想让其他人用手机填写？

127.0.0.1 表示“这台电脑自己”，发给别人也不能访问。本机试用完成后，需要把这套程序放到一台能持续运行的服务器上，再给大家一个正式网址。

你如果不熟悉服务器，可以把完整管理员部署包和包内的“给部署者的交接.md”交给帮助部署的人。等对方验证注册、邀请、提交、重启后数据保留都正常，再发送网址。成员不用安装 Node.js，也不用下载这个包。

启动没有成功，先看这几种情况
  • 提示没安装 Node.js：完成第2步后，重新双击“开始使用”。
  • 提示端口正在使用：可能已经启动过一次，先回到原来的网页和启动窗口。
  • 浏览器显示无法访问：检查启动窗口是否还开着，复制它显示的完整网址再试。
  • 提示缺少网页：重新完整解压管理员部署包。
  • 文件名没显示 .cmd 后缀：找名字为“开始使用”的 Windows 命令脚本，不需要打开 scripts 文件夹。
怎样备份，怎样保留数据

双击“备份我的数据”，看到成功提示后，双击“打开数据文件夹”，进入 backups。把备份另存一份到自己的私人磁盘。

更新或换电脑前先备份。默认的 .campus-data 文件夹保存账号和答卷，请保留。配置过其他数据位置时，“打开数据文件夹”会打开实际位置。恢复备份请按交接文档操作。

已经有服务器，想自己配置正式网址

打开 deploy 文件夹里的“配置并启动”。这部分会涉及域名、HTTPS 和数据存储，具体步骤见“给部署者的交接.md”。单纯在电脑上练习可以直接跳过。

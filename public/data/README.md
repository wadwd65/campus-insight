# public/data/ · 示例数据

评委 clone 仓库后，点一下就能用这里的文件看到完整效果，**不需要自己去找数据**。

## 要求

- 必须是**真实可用的数据**，不是占位符（不能出现 `xxx,1,2,3` 这种）
- 字段名用中文，让评委一眼看懂
- 行数 50–200 行：太少看不出趋势，太多浏览器里滚动不便

## 计划放什么

选题方向尚未确定，示例数据的字段与内容待产品定义确认后填写。

届时至少准备两份：

| 文件名 | 用途 |
|---|---|
| 示例数据（主） | 让评委一键看到完整效果 |
| 示例数据（异常） | 故意留空值、格式错乱、极端值，用于演示容错能力 |

> 容错能力（空数据、异常值）是评分点之一，第二份不是可选项。

# public/data/ · 示例数据

评委 clone 仓库后，点一下就能用这里的文件看到完整效果，**不需要自己去找数据**。

## 要求

- 必须是**真实可用的数据**，不是占位符（不能出现 `xxx,1,2,3` 这种）
- 字段名用中文，让评委一眼看懂
- 行数 50–200 行：太少看不出趋势，太多浏览器里滚动不便

## 计划放什么

| 文件名 | 内容 | 用途 |
|---|---|---|
| `示例-消费明细.csv` | 一个月的消费记录：日期、金额、分类、支付方式、备注 | 主演示数据 |
| `示例-异常数据.csv` | 故意留空值、格式错乱、超大金额 | 演示容错能力（空数据与异常值处理是评分点） |

## 字段约定

```
日期,金额,分类,支付方式,备注
2026-03-01,28.50,餐饮,微信,食堂午饭
```

金额单位统一为元，保留两位小数。

# campus-insight · 消费明细分析看板

> 2026 第九届传智杯全国大学生数智创新与 AI 应用大赛 · AI创新应用挑战赛
> 个人赛 · B 组

**一句话**：把一份消费明细表拖进网页，自动出图表，再让大模型用人话告诉你钱花到哪去了。

## 解决什么问题

记账的人不少，看得懂账的人不多。

记账 App 给的是流水 —— 一长串数字，看完还是不知道问题在哪。真正有用的判断是「这个月外卖比上个月多了 40%」「你的钱有三分之一花在深夜时段」，而这种话只能靠分析才能得出来。

本项目做的是从**原始明细**到**结论**的最后一公里：上传表格 → 图表呈现 → 一句话结论。

## 功能

- [ ] 上传 CSV 明细，或一键使用内置示例数据
- [ ] 自动识别金额、日期、分类等字段
- [ ] 生成图表：分类占比 / 月度趋势 / 时段分布
- [ ] 筛选与悬停查看细节
- [ ] 大模型生成解读文字，逐字流式输出

## 10 分钟极速复现指南

> 评审老师按这一节操作，十分钟内可看到完整效果。

### 环境要求

| 项 | 版本 |
|---|---|
| Node.js | 18 以上（开发环境为 24.21.0） |
| npm | 9 以上 |
| 浏览器 | Chrome / Edge 最新版 |

### 步骤

```bash
# 1. 获取代码
git clone <仓库地址>
cd campus-insight

# 2. 安装依赖
npm install

# 3. 配置环境变量
cp .env.example .env
# 打开 .env，填入大模型接口地址与密钥（见下表）

# 4. 启动
npm run dev

# 5. 打开终端里显示的地址，点「使用示例数据」
```

### 环境变量

| 变量 | 说明 | 示例 |
|---|---|---|
| `VITE_LLM_BASE_URL` | 大模型接口地址（OpenAI 兼容格式） | `https://api.example.com/v1` |
| `VITE_LLM_API_KEY` | 接口密钥 | `sk-xxxxxxxx` |
| `VITE_LLM_MODEL` | 使用的模型名 | `gpt-4o-mini` |

### 没有密钥也能看

图表部分**完全不依赖大模型**。未配置密钥时，页面会切换到内置文案模板，所有图表功能正常可用。

这同时也是本项目的一条设计底线：AI 解读是加分项，不是承重结构。它失效不影响产品成立。

## 技术栈

| 层 | 选型 |
|---|---|
| 构建 | Vite |
| 界面 | React 18 + Tailwind CSS |
| 图表 | ECharts |
| 表格解析 | PapaParse |
| 大模型 | OpenAI 兼容接口 + SSE 流式输出 |

无数据库、无后端服务、无部署依赖，纯前端运行。

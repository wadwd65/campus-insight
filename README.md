## 候选方向（未定稿）

官方给出 10 个选题方向，个人赛任选其一。当前在两个方向之间权衡，**尚未拍板**。

### 候选 A · 校园 / 垂直社区全栈 MVP（对应官方方向 6）

把一份表格数据（CSV / JSON）拖进网页，自动出图表，再由大模型生成一段人话解读。

- 大模型只负责写一段解读文字；写得不好，图表照常显示
- 出问题时有确定的报错信息，可复现、可描述给 AI
- 可分级退守：满配 → 图表 + 固定文案 → 纯图表工具，每一级都是可交付的产品

### 候选 B · 低代码与智能表单生成引擎（对应官方方向 4）

用自然语言描述需求，系统现场生成结构化表单或文档（例如按教师大纲生成含 LaTeX 公式的考卷）。

- 整个页面依赖大模型返回的结构才能渲染；结构不合格，页面空白
- 约一半缺陷是概率性的（同一句话时好时坏），不产生可复制给 AI 的报错
- 无中间退守层级：满配 → 白屏

### 关键差异

| | 候选 A | 候选 B |
|---|---|---|
| 大模型扮演的角色 | 附加解读，失效可降级 | 页面渲染的前提 |
| 缺陷是否可复现 | 是，有报错可复制 | 部分否，时好时坏 |
| 卡住后的退路 | 三级台阶 | 一级 |

> 以上为选型参考资料。**决定权在本人**，确认后本文件的产品定义部分据实补齐。

## 10 分钟极速复现指南

> 评审老师按这一节操作，十分钟内可看到完整效果。
> ⚠️ 项目骨架尚未生成，本节为结构骨架，命令在骨架落地后据实更新。

### 环境要求

| 项 | 版本 |
|---|---|
| Node.js | 18 以上（开发环境为 24.21.0） |
| npm | 9 以上 |
| 浏览器 | Chrome / Edge 最新版 |

### 步骤

```bash
# 1. 获取代码
git clone <仓库地址>
cd campus-insight

# 2. 安装依赖
npm install

# 3. 配置环境变量
cp .env.example .env
# 打开 .env，填入大模型接口地址与密钥（见下表）

# 4. 启动
npm run dev

# 5. 打开终端里显示的地址
```

### 环境变量

| 变量 | 说明 | 示例 |
|---|---|---|
| `VITE_LLM_BASE_URL` | 大模型接口地址（OpenAI 兼容格式） | `https://api.example.com/v1` |
| `VITE_LLM_API_KEY` | 接口密钥 | `sk-xxxxxxxx` |
| `VITE_LLM_MODEL` | 使用的模型名 | `gpt-4o-mini` |

### 没有密钥也能看

凡涉及大模型的功能都不是承重结构：未配置密钥时页面切换到内置文案模板，其余功能保持完整可用。

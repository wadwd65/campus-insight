**产品形态**：学习投入诊断看板

---

## 项目要做到什么

官方对方向 6 的原始描述：

> 数据源（CSV / JSON 或公开 API）→ ECharts / D3 动态图表大盘 → 大模型对长尾数据做趣味解读

**本产品的具体形态**：上传每日学习记录表，出来几张图表，大模型诊断学习模式。

要解决的问题：备考的人只知道「我学了多久」，不知道「我学得有没有用」。时长和正确率是两个维度，分开看都没问题，**交叉起来才看得出背离**——课时长最长的那一科，正确率可能最低。这个结论人不主动算就看不见。

```
一份学习记录 CSV  →  若干张图表  →  大模型写一段诊断
```

产品边界：无登录、无数据库、无后端、无部署依赖。数据只在浏览器内存里，刷新即清空。

### 环境要求

| 项 | 版本 |
|---|---|
| Node.js | 20.19 以上（开发环境为 22.22.2） |
| npm | 10 以上（开发环境为 10.9.7） |
| 浏览器 | Chrome / Edge 最新版 |

### 步骤

```bash
# 1. 获取代码
git clone <仓库地址>
cd campus-insight

# 2. 安装依赖
npm install

# 3. 配置环境变量（可选，不配也能看图表）
cp .env.example .env
# 打开 .env，填入大模型接口地址与密钥（见下表）

# 4. 启动
npm run dev

# 5. 打开终端里显示的地址（默认 http://127.0.0.1:5173）
```

### 环境变量

| 变量 | 说明 | 示例 |
|---|---|---|
| `VITE_LLM_BASE_URL` | 大模型接口地址（OpenAI 兼容格式） | `https://api.example.com/v1` |
| `VITE_LLM_API_KEY` | 接口密钥 | `sk-xxxxxxxx` |
| `VITE_LLM_MODEL` | 使用的模型名 | `gpt-4o-mini` |

### 没有密钥也能看

凡涉及大模型的功能都不是承重结构：未配置密钥时页面切换到内置文案模板，图表功能保持完整可用。

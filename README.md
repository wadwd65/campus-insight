# 你的大学平行宇宙 · Campus Insight

2026 传智杯 AI 创新应用挑战赛，校园 / 垂直社区全栈 MVP。程序 v37；材料校对日期 2026-10-23。

个人回答十道校园日常题，得到有计算依据的画像；管理员创建邀请式圈子，成员确认共享后，直接收集原始答卷、查看进度与导出，减少逐份传文件的操作。CSV 离线流程继续可用。

v37 根据测试者“整体像工具，缺少参与感”的反馈，将首页改为可试玩的三幕校园选择，十题加入生活片段反馈，报告增加可自选片段、填写短留言并保存PNG的纪念卡。试玩和留言均不改正式答卷。见 [v37 参与感改进与验收](docs/迭代-20261023-参与感与校园片段.md)。

v36 增加小车车内第一人称与独立环视、V切换视角、可见实体学生及驾驶坐姿、空格二段跳与实际屋面落地。左侧可直接进入屋顶跳跃练习，随时回到湖畔。详见 [v36 操作与验收](docs/迭代-20261023-人物驾驶与屋顶二段跳.md)。

v35 在独立3D校园增加基础驾驶小车，以及图书馆、自习室、食堂三间可进入的示意室内。支持安全上下车、障碍碰撞和随时返回校园，室内按进入/离开创建与释放。它是电脑端补充玩法，不改变测评或圈子答卷。见 [v35 操作与验收](docs/迭代-20261023-校园小车与室内.md)。

v34 支持直接注册并创建自己的圈子，自设6～12位密码，无需初始化口令；受邀加入其他圈子仍需有效邀请。已登录用户答完十题，可在“我的档案”选择圈子，核对共享范围并明确同意后直接提交，管理员本人也能填报。Windows x64即用包附带Node.js，提供开始使用、备份和打开数据位置入口；服务器使用通用部署包。当前行为与交付边界见 [v34 上线与交接](docs/上线与交接-20261023-v34.md)。

v33 是当前版本的历史设计基础：当时将主线统一为「校园生活档案」，先看模拟结果，再选择个人测评或圈子收卷。地图保留在可展开的补充区；页头、登录、分享信息与页脚采用同一套文案和视觉。公开静态体验与 Node 完整账号服务的能力分开说明，历史记录见 [v33 上线与交接](docs/上线与交接-20261023-v33.md)。

v31 面向不熟悉电脑的使用者：首次提供可跳过的三步指引，平时可点“使用帮助”重看；登录可跳过进入个人测评，问卷手动点“下一题”，支持暂停续答；成员与管理员按各自任务逐步操作。登录与注册仍独立，新密码6～12位，旧长密码兼容。详细改动和验收见 [v31 记录](docs/迭代-20261022-新手指引与体验优化.md)。

v32 新增首页一键48人合成班级、前置来源与统计范围、少于5份仅显示直接选择统计，以及真实账号/部署能力状态。手机操作入口先于长说明，主站完整复现以规则计算和本地解读为基线，在线模型为可选项。详见 [v32 实现与验收](docs/迭代-20261022-评委视角自查与优化.md) 和 [往届作品对比](docs/往届相近作品对比-20261023.md)。

## 当前版本与访问方式

- 完整功能是 React + Vite 前端、Node.js 同源服务、私有 SQLite 和可选模型接口。个人测评不需账号，在线圈子需注册登录。
- [公开仓库](https://github.com/wadwd65/campus-insight) 保留 95 次真实提交。2026-10-22 核对远程与本地已提交 HEAD 为 `c5713de`；当前v37工作区新增变更尚未提交同步。评审当前成品请使用v37同轮源码或管理员运行包，该 HEAD 不包含v37全量成品。
- [历史公网静态演示](https://campus-insight.app.workbuddy.host/) 首页 HTTP 可访问，但账号会话 API 返回 404，尚未承载新版完整账号服务。本机 `127.0.0.1` 地址不能发给异地成员使用。
- 最新参赛包提供“源码校对版 ZIP”和管理员 ZIP。源码 ZIP 包含当前未提交工作副本，历史 Git bundle 单独归档，不通过伪造日期补齐过去记录。
- 技术文档、两个 AI 的原始对话链和录制素材随参赛附件提供。最终 5-8 分钟 MP4、仓库同步和个人中心提交仍待完成；录制分镜不等于最终视频。

## 10 分钟本机复现

环境：Node.js **24.21.0 或更高**，自带 npm；现代桌面浏览器。Windows 中文及带空格目录已实测。首次安装 Node、慢网络下载、其他操作系统的耗时不在十分钟实测承诺内。

从本轮源码 ZIP 解压进入项目目录：

```powershell
npm ci
npm run build
npm start
```

打开启动日志打印的网址。默认同源服务提供网页与 API；配置项见 [.env.example](.env.example)。无需模型密钥即可运行规则计算、本地解读和账号圈子。开发调试可用 `npm run dev`，不要用纯静态预览代替同源后端验收。

如果使用已构建的管理员运行包，先完整解压，打开最外层的“先看这里.html”。Windows x64即用包直接双击“开始使用.cmd”即可。通用部署包需要先安装一次Node.js 24.21或更新版本。不需要安装 npm 依赖、填写技术配置或查找初始化口令。网页上直接注册并创建自己的圈子。下次仍双击“开始使用”，登录原账号。

### 按顺序体验

1. 跳过或播放片头，首次可按指引选择用途，也可“跳过引导”。主页选择“开始测评”，每题选一个答案再点“下一题”，答完查看报告与选项贡献。可“稍后填写”返回，下次接着答；临时换答只重算预览，不修改已提交答卷。
2. 使用 `public/data/示例-班级问卷.csv` 查看合成班级；或从个人报告导出答卷，上传多个兼容文件合并。示例数据不是真实班级调查。
3. 从右上角账号入口直接注册，选择“创建圈子，我当管理员”，设置自己的账号与6～12位密码。成员通过邀请加入。答题后在档案页直接选择圈子并确认提交。只体验个人测评可暂不登录。
4. 成员答完十题后核对共享范围并明确确认提交；管理员查看原始十题、提交时间与进度，再按名称/状态查找或导出。普通成员仅可查看自己的答卷，支持撤回和重交。
5. 行动地图可安排四个时段，确认前先看本次实际增量；重复访问有衰减。独立 3D 校园用于自由参观，不更改个人画像。

## 规则、数据与在线 AI

- `matrix.json`、`surveySchema.js` 和 `results.js` 统一题目、选项、八维属性与百分位计算。负值在累加阶段保留，贡献可追溯；佛系为派生属性。
- 相对位置参考 **2000 条脚本模拟基准**，不是全国大学生调查。时间分配与四年曲线是规则叙事，不能用于能力评价、心理评估或预测个人未来。
- 数据源在 `public/data/`：基准和 48 人班级均为合成数据。用户自己的 CSV 在浏览器解析；圈子答卷只在成员明确提交后进入同源私有数据库。
- 模型只负责在已有统计范围内组织文字，不负责修改数值。服务配置放在服务端环境变量或私有文件，字段见模板；不要把密钥写进前端变量或公开仓库。
- 有先前真实在线联调记录，近期 UI 验收使用本地回退。演示以页面实际“在线/本地”状态为准，未配置或失败时继续提供规则解释。

## 两种部署与交接

同一包可供管理员独立部署，也可由维护者提供公共站点。正式异地访问需要可持续运行的 Node 服务、HTTPS 和持久磁盘，纯静态托管只能提供部分体验。不同实例不会自动同步账号和答卷。

引导配置使用 `npm run configure`。备份使用 `npm run accounts:backup`；恢复到全新空数据目录，启动前使用 `npm run accounts:restore`。详细参数见 [双方案部署与交接](docs/双方案部署与交接.md)。整站备份含私人数据，与公开通用运行包分开保管；恢复后旧会话与旧邀请失效，需要重登、重发邀请。

Docker / Caddy / HTTPS 模板位于 `deploy/`，尚未进行实际容器与公网部署验收。Windows 同机解压、配置、启动、建圈、提交、导出、重启及空目录恢复已有实测；这不等于零基础新手或真实异地并发验证。

## 架构与边界

| 模块 | 职责 |
|---|---|
| `src/App.jsx`、页面组件 | 个人报告、问卷、圈子工作台与导航 |
| `src/lib/results.js` 等领域模块 | 规则计算、输入契约、选项贡献、CSV 校验和导出 |
| `src/lib/accounts.jsx` | 账号状态与同源请求，服务端仍独立校验授权 |
| `server/index.mjs`、`server/accounts.mjs` | 静态网页、账号/圈子 API、私有 SQLite、同源写请求保护 |
| `server/ai.mjs` | 可选模型转发、结果校验与回退，密钥不进入前端 |
| `map-src/`、`scripts/build-campus-web.mjs` | 按构建生成独立 3D 静态页面与资源，主站按需打开 |

密码使用 scrypt，随机会话只保存哈希，Cookie 为 HttpOnly / SameSite，HTTPS 时使用 Secure；写请求检查 Origin 与 CSRF。成员权限、跨圈访问和导出范围在服务端校验。邀请链接令牌进入后清理，注册与已有账号加入路径明确区分。

3D 沿用 v24 的天空、建筑、草木、第一人称、跳跃和建筑点选；手机入口受限以控制资源。地图布局来自参考导览图人工标定，不能作实际导航。不要同时打开多个 3D 场景；历史面数、draw call 或后台节流样本不能当成本版前台 FPS。内存闪退的根因尚未证实。

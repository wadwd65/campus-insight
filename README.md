# 校园行迹 · 你的大学平行宇宙

十个校园日常选择，一份能回看的个人档案。无需注册即可答题、查看解读与图表；班级或社团需要一起收卷时，再使用邀请圈子。

2026 第九届传智杯参赛项目。业务版本 **B-v53.3**，独立3D版本 **v30.2**；本次为 **2026-11-12 交付修订**，整理启动、安装和复现入口，保留原问卷、权限及数据规则。

## 先在自己的电脑上打开

**Windows接收者：**将参赛材料里的“Windows离线即用包”全部解压，双击 **开始使用.cmd**。包内已带Node运行时，首次启动不需要安装开发工具或下载npm依赖。想保留桌面入口，可运行 **安装到此电脑.cmd**。

**从本仓库下载：**点 **Code → Download ZIP → 全部解压缩**，再双击 **开始使用.cmd**。它优先使用包内或本机的Node；缺少合适版本时，下载并校验完整Node便携包（包含npm），保存在本项目内。这个首次下载需要联网。

已有 **Node.js 24.21.0+** 和Git，也可以直接：

```sh
git clone https://github.com/wadwd65/campus-insight.git
cd campus-insight
node server/index.mjs
```

浏览器打开 **http://127.0.0.1:5191/**，先填十题即可。直接启动使用仓库已提交的 `dist/`，**不需要先运行 `npm ci`**。

## 可以怎样体验

1. **自己的档案：**首页 → 填写十题 → 个人解读与五维图表。可暂停续填、预览改答后的计算结果，再确认更新。
2. **校园一天：**在情境地图里做选择，带回答题建议；原有人工答案保留，每题由本人核对，最后十题统一生成报告。
3. **一起收卷：**注册时选“创建圈子”，自设6～12位密码。成员使用邀请加入，看清共享范围并明确同意后提交；管理员可查看本圈已提交的原始答案、时间及汇总。
4. **可选探索：**首页可打开合成班级示例和独立3D参观。3D为艺术化校园，不会自动修改问卷或把答卷提交给圈子。

个人报告使用本地规则和2000条模拟基准，不代表真实学生排名、心理诊断或未来预测。在线模型是可选扩展，默认未连接；本地统计、规则解读、账号与圈子不依赖模型密钥。

## 从源码重新构建

这条路线会下载前端依赖，并重新产生网页构建，和上面的“直接启动成品”分开验收。

**Windows可双击“重新构建并启动.cmd”**：自动准备Node与npm，按锁定依赖安装、构建、校验，再打开网站。它不改系统PATH，也不要求管理员权限。命令行等价步骤如下：

```sh
npm ci
npm run build
npm run verify:dist
npm start
```

开发界面用 `npm run dev`；交付前的完整检查为 `npm run check`。DOM测试不等于真实浏览器走查，问卷、图表、账号切换、手机布局和3D仍需分别验证。网络速度与是否已有Node会影响耗时，10分钟是本项目的复现目标，不是任意环境的保证；实测前提与结果见[验收记录](docs/交付验收-20261112.md)。

## 给其他人访问与保留数据

`127.0.0.1`只供本机使用。多人远程访问需要Node服务器、HTTPS及持久数据目录，详见[部署交接](docs/给部署者的交接.md)和[两种部署方式](docs/双方案部署与交接.md)。

- 服务器读取项目根目录的 `dist/`，启动入口为 `node server/index.mjs`，也可 `npm start`。修改前端源码后必须重新构建。
- 将 `.env.example` 复制为私有 `.env.local`，设置正式 `APP_ORIGIN`，由平台提供 `HOST`、`PORT` 和 `CAMPUS_DATA_DIR`。环境变量模板不是实际凭据。
- 默认数据在 `.campus-data/`，升级前先备份并保留。Windows提供 **备份我的数据.cmd**、**打开数据文件夹.cmd**；安装版以启动器显示的数据位置为准。
- 安装版和原便携版不自动共用账号、搬迁数据。原包已有账号时，可继续使用原入口，或先备份，再按恢复说明迁移到新的空数据目录；安装根目录也提供备份工具。
- 不公开 `.env.local`、数据库、账号备份或密钥。源码和交付包不会包含现有用户账号；程序更新也不应替换原站点持久数据。
- 仓库更新不等于公网自动更新。更新原实例后运行 `npm run verify:live -- https://你的网站`，再按[发布验收](docs/发布验收.md)复查实际流程。反向代理配置按真实网关填写，默认不信任转发来源头。

# 你的大学平行宇宙

> 2026 第九届传智杯全国大学生数智创新与 AI 应用大赛 · AI创新应用挑战赛
> 个人赛 · B 组

**选题方向**：方向 6（校园 / 垂直社区全栈 MVP，数据看板类）
**产品形态**：个人青春行为图谱生成器 —— 答 6 题，30 秒生成一份专属的「大学时代数据叙事报告」

---

## 这是什么

```
答 6 道有画面感的选择题（约 30 秒）
        ↓
8 个潜在属性的连续值 × 与 2000 人基准人群比对
        ↓
五件套报告：雷达图 · 时间分配环形图 · 四年心情曲线 · 人群冷知识 · 大模型个性化总结
```

**它和你见过的所有「数据看板」都不一样的地方在于**：

普通看板让你**看别人的数据**。这个产品让你**成为数据源** —— 不需要账号、不需要上传、不需要安装任何东西，只需要回答几个有共鸣的简单问题，然后看到一份属于**你自己**的报告。

人类对自己的好奇心，远大于对抽象数据的好奇。这是本产品唯一依赖的机制，也是它最难被复制的地方。

**示例输出**（真的跑出来的，不是设计稿）：

> 在「学术投入」上，你超过了 98% 的大学生 —— 你的书桌像有结界，坐下就能学进去
> 你的称号：**图书馆常驻民**
> 四年曲线：大一 59 → 大二 66 → 大三 71 → 大四 65（「别人开始慌的时候，你在按表推进」）

## 官方要求与本产品的对应

官方对方向 6 的原始描述：

> 数据源（CSV / JSON 或公开 API）→ ECharts / D3 动态图表大盘 → 大模型对长尾数据做**趣味**解读

| 官方要求 | 本产品对应 |
|---|---|
| 数据源（CSV） | `public/data/问卷基准数据.csv`（2000 条模拟问卷）；真入口另可上传自己的 CSV |
| 动态图表大盘 | ECharts 雷达图 / 环形图 / 折线图，均带入场动画 |
| 长尾数据 | 8 个潜在属性的分布，以及「你排在人群第几」的百分位 |
| **趣味**解读 | 大模型生成带称呼的个性化总结 + 称号 + 冷知识句 |

## 核心设计

产品最要紧的技术含量在**映射矩阵**：6 个问题、28 个选项，为什么能撑起四个维度各异的输出？

答案是插一层 **8 个潜在属性**作为中间层 —— 每个选项同时影响多个属性，而四套派生规则各自从属性出发。于是「选项数少、输出维度多」这个矛盾被解开，而两个人只要有一题不同，8 维向量就会分叉，分叉会同时传导到所有输出上。

完整设计（含 8 个属性的定义、28 个选项的增量矩阵、四套派生公式、两道自动闸门）见 **`docs/设计-01-问题与映射矩阵.md`**。

**「结果因人而异」不是一句口号，是有闸门守着的**：`npm run selftest` 会随机生成 5000 份作答，量化检验输出分化度。实测雷达图两两平均距离 70.0（门槛 18），200 对抽样中重复 0 对。

### 环境要求

| 项 | 版本 |
|---|---|
| Node.js | 20.19 以上（开发环境为 22.22.2） |
| npm | 10 以上 |
| 浏览器 | Chrome / Edge 最新版 |

### 步骤

```bash
# 1. 获取代码
git clone <仓库地址>
cd campus-insight

# 2. 安装依赖
npm install

# 3. 配置环境变量（可选，不配也能看完整报告）
cp .env.example .env
# 打开 .env，填入大模型接口地址与密钥（见下表）

# 4. 启动
npm run dev

# 5. 打开终端里显示的地址（默认 http://127.0.0.1:5173）

# 6.（可选）跑一遍计算层自检，看「结果因人而异」的量化证据
npm run selftest
```

### 环境变量

| 变量 | 说明 | 示例 |
|---|---|---|
| `VITE_LLM_BASE_URL` | 大模型接口地址（OpenAI 兼容格式） | `https://api.example.com/v1` |
| `VITE_LLM_API_KEY` | 接口密钥 | `sk-xxxxxxxx` |
| `VITE_LLM_MODEL` | 使用的模型名 | `gpt-4o-mini` |

### 没有密钥也能看

大模型不是承重结构：未配置密钥或接口不可用时，页面切换到**内置文案模板**，图表与百分位保持完整 —— 「自己答完看到自己的结果」这个核心机制不依赖任何外部服务。

⚠️ `public/data/问卷基准数据.csv` 为**模拟生成**，不是真实调查结果，不含任何真实个人信息。

## 项目要做到什么

官方对方向 6 的原始描述：

> 数据源（CSV / JSON 或公开 API）→ ECharts / D3 动态图表大盘 → 大模型对长尾数据做趣味解读

技术链路固定为三段：

```
一份表格数据  →  图表呈现  →  大模型写一段人话解读
```

三个候选方案共用这条链路，差别只在「喂进去的是什么数据」。因此**产品定义尚未写定**，选定后据实补齐本节。

### 环境要求

| 项 | 版本 |
|---|---|
| Node.js | 18 以上（开发环境为 24.21.0） |
| npm | 9 以上 |
| 浏览器 | Chrome / Edge 最新版 |

### 步骤

```bash
# 1. 获取代码
git clone <仓库地址>
cd campus-insight

# 2. 安装依赖
npm install

# 3. 配置环境变量
cp .env.example .env
# 打开 .env，填入大模型接口地址与密钥（见下表）

# 4. 启动
npm run dev

# 5. 打开终端里显示的地址，使用内置示例数据
```

### 环境变量

| 变量 | 说明 | 示例 |
|---|---|---|
| `VITE_LLM_BASE_URL` | 大模型接口地址（OpenAI 兼容格式） | `https://api.example.com/v1` |
| `VITE_LLM_API_KEY` | 接口密钥 | `sk-xxxxxxxx` |
| `VITE_LLM_MODEL` | 使用的模型名 | `gpt-4o-mini` |

### 没有密钥也能看

凡涉及大模型的功能都不是承重结构：未配置密钥时页面切换到内置文案模板，图表功能保持完整可用。

# 你的大学平行宇宙 · Campus Insight

以十题校园生活问卷为核心的互动网站。先回答自己的选择，再看五维解读与图表；也可以玩一段校园一天，把行动转成待核对的答题建议。需要一起收集反馈时，管理员创建圈子，成员在知情确认后提交自己的答卷。

2026 第九届传智杯参赛项目。当前本地版本 **B-v53.1 · 2026-11-11**，本轮说明见 [布局与流程复查](docs/布局与流程复查-20261111.md)，上一轮记录见 [新手体验优化](docs/新手体验优化-20261111.md)。公网配置与发布由原部署方处理，详见 [公网部署交接](docs/公网部署交接-20261111.md)；此前记录见 [接手修复验收](docs/接手修复验收-20261110.md)。本次修改尚未部署，线上是否更新以实际发布核验为准。

## 先体验什么

- **个人体验**：进入网站 → 开始十题 → 查看个人档案。无需注册；可以暂停，在同一标签页恢复已保存的档案。
- **校园探索**：地图与校园一天是可选入口。行动提供问卷建议，原答案优先，每题仍由本人核对；游戏不替代问卷。
- **看看群体统计**：首页可打开48份合成示例。答完本人十题后可比较，并进入自己的完整档案。示例编号不代表真实同学。
- **一起收卷**：注册时选择创建圈子，自己成为管理员。其他成员用邀请加入，只能查看自己的答卷；管理员可看本圈已提交的原始答案、提交时间和汇总。管理员本人也能填报。

## 在自己的电脑上打开

1. 从仓库的 **Code → Download ZIP** 下载，右键“全部解压缩”，保留解压后的文件夹。
2. 安装 **Node.js 24.21.0或更高版本**。本轮在24.21.0验证；账号服务需要Node内置SQLite。
3. 在项目文件夹安装一次依赖：`npm ci`。
4. Windows双击最外层 **开始使用.cmd**；其他系统运行 `npm start`。
5. 浏览器打开 `http://127.0.0.1:5191/`。个人体验直接开始；需要圈子时在网页上注册，自设6～12位密码，无需初始化口令。

下次仍从同一个文件夹启动。Windows可用 **备份我的数据.cmd** 和 **打开数据文件夹.cmd** 管理自己的数据。

仓库内提供源码与构建好的 `dist/`。Windows自带运行时的“解压即用包”、服务器通用包和录制素材不随公开仓库分发，需要由提供者另行交付。**仓库ZIP本身不含Node运行时，也没有两个现成部署ZIP。**

## 修改和验证

开发时运行 `npm ci`、`npm run dev`。交付前运行 `npm run check`，通过后运行 `npm start`。

`check` 包含源码计算、服务端权限、生产构建、资源完整性、模拟班级完整操作流程和反代限流等检查。React DOM流程测试省略图表像素渲染；通过后仍需真实浏览器核对页面、图表、手机布局和真实账号操作。

生产服务固定读取项目根目录的 `dist/`，启动命令为 `node server/index.mjs`（`npm start`）。改源码后，需重新构建并发布该目录。

## 部署给其他人访问

本机的 `127.0.0.1` 地址仅限这台电脑使用。多人访问需要完整Node服务、HTTPS反向代理和持久化数据盘。

- 将 `.env.example` 复制为 `.env.local`，填写真实网站的 `APP_ORIGIN`。密钥和私有配置不放进公开仓库。
- 由平台设置 `HOST=0.0.0.0` 和实际 `PORT`，启动 `npm start`。
- 数据默认保存在 `.campus-data/`。云端使用私有持久磁盘，并通过 `CAMPUS_DATA_DIR` 指定目录。更新前先备份，迁移时恢复账号、圈子与答卷。
- 经过反向代理时，维护者须按真实网关地址设置 `CAMPUS_TRUSTED_PROXIES`。默认忽略转发来源头，不猜测平台网络范围。
- 部署后运行 `npm run verify:live -- https://你的网站`，再按 [发布验收](docs/发布验收.md) 完成真实操作。版本号、源码摘要和实际功能一起核对，Vite资源文件名无需固定。

## 数据与解读边界

十题通过同一套映射矩阵生成个人解读与五维图表。百分位参照的是模拟基准，结果用于表达校园生活选择，不是心理诊断、人格鉴定或真实总体排名。

本人答卷保留在当前标签页的会话存储，圈子提交需要单独确认。管理员只接收明确提交到本圈的答卷。更换账号、返回、刷新及异常路径须分别验收，不能用单条成功路径代表全部权限流程通过。

在线模型服务是可选扩展。未配置时仍提供规则计算和本地解释，不把本地解释称作真实模型输出。模型密钥仅由服务端读取。

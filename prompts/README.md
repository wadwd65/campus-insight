# prompts/ · 与 AI 的对话记录

这个目录是**「过程可复现性」这一项的物证**。评委据此判断代码是不是真的一步步演进出来的。

## 命名

```
prompt-001-<短标题>.md
prompt-002-<短标题>.md
```

三位数递增，不跳号。只记录**产生了代码变更**的对话。

## 每个文件写四段

```md
## 1. 我的提问
（原话照抄）

## 2. AI 的回复要点
（抓关键，不必全文）

## 3. 哪里不对 / 我实际需要什么
（哪个页面、什么操作、期望什么、实际什么）

## 4. 追问与最终结果
（怎么纠偏的，最后成了没有）
```

模板文件：`_模板.md`

## 已归档

| 编号 | 主题 | 偏差是什么 | 怎么发现的 |
|---|---|---|---|
| `prompt-001` | 选题方向与越权纠正 | AI 在只被问「这两个方向要做什么」时，直接下了结论并改了四处文件 | **我指出**：我还没有选，你就直接帮我选好了 |
| `prompt-002` | 示例数据与转折点检测 | 转折点检测算法系统性偏晚 12 天（用了滞后平均 + 阈值法） | **自检脚本**：任务表里预先写下的「误差 ≤ 3 天」被转成了可执行校验 |
| `prompt-003` | 方案定案与映射矩阵偏差 | 三处：①问卷数据照搬学习记录的去重规则，误删 449 条真人 ②环形图三类共用一个权重下限，塌缩成同一个百分比 ③派生属性漏配文案，输出成「—— 」后面空着 | **自检脚本**：三处全部由量化闸门发现，人眼一次都看不出来 |

这三条的发现方式构成一条递进的线：**001 靠人**（我当场纠正），**002 靠判据**（任务表里预置的阈值），**003 靠闸门**（输出分化度这类连判据都不好写、只能量化检验的指标）。

**003 那种偏差最值得记**：误删 449 条不会让程序报错，塌缩的百分比不会被任何人注意到，空文案看起来只像一句没写完的话。如果只在文档里写一句「结果因人而异」，这三件事一件都发现不了。

## 注意

第 3 段最值钱。AI 一次就对的部分没什么可记的，**它错了、你怎么发现的、你怎么把它掰回来的**，才是赛事要看的。

赛事要求至少 3 条完整的「提问 → 偏差 → 修正 → 收敛」链条，所以这个目录会一直写下去。

# 026 · 账号登录与邀请圈子 · 2026-10-22

## 1. 我的提问

> 增加账号登录系统，看一下我们可以是做本地端还是做云端的。我的设想是到时候管理员就可以邀请其他的用户进入一个小圈子里面，管理员可以查看其他用户填报的东西，就不用用那个拖动文件了。

## 2. AI 的回复要点

建议以云端多人使用为目标，先在本机完成全套流程：成员凭邀请注册，只能查看自己的填报；管理员查看圈内原始答案、提交时间及汇总画像，提交前告知成员。使用同一套前端和 Node 服务，账号与答卷放在服务端数据库中，避免浏览器本地假登录。

## 3. 哪里不对 / 我实际需要什么

用户确认上述权限范围“符合，按这个做”；关于服务器，用户回复“看到时候具体怎么做吧，这方面我的知识量很少。我也不知道怎么做这个云服务器”。因此没有要求用户先选平台或购买资源，而是把本机可验收功能与日后部署说明一并准备。

## 4. 追问与最终结果

完成一次性初始化、账号登录/改密/退出、管理员建圈、限时限人数邀请码、成员注册和加入、按账号与圈子隔离的问卷草稿、十题核对及确认后在线提交、重交/撤回、管理员查看原始答卷/提交时间/汇总、移除成员与数据备份。首页和页头提供入口，个人测评及地图继续可用。

完整 check 通过，账号专项 47 项、生产服务 8 项通过。真实浏览器以隔离合成账号完成邀请填报和管理员读取，手机无横向溢出；生产启动包也独立走通同源账号和数据流程。依赖补丁更新后审查为 0 项已知漏洞。交付 Node 启动包及新手指南，不含密钥、数据库、初始化口令或测试账号。未购买服务器，未发布公网；正式平台、HTTPS 与持久卷在用户准备给别人使用时再一起完成。

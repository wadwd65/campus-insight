# prompt-017 · 主站体验收尾

## 1. 我的提问

> 这边还剩下一点额度，我去优化一下网站，今天就结束。然后辛苦两天，差不多就把这个项目先给他做完就差不多了

## 2. AI 的回复要点

做小范围主站收尾：首页班级入口更醒目，问卷增加暂停回首页，首页根据现有有效草稿显示继续测评与题号；整理手机排版，不增加新动效与评分规则。

## 3. 哪里不对 / 我实际需要什么

原班级入口仅是一行较弱的链接；原问卷虽有草稿，首页没有明确续答反馈，中途缺少专门的暂停入口。实施中发现暂停不能直接复用取消回调，因为从班级画像进入答题时取消会返回班级页，和「回到首页」文案不符，最终分开处理 onPause 与 onCancel。

## 4. 追问与最终结果

浏览器完成答两题、第三题暂停、首页显示3/10、继续生成报告的完整流程，并核对完成后草稿清除；班级入口成功读取48人模拟CSV并生成画像，390像素手机页无横向溢出。完整 npm run check 通过，资料集中交付至v17目录，地图保持v16。详见 docs/迭代-20261020-主站体验收尾.md。

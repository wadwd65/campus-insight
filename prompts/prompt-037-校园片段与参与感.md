# Prompt 037 · 校园片段与参与感

日期：2026-10-23。本文件为需求/实现摘要，不冒充原始对话或录屏。

用户：“我找了几个人测试了网站，他们说这个网站很单调。你看有什么能优化的？”随后明确：“整体像工具，缺少参与感”。

实施：把主站参与放在首页较早的位置，以正式题库选项做三幕可试玩的校园小剧场；答题用生活片段和本人原始选择作反馈；结果页允许选一幕、写一句自己的话，并真实保存为PNG纪念卡。试玩/留言不改正式答卷，提供跳过和重玩，不增加虚假人气或自动填写。

验收：完整检查、新增5项规则与输入边界、5项离线React交互、真实SVG/PNG导出与图像检查。没有把这些内部检查说成真实浏览器或测试者满意度已提升；需要原测试者继续复测。详见docs/迭代-20261023-参与感与校园片段.md。

# 020 · 桥面闪烁与体育场避路修正 · 2026-10-21

## 1. 我的提问

> 现在目测的问题就是那个桥它在拖动的时候会产生一些就是。嗯闪烁，就是某些模块，然后就是这个这个体育场，它的部分边边角角到公路上面去了

## 2. AI 的回复要点

检查桥面重叠与深度冲突，再核对体育场边缘与道路的交叠；修正几何后在浏览器拖动、换角度与缩放检查。

## 3. 哪里不对 / 我实际需要什么

此前只验证建筑主体没有穿路，没有覆盖体育场矩形底座、看台与护栏。湖边矩形步道在转角以同一顶面高度相互压叠，之前结构测试未检查共面重叠。用户的目视反馈暴露了这两个验证缺口。

## 4. 追问与最终结果

本轮无额外追问。桥面改成连续共享接边几何；体育场改成弧形外廓，按道路与人行边带净距统一收边，保留中心。增加针对实际渲染三角形的重叠与道路净距回归检查，全项目检查和 41 项 3D 检查通过；浏览器正反拖动复核、截图、部署包与校验完成。没有虚构用户已再次确认修正满意。

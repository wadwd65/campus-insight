## 2. AI 的处理方案

把“需要更多指引”落实到首页、账号、答题、圈子和报告各自的下一步，而不是增加一个只能看完才能使用的教程。

首页和圈子提供三步轻量指引，区分个人体验与圈子填报 / 收卷，随时跳过并能重看。新手指引使用原生弹窗、独立 CSS 和代码内原创 SVG；没有调用秋绘，也没有新增位图素材或第三方依赖。

登录 / 注册继续独立，错误输入就地解释并聚焦。允许先跳过登录做个人十题；个人入口明确清除圈子上下文。答题使用手动下一题、可收起的说明、暂停续答、清空前确认；报告提供阅读与保存入口，页内锚点不改变站内路由。

管理员看到建圈、邀请、收卷步骤；成员看到加入、填写、核对提交步骤。提交前说明共享范围，允许稍后提交。答完题只生成报告，只有明确同意并点击提交，管理员才会收到答卷。

## 3. 自查发现的问题与修正

- 不能把“跳过指引”“暂不登录”“稍后填写”“稍后提交”混为一谈。分别关闭说明、进入个人体验、保留草稿和保留待提交答案，不自动填写或交卷。
- 管理员和成员需要的说明不同。圈子指引同时解释成员用邀请和管理员可创建圈子；全新站点由网站管理员先开通，不让普通成员寻找私有口令。
- 浏览器存储可能不可用。引导偏好只存版本与状态，增加本页面内存兜底；草稿仍明确属于本标签页，不能承诺关闭后一定恢复。
- 写入成功后列表读取失败，不能误报整次操作失败。保留成功结果，提示重新加载，减少重复创建或加入。新圈子加载后聚焦圈子名称，有弹窗时不抢焦点。
- 提交网络中断后可能已经保存，不能直接引导重复点击。先返回圈子核对收到状态；没有同意共享时，提交始终不可用。
- 手机上的下一步需要持续可见，说明可以收起，避免装饰和长说明挤走核心操作。

# v14 诊断书 —— 为什么 v13 还是"玩具感"

对照物：`27837116_d.jpg`（1536×1536 实拍，机位「实验楼」）
渲染物：`shot-tower.png`（1410×865，v13b）

---

## 一、七个硬伤（每一条都有实拍证据）

### ① 屋顶坡度太缓 + 出檐太宽 ⇒ 读成"帐篷"

| 项 | 实拍量值 | v13 用的 |
|---|---|---|
| 屋面坡角 | **≈ 26~28°**（四条戗脊很长、正脊很短） | 0.42 rad = **24°** |
| 出檐 | **≈ 0.7m**（贴着实墙，几乎看不出挑出） | **1.10m** |
| 正脊长度 | **很短**（约为屋面总长的 40%） | `a*0.58`，偏长 |
| 屋面占建筑立面高度 | 俯视下**屋面面积 ≈ 建筑投影的 45%** | 目测约 30% |

**实拍证据**：`q-b1.png` 中，左上那栋的四坡顶，四条戗脊从四个檐角向中心收，
**正脊只有中间一小段**；屋面几乎是"金字塔"感，而不是"长条帐篷"。

⇒ **v14 改**：坡角提到 `0.48`（27.5°），出檐收到 `0.75`，正脊占长比降到 `0.34`。

---

### ② 墙太"浅"、窗太"碎" ⇒ 立面读成"马赛克瓷砖"

实拍砖墙**直方图主峰**（全图 13133 个砖红像素）：

```
(156, 84, 72)  ← 主色 #9C5448
(144, 72, 72)  ← 暗面 #904848
(156, 96, 84)
(168, 108, 96) ← 亮面 #A86C60
```

我 v13 用的 `makeBrickTex` 基色是 `rgb(214,146,110)` = `#D6926E`，
**R 高了 58、G 高了 62、B 高了 38** —— 整面墙"发白泛粉"，这是"塑料玩具感"的第一来源。

更关键的是**砖的饱和度**：实拍砖是 **R−G = 72**（很高），我的是 **R−G = 68** 但整体亮度太高，
导致对比度被稀释。⇒ 必须**降亮度、保饱和**。

另外实拍砖的**尺度**：在 1536 图上，一层楼高约 60px，砖的行高约 **3.2px**
⇒ 一层楼排 **约 19 行砖**。v13 的贴图一张 1.0m 排 19 行 ⇒ 一层楼（3.9m）排 **74 行** ——
**砖小了 3.9 倍**，远看自然糊成一片纯色。这是"没有砖感"的真凶。

⇒ **v14 改**：
- 砖色基色 → `#A85A48`（约 `rgb(168,90,72)`），抖动范围收窄到 0.90~1.10
- 灰缝色 `#C8B49C` → 更暖的 `#B8A48C`，且**缝宽收细到 1px**
- 贴图物理尺寸从 1.6m×1.0m 改为 **1.6m×2.0m**（一张贴图 = 2m 高 = 约半层楼）
  ⇒ 一层楼约 2 张贴图，砖行 ≈ 每层 19~20 行 ✓

---

### ③ 窗的**比例反了** —— 实拍是"横向扁窗"，我做成了"近方形窗"

实拍量（`q-fac.png` 右下角那栋的立面，4 开间）：
- 开间中心距 ≈ **3.4m**
- 窗净宽 ≈ **2.05m**（占开间 **60%**，不是 40%！）
- 窗净高 ≈ **1.75m**（**比宽小** —— 扁窗）
- 窗下墙 ≈ **0.75m**，窗上墙 ≈ **1.40m**

v13 做的是 1.5m 宽 × 2.05m 高的**竖高窗** ⇒ 方向完全相反。

**这是"马赛克感"的第二真凶**：竖向高窗在斜视角下密集排列 ⇒ 读成"瓷砖格子"。

⇒ **v14 改**：`winW = 2.05`（固定，不随开间浮动）、`winH = 1.75`、窗下墙 `0.75m`。

---

### ④ 缺少"深色带" —— 实拍立面是"砖红 + 深蓝黑"两条大色块

实拍立面的**结构**（`q-fac.png`）是：

```
▓▓▓▓▓ 深蓝灰檐口带（约 0.9m，很宽，存在感极强）▓▓▓▓▓
   砖红墙（0.55m）
▓▓▓ 深蓝黑玻璃窗带（1.75m，连续得很长，几乎不断）▓▓▓
   砖红墙（0.75m）
   …重复…
```

**我 v13 的问题**：窗与窗之间留了 60% 的砖墙 ⇒ 立面变成"砖墙为主、窗是点缀"；
实拍恰恰相反 —— **窗带是主，砖墙是次**，深色玻璃面积甚至比砖还多。

⇒ **v14 改**：窗宽 60%、窗与窗之间砖垛仅 1.35m；并且窗玻璃**加深到近乎黑蓝**
（实拍深色像素主峰是 `(0,0,8)`，纯黑偏蓝）。

---

### ⑤ 屋面颜色"太干净" —— 实拍屋面的蓝是**高饱和它**，我做的是"灰蓝"

实拍屋面蓝直方图主峰：

```
(120,144,192)  ← 主色 #7890C0
(108,144,192)  ← #6C90C0
(132,156,204)  ← 亮坡 #849CCC
(96,132,180)   ← 暗坡 #6084B4
```

关键：**R 只有 96~132，B 有 180~204，B−R ≈ 72~96** —— 非常"蓝"。
我 v13 的 `roofLit 0x7A8FA6` = `(122,143,166)`，**B−R 只有 44**，只有实拍的一半 ⇒ 读成"灰瓦"。

⇒ **v14 改**：`roofLit → 0x7E96C4`（`126,150,196`）、`roofDark → 0x5E7AAE`、
`ridge → 0x4A6288`。

---

### ⑥ **没有竖向贯通玻璃带**（v13 加了但看不见）

v13 的 `verticalGlassBand` 被 `windowRow` 的窗阵列**盖住了** ——
因为两者在同一平面上，窗阵列先画、竖带后画但 z 偏移只有 0.14m，
在斜视角下**竖带插进了窗阵里而非独立出来**。

实拍真相（`q-b1.png` 右下角）：楼梯间的竖带是**独立的、比窗更深、通高不受楼层分割**，
宽度约 1.6m，位置在**楼体端部**（不是开间中部）。

⇒ **v14 改**：竖带只放在楼体**端部**，且**不画窗阵列**（该开间完全让给竖带），
深度再加 0.10m 让它明显凹进去。

---

### ⑦ 场地与配景"零碎" —— 读不出"校园"

v13 的绿岛是**三块不规则多边形 + 12 个球**，散在中庭里 ⇒ 看着像"洒了几颗豆子"。
实拍中庭是：**大面积浅灰石材铺装（占 70%）+ 3 块不规则绿岛（带修剪灌木成组）+ 行道树**。

⇒ **v14 改**：绿岛形状改为**沿铺装边界的有机曲线**、灌木改成**一簇簇**（每簇 5~7 个球，
大小递减）、加**行道树列**（树干 + 球冠）。

## 四、★★★ v14d 追加：一个更致命的 bug（已修，附证据）

做完上面 10 项后重新渲染，**窗户仍然是白块**。于是写了 `diag-glass.cjs` 做像素级探针。

### 4.1 探针（把问题变成可数指标）

把可疑材质换成**亮品红**、把可能遮挡它的兄弟构件**隐藏**，然后数品红像素占比：

```js
scene.traverse(o => {
  if (!o.isMesh) return;
  const hex = o.material?.color?.getHex();
  if (hex === 0xE4E0D8 || hex === 0xCFC8BA) o.visible = false;   // 隐藏窗套/窗台
  if (hex === 0x0C1420) o.material = new THREE.MeshBasicMaterial({ color: 0xFF00FF });
});
```

**结果：品红占比 = 0.024%（72/305265）** —— 仅剩楼梯间那扇门。
⇒ 232 片玻璃**全部没进画面**。（几何统计确认：`glassMeshes: 232`，尺寸 2.1×1.75 ✓ 全对）

### 4.2 真因：偏移符号反了，玻璃整片沉进墙里

在同一面墙上打印各层**外表面坐标**（外法向 = +Z，数值越大越靠外）：

| 层 | 外表面 z | 与墙面关系 |
|---|---|---|
| 玻璃 | **−7.105** | **比墙面还靠里 0.075** ✗ |
| 窗套 | −7.010 | 凸出 0.020 ✓ |
| 窗台 | −6.975 | 凸出 0.055 ✓ |
| **结构体墙面** | **−7.030** | 基准 |

`faceBox` 的语义是 `halfD + v`（+Z 面），**正 v 才是朝外**；
而 `aWindow` 传的是 `v = −0.075`（本意"凹进 0.075"）⇒ 直接**朝墙内跑**。

叠加第二个坑：立面基准传的是 `halfD = W/2`，而结构体盒子是 `BoxGeometry(W−0.06,…)`
⇒ 真实墙面在 `W/2 − 0.03` ⇒ **基准面比墙面多出 0.03**，误差被放大到 0.105。

叠加第三个坑：**窗套是 `w+0.13 × h+0.13` 的实心板**（不是框）⇒
即使玻璃位置对了，也会被这块更大的白板**整块盖住**。

### 4.3 修法（三处）

1. `faceBox` 语义**明确固定**为 `v = 沿外法向偏移（>0 凸出、<0 凹进）`，并把注释写进函数头
2. 立面基准改传**真实外表面**：`halfWf = halfW − 0.03` / `halfDf = halfD − 0.03`
3. 玻璃改 `v = +0.008`（嵌在墙里 8mm）；窗套改**四根边框条**（不再用实心板）

### 4.4 修完的量化对比（同一切片区域，1440×960）

| 指标 | 修前 | 修后 |
|---|---|---|
| 深色玻璃像素 | **0** | **822** |
| 砖红像素 | 800 | 830 |
| 白色像素（窗套/腰线） | 1973 | 1646 |
| 品红探针占比 | 0.024% | — |

**"0 → 822"是这次最硬的一条证据**：从"完全看不见"到"成为立面的第二主色"。

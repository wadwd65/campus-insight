## 四、构建过程：六道闸门

`python build-campus.py` 依次做这些事，**任何一道不过就中止**：

### ① 抽取自证
从 `tower-04-assembly.js` 抽出 `makeTower()` 到 `var campus =` 之间的片段，
并断言：**必须含** `function makeTower`、`function skyBridge`；
**必须不含** `var campus`、`scene.add(`。边界找错就立刻报错。

> 为什么：靠"行号"或"搜关键字"切代码，边界一旦偏一点，
> 产物会**静默少一半楼**——而页面照样能打开。

### ② 语法预检
逐个 `node --check`。防的是拼接后才暴露的语法错误。

### ③ 色号 lint（`color-lint.py`）
拦截"随手写了个 `#A08078` 这类未登记色号"。
纯数据文件（base64 里会出现假的 `0x+字母`）在 `LINT_SKIP` 里跳过。

### ④ 顶层重名
扫所有 `var` / `function` 声明，同名跨文件即报错。

### ⑤ 局部变量遮蔽（10-06 新增）
**真实事故**：`campGround()` 里 `var cu = ..., cv = rnd(...)` 把外层的
canvas 对象覆盖成数字 ⇒ 贴图上传失败 ⇒ **整个地面全黑**。
顶层重名抓不到（都在函数体内），所以单独扫：
同一函数块内，某标识符既被声明为 `document.createElement` / `new THREE.*` / `getContext`，
又被 `var x = rnd(...)` 二次声明。

### ⑥ ASI 静默失效（10-06 新增）
**真实事故**：批量重写 `CAMP_STAGE.add(city())` 时漏了行尾分号，
JS 靠 ASI 把下一行解析成函数调用 ⇒ 运行时 TypeError，
而 `node --check` **查不出来**（语法合法）。
判据：形如 `})(xxx())` 开头、去掉行尾注释后不以 `;` 结尾的行。

### ⑦ 坐标多真源（10-06 新增）
**两次事故**：
- 田径场有三份坐标，改 `CAMP_TRACK` 完全不生效；
- `campAptLinks` 硬编码公寓坐标，建筑一挪就连廊悬空。
判据：`CAMP_PLACE` 不得含已由别处渲染的对象；依赖落位的构件必须 `Box3` 实测。

### ⑧ 组装
```python
body = 12 个 parts 顺序拼接
out  = shell.replace('</body>', '<script>'+lib+'</script><script>'+body+'</script></body>')
out  = out.replace('<title>', '<title>完整校园 · ', 1)
→ 写 campus.html
```

**打包的本质**：把 three.js 和一个巨大的 IIFE/顺序脚本，各塞进一个 `<script>` 标签，
让浏览器只发一次请求。**没有任何模块系统、没有打包器**——就是字符串拼接。

## 五、⚠️ 最大的技术债：2.5D 模块不在构建链里

`public/map/校园地图-3D实景.html` = `campus.html` + **手写的 2.5D 模块**
（10-10 加的「隐藏城市层/天空、锁俯角 55°、拖拽缩放」，10-20 又改成实时渲染）。

**这个模块没有对应的 `tower-15-flat25d.js` 源文件**——
它是直接写进产物的，`parts` 列表里没有它。

### 后果（动手前必读）
1. **重新跑 `build-campus.py` 会覆盖传播链的另一头**：
   它只产出 `campus.html`，**不会**更新 `public/map/校园地图-3D实景.html`；
2. 反过来，如果你拿新的 `campus.html` 去替换线上文件，
   **2.5D 模块、实时渲染、太阳公转全都会消失**，页面会退回纯 3D 航拍；
3. 所以现在的正确做法是：**不要跑构建脚本**，直接改
   `public/map/校园地图-3D实景.html`（改前先 `git diff` 确认）。

### 想还债的话（建议顺序）
1. 把产物里的 2.5D 模块**反向抽出来**存成 `tower-15-flat25d.js`；
2. 加进 `parts` 列表末尾；
3. 让 `build-campus.py` 直接产出到 `public/map/校园地图-3D实景.html`；
4. 跑一次构建，用 `cmp` 确认与现产物只差预期部分。

## 六、重建步骤（按当前状态，不推荐直接跑）

```bash
cd campus-insight/map-src
python build-campus.py          # 产出 campus.html（六道闸门全绿才有输出）
```

然后是**手工**步骤（因为第五节的技术债）：
```bash
# 1. 备份现产物
cp ../public/map/校园地图-3D实景.html ../public/map/校园地图-3D实景.html.bak
# 2. 把 campus.html 的 2.5D 模块段（约 7,600 B）手工搬过去
# 3. 浏览器验：拖拽/缩放/太阳移动/无报错
```
